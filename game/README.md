## 앱 이름: 비행기 시뮬레이터

## 카테고리: 게임 앱

### 배포 링크

https://gemini.google.com/share/f5fc1238b5d7

### 이 앱을 만든 이유
- 웹에서 자동차 시뮬레이터에서 라디오가 나오고 풍경을 보면서 힐링하는 게임이 기억이 나서 비행기로 다시 만들어보았습니다.
- 바닐라 JS, HTML, CSS만으로 3D 렌더링이 얼마나 부드럽고 자연스럽게 동작하는지  검증하고자 제작했습니다.

### 주요 기능
- 키보드(WASD, 방향키)와 스로틀 슬라이더를 통해 누구나 직관적이고 쉽게 비행기를 조종할 수 있습니다.
- 숲, 사막, 설산, 도시 등 4가지 환경을 선택하면 지형지물과 조명이 해당 테마에 맞춰 즉각적으로 변경됩니다.
- 프로펠러기, 제트기, UFO등 비행기의 외형과 색상을 실시간으로 교체하여 다양한 시각적 경험을 제공합니다.
- 고도가 지면에 너무 가까워지면 자동으로 고도를 올려서 추락 스트레스 없이 평화로운 비행에만 집중할 수 있게 돕습니다.
