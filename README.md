# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

# 3. 학습 앱

## 앱 이름: Linden
## 카테고리: 학습 앱

### 배포 링크
https://gemini.google.com/share/e70523785c76

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
    1. AI를 이용해서 공부를 할 때 내가 물어본 개념에 대한 설명 뿐만 아니라 해당 개념을 이해하기위한 상위 지식과 해당 개념에서 깊게 들어가는 심화지식을 제안받고싶었음.
    2. 내가 공부했던 개념들의 리스트를 상위지식과 심화지식을 포함하여 시각화를 이용해 깔끔하게 정리하고 싶었음.
- 이 앱을 언제, 어떻게 사용할 건가요?
    1. 공부하다가 모르는 개념이 생기면 물어보고, 해당 개념을 완벽하게 이해하기위한 상위지식과 더 깊게 들어가는 심화지식을 공부하고 싶을 때.
    2. 내가 공부했던 내용들을 빠르게 정리하고 복습하고싶을 때.

### 주요 기능
1. 궁금한 개념을 검색하면 AI가 설명과 함께 선수/심화 지식을 추천
2. 추천된 개념을 클릭하면 지식 그래프가 연쇄적으로 확장
3. 검색한 개념들의 관계를 노드와 화살표로 시각화

### AI 기능 (해당되는 경우)
- Gemini 2.5 Flash API를 활용하여 입력된 개념에 대한 설명을 실시간 생성
- AI가 개념 간 위계를 자동 판단하여 선수 지식(prerequisite)인지 심화 지식(advanced)인지 분류
- 분류된 위계 정보를 기반으로 그래프의 노드 위치와 화살표 방향을 자동 결정

## AI 사용 일지

### 1. 초기 프롬프트
```
1. 제미나이 AI를 이용해서 학습에 도움을 주는 서비스를 만들거야. 시각화도 넣을거고.
2. 예를들면 
- 내가 클로저에 대해 설명해달라고 질문을 한다.
- 클로저에 대해 자세히 설명해주고, 클로저를 이해하기 위한 선수 지식들(특히 자세한 설명에 포함되어있는 단어를 우선으로)을 추가적으로 물어보기를 추천해준다.
- 클로저를 이해하기위해 제시해준 많은 선수 지식들중 만약 실행컨텍스트와 호이스팅을 알아보기위해 질문했다고 치자. 
- 시각화 자료를 볼 수 있는 페이지가 있어야해. 이 페이지에서는 클로저와 실행컨텍스트, 호이스팅이 한줄로 이어져있어. 내가 무엇을 검색해봤는지 한눈에 알 수 있고 클로저와 연관된 지식이 무엇인지도 바로 알 수 있는거지. 
3. 시각화 페이지는 옵시디언을 예시로 들 수 있을거같은데, 옵시디언은 자료가 쌓이면 서로 너무많은 선이 이어져있어서 오히려 보기가 힘들어. 우리 서비스에서는 내가 선택한 주제에 대해서만 시각화가 진행되어야해. 내가 원하는 지식과 관련된것들만 깔끔하게 시각화자료로 볼 수 있도록.
4. 내가 검색한 지식들은 제미나이ai를 이용해 태그를 생성할거야.  사용자가 새로운 지식을 검색해봤을때 기존에 검색했던 자료들의 태그들을 확인해서 시각화를 용이하게 하기위해서. 클로저에 대해 자세히 설명해줘 라고 질문했다면 클로저가 하나의 태그가 되겠지.
```

### 2. 프롬프트 개선 과정
- 처음 결과물의 문제점은 무엇이었나요?
    1. 코드를 HTML/CSS/JavaScript만으로 구현하지 않고, React와 Tailwind CSS 등을 이용해서 구현함.
    2. 초기 화면에서 추천해주는 개념 리스트를 클릭해도 설명 요청이 정상적으로 안일어남.
    3. 검색한 개념과 연관된 지식들을 추천해주는데, 해당 지식들이 상위지식인지 아니면 심화지식인지 정상적으로 판단해주지 못함.
    4. 개념을 설명해주는 페이지에서 아래에 선수 지식이나 심화지식을 추천해주는 리스트를 클릭해도 아무 동작이 일어나지 않음.
- 어떤 식으로 프롬프트를 수정했나요?
    ```
    1. 원래 구현했던 코드로 복구해줘.

    2. 무엇을 배워볼까요?에 나오는 개념들을 클릭해도 아무 반응이 없어.

    3. 궁금한 개념을 검색하고 밑에 해시태그로 제시해준 단어를 클릭했을때 로딩이 꽤 길어지는데, 무한로딩이 되는건아닌지 체크해줘.

    4. 궁금한 개념을 검색하고 연계되는 개념들의 설명을 요청했을때 해당 개념이 상위지식인지 아니면 하위지식인지 알아서 판단해주도록 구현되어있는지 체크해줘.

    5. 코드는 리액트를 사용하지 않고, HTML/CSS/JavaScript만으로 구현해야하는 제약사항이 있어. 해당부분 반영해서 다시 코드를 작성해줘.
    ```
- 몇 번의 반복을 거쳤나요?
    총 15회. 특히 시각화 관련 부분에서 반복적으로 문제가 발생했는데, 해당 문제를 해결하기 위한 프롬프트만 7회 반복했음.

### 3. 효과적이었던 프롬프팅 전략
- 어떤 방식으로 요청했을 때 원하는 결과가 나왔나요?
    발생한 문제를 자세히 묘사하고, "오래 걸려도 좋으니 코드를 상세하게 살펴보며 해결해달라"고 요청했을 때 효과적이었음.
- 반대로 효과가 없었던 방식은 무엇이었나요?
    단순한 문장으로 요청했을 때 효과가 없었음. 예: "안돼. 동작안되니까 해결해줘." 같은 방식은 문제를 정확히 파악하지 못하고 엉뚱한 수정을 하는 경우가 많았음.

### 4. 배운 점
- Gemini Canvas를 효과적으로 사용하기 위한 나만의 팁이 있다면?
    1. 하나의 HTML 파일로 작성하는 등 제약사항이 많은 상황에서는 가능한 핵심만 간단하게 요청하는 것이 좋았음.
    2. 문제가 발생했을 때 단순히 "고쳐줘"보다 구체적인 증상과 기대 동작을 함께 설명하면 정확도가 올라감.
    3. 한 번에 여러 요구사항을 나열하기보다 번호를 매겨 구조화하면 AI가 빠짐없이 반영하는 확률이 높아짐.
    4. 기술적 제약사항(예: React 사용 금지, HTML/CSS/JavaScript만으로 구현)은 초기 프롬프트에서 명확히 선언하는 것이 반복 수정을 줄여줌.

### 5. 리뷰어에게 피드백 받고 싶은 포인트
- 프롬프트를 적절하게 작성했는지
- 제약사항이 많은 상황에서 더 적합하게 AI를 활용하는 방법이 있는지
- 서비스의 개선점이 무엇이 있을지
- 선수 지식/심화 지식의 위계 분류 정확도를 높이기 위한 프롬프트 개선 방안

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
    우테코 과정 진행 시 LMS 링크, 구글 캘린더, 스프레드시트, 구글 독스 등 다양한 형식의 안내 자료가 제공된다. 자료가 여러 플랫폼과 형식으로 분산되어 있어 필요한 정보를 빠르게 찾기 어려운 문제가 있었음.

### 주요 기능
1. 구글 캘린더, 알쓸크잡, 우테코 LMS, 테크코스 생활가이드를 기본으로 제공
2. 우측 상단의 + 버튼을 통해 자료(제목,주소)를 추가
3. 삭제 버튼을 통해 삭제
