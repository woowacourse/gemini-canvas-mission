### 💡 이 앱을 만든 이유

**1. 어떤 문제/불편함을 해결하려고 했나요?**
우아한테크코스 프리코스를 통해 자바로 콘솔 앱을 만드는 것에는 어느 정도 익숙해졌지만, 백엔드의 핵심인 '스프링(Spring)' 프레임워크에 대해서는 아는 것이 거의 없는 백지상태였습니다. 시중의 강의나 공식 문서는
너무 전문적인 용어가 많아 진입장벽이 높다고 느꼈고, 이에 저처럼 **"자바 콘솔 앱만 겨우 만들어본 완전 초보"** 의 눈높이에 맞춰 스프링의 기초 지식을 빠르고 직관적으로 채워줄 수 있는 맞춤형 학습 앱을
기획하게 되었습니다.

**2. 이 앱을 언제, 어떻게 사용할 건가요?**

- 본격적인 스프링 학습에 들어가기 전이나 학습 초기 단계에, 낯선 개념들에 익숙해지기 위해 매일 가볍게 사용합니다.
- 단순히 눈으로만 읽는 것을 넘어 **직접 키보드로 타이핑하며 개념을 설명해보는 '백지 복습'** 과 '빈칸 채우기' 기능을 통해 지식을 확실히 체화하는 데 집중적으로 활용합니다.

---

### 🚀 주요 기능

- **📖 개념 비유 사전**
  낯선 스프링의 핵심 개념들(IoC, DI, Bean, MVC 등 20여 개)을 프리코스에서 경험한 '자바 콘솔 앱 개발(main 메서드, new 객체 생성 등)'에 빗대어 아주 쉽게 설명합니다.

- **💬 인터랙티브 백지 복습**
  배운 개념을 나만의 언어로 백지에 적듯 자유롭게 작성해보는 공간입니다. 단순 암기가 아닌 본인만의 이해도를 텍스트로 풀어내며 스스로를 테스트할 수 있습니다.

- **✅ 미니 퀴즈 & ✍️ 빈칸 채우기**
  객관식 퀴즈와 직접 타이핑하는 주관식 빈칸 채우기를 통해 스프링 지식을 가볍게 점검합니다.
  오답 노트 지원: 100점을 맞을 때까지 **'틀린 문제만 다시 풀기'** 가 가능하며, 마우스 클릭 없이 Enter 키만으로 다음 문제로 부드럽게 넘어가는 UX를 적용해 학습 몰입감을 극대화했습니다.

### ✨ AI 기능 (Gemini API 활용)

본 앱은 구글 Gemini API를 활용하여, 고정된 정답이 없어 채점이 불가능한 서술형 학습의 한계를 극복하는 AI 기능을 제공합니다.

**1. 💬 AI 1:1 맞춤형 피드백 코치**

- **역할:** 사용자가 '백지 복습' 탭에서 특정 스프링 키워드에 대해 자신이 이해한 바를 서술형으로 엉성하게나마 작성하면, AI가 문맥을 파악하여 1:1 피드백을 즉시 제공합니다.
- **프롬프트 특징:** 시스템 프롬프트를 통해 AI에게 **'우테코의 친절하고 다정한 코치'** 라는 페르소나를 부여했습니다. 어려운 전문 용어 사용을 철저히 제한하고, 사용자가 맞게 이해한 부분은 폭풍 칭찬해
  주며, 틀린 부분은 자바 콘솔 앱(로또 미션 등)의 경험에 빗대어 아주 쉽게 교정해 주는 든든한 페이스메이커 역할을 수행합니다.
