# 📅 은오의 TODO 캘린더 (Eun-o's TODO Calendar)

스마트하게 관리하는 나만의 일정 관리 웹 애플리케이션입니다.  
깔끔한 블루 & 그레이 톤의 UI를 통해 하루의 할 일과 한 달의 일정을 한눈에 파악할 수 있습니다.

---

## 🚀 주요 기능

### 1️⃣ 하이브리드 일정 관리

#### 📆 달력 뷰
- 한 달 전체 일정을 **그리드 형태**로 확인
- 각 날짜별 할 일을 요약 표시

#### 📝 일일 투두 리스트
- 특정 날짜 클릭 시 우측에 상세 할 일 목록 표시
- 달력과 실시간 연동

---

### 2️⃣ 스마트 카테고리 시스템

각 할 일의 특성에 따라 **4가지 카테고리**를 제공합니다.

| 카테고리 | 기능 설명 |
|----------|------------|
| 📚 과제 | 마감일(Deadline) 지정 가능, D-Day 자동 계산 |
| 💼 알바 | 요일 선택 → 매주 반복 일정 설정 |
| 🏋️ 운동 | 요일 선택 → 반복 일정 설정 |
| 📌 기타 | 단발성 일반 할 일 |

✔ 카테고리에 따라 입력 UI가 동적으로 변경됩니다.  

---

### 3️⃣ 📊 통계 및 상태 관리

- **실시간 카운팅**  
  - 전체 할 일 개수
  - 완료된 할 일 개수

- **상태 동기화**
  - 달력 요약과 상세 리스트 체크박스 실시간 연동

---

### 4️⃣ 💡 사용자 편의성

- 💾 **로컬 스토리지 저장**
  - 새로고침 / 브라우저 종료 후에도 데이터 유지

- 📱 **반응형 디자인**
  - PC / 모바일 환경 최적화
  - Tailwind CSS 기반 UI

## 📖 사용 방법

### 1️⃣ 날짜 선택
왼쪽 달력에서 일정을 관리할 날짜를 클릭합니다.

### 2️⃣ 할 일 입력

1. **Task Name**에 할 일을 입력합니다.
2. 카테고리를 선택합니다.
   - 📚 과제 → 마감일 입력창 활성화
   - 💼 알바 / 🏋️ 운동 → 요일 선택 칩 활성화
3. **Add Task** 버튼을 눌러 추가합니다.

### 3️⃣ 완료 처리
- 리스트 왼쪽 체크박스를 클릭하여 완료 상태를 토글합니다.

### 4️⃣ 삭제
- 마우스를 올리면 나타나는 🗑 휴지통 아이콘을 클릭하여 삭제합니다.
