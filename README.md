# gemini-canvas-mission

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## AI 사용 일지

### 1. 초기 프롬프트
처음 Gemini에게 입력한 프롬프트를 그대로 적어주세요.
```
목표 사용자는 백엔드 개발자이고, 
RESTful한 API를 작성할 때, 
네이밍에 어려움을 겪는 사람들을 위한 유틸리티 서비스를 
Gemini AI를 연동해서 비즈니스 모델이 무엇인지, 
함수의 기능이 무엇인지 입력 받아서 추천해주는 챗봇으로 만들어줘
```
### 2. 프롬프트 개선 과정
- **처음 결과물의 문제점은 무엇이었나요?**
    - 컴파일 오류가 발생했습니다.
    - React를 사용하여 결과물을 만들어냈습니다.
    - 1 단계와 2 단계를 진행하고 나서 3단계가 진행되어야 하는데, 입력 오류로 인해서
      1단계 입력의 마지막 단어가 2단계의 입력으로 들어가는 문제가 있었습니다.
    - 비즈니스 모델을 반복적으로 다시 입력 받는 사용자 피로도를 높이는 UX가 있었습니다.

- **어떤 식으로 프롬프트를 수정했나요?**  
  단계별로 진행하는 로직을 추가하였습니다.
```
목표 사용자는 백엔드 개발자이고, RESTful한 API를 작성할 때, 
네이밍에 어려움을 겪는 사람들을 위한 유틸리티 서비스를 만들려고 해. 
Gemini AI를 연동해서 추천 네이밍을 생성해줄거야. 
비즈니스 모델이 무엇인지, 
API의 기능이 무엇인지 입력 받아서 추천해주는 챗봇을 만들어줘.
1 단계: 비즈니스 모델 입력받기
2 단계: API의 기능 입력받기
3 단계: 추천 네이밍 보여주기
반드시 1,2 단계를 진행한 후에 3단계가 진행되어야 해.
```
기술 스택을 제한하는 조건을 추가하였습니다.
```
그리고 HTML, CSS, JavaScript만 사용해서 만들어줘.
React나 다른 프레임워크는 사용하지 마.
```
수정이 필요한 오류에 대한 설명을 프롬프트로 추가 작성하여서 문제를 해결했습니다.
```
비즈니스 모델을 입력하고 엔터를 누르면 
제일 마지막 단어가 중복으로 입력되어서 
기능 입력 단계의 입력으로 들어가는 오류가 있어. 
도메인 입력을 받고나서 생기는 입력 오류를 해결해줘
```
개선이 필요한 부분에 대해서 개선 로직을 조건으로 추가하여 문제를 해결했습니다.
```
비즈니스 모델을 한번 입력한 다음에는 기능 입력을 계속 받는데, 
비즈니스 모델을 바꾸고 싶을 때는 
초기화 버튼을 선택해서 비즈니스 모델을 다시 입력받게 해줘
```
- **몇 번의 반복을 거쳤나요?**  
  처음 입력을 포함하여 5번의 입력을 진행했습니다.

### 3. 효과적이었던 프롬프팅 전략
- **어떤 방식으로 요청했을 때 원하는 결과가 나왔나요?**  
  단계별 입력과 기술 스택 제한, 오류 발생 상황 정리를 한 경우에 원하는 결과가 나왔습니다.
- **반대로 효과가 없었던 방식은 무엇이었나요?**  
  목표 사용자와 비즈니스 모델, 사용해야하는 기술만을 정의하는 방식으로 했을 때,
  컴파일 에러가 뜨고 결과물을 생성하지 못했습니다.
### 4. 배운 점
- **Gemini Canvas를 효과적으로 사용하기 위한 나만의 팁이 있다면?**  
  사용자, 비즈니스 모델, 사용 기술, 단계별 비즈니스 로직 작성, 기술 스택 제한과
  세부적인 기능 조건 제안을 할 수록 정확하게 원하는 결과물이 나왔습니다.
### 5. 리뷰어에게 피드백 받고 싶은 포인트
- 추천 받는 비즈니스 로직이 적절한지
- 추가로 입력받거나 결과로 나오는 추천 내용의 형식이 적절한지
