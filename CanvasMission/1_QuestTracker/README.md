## 앱 이름: [QuestTracker]
## 카테고리: [유틸리티 앱]

### 배포 링크
https://gemini.google.com/share/36db7b0ab6f0

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
  - 여러 개의 게임을 주기적으로 돌리는 사람들이 언제든지 게임을 켜지 않고 간단하게 진행 상황을 확인할 수 있도록 하기 위해
- 이 앱을 언제, 어떻게 사용할 건가요?
  - 매일매일 하고 있는 게임의 숙제를 완료할 때마다 체크해두어 정신없을때 빠진 것이 없는지 잊지 않도록 사용합니다. 게임이 아니더라도 주기적으로 먹는 약 체크, 운동 루틴 체크 등 유용하게 사용 가능

### 주요 기능
- 기능 1 : 카드 1장마다 제목을 설정하고, 해당 제목의 소분류 체크박스 여러개를 아래로 확장가능
- 기능 2 : 체크박스별로 초기화 주기를 설정하여 일일은 00시마다, 주간은 월요일 00시마다, 월간은 1일 00시마다 체크박스가 해제되는 기능
- 기능 3 : 클라우드/로컬 저장으로 사용하던 환경에서 재접속 시 이전 기록이 남아있을 수 있도록 설정
