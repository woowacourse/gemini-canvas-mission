## 🖥️ 1. 유틸리티 앱
### 앱 이름: 트래블 버디 - 스마트 해외 출국 가이드
### 카테고리: [유틸리티 앱]

배포 링크
https://gemini.google.com/share/c661e295e7bf

### 이 앱을 만든 이유
- 해외를 나가면서 각 나라마다 주의해야 하는 사항과 준비해 놔야 될 입국신고서 정보 등은 사이트마다 파편화되어 있습니다.
- 여행자가 여러 사이트를 일일이 조사하고 준비해야 하는 불편함을 해소하고자, 한 곳에서 모든 정보를 알려주면 좋겠다 라는 생각이 들었습니다.
- 해외 여행이나 출장 등 타국에 나갈 때 이 앱을 사용하면 복잡한 과정 없이 보다 편리하고 안전하게 출국을 준비할 수 있습니다.


### 주요 기능
- 일본, 베트남, 세부(필리핀), 유럽, 호주 등 주요 국가별로 최적화된 필수 준비물과 서류 리스트를 제공
- 메인 화면의 간략한 리스트 외에도 '더보기' 버튼을 통해 해당 국가의 전체 준비물과 구체적인 현지 에티켓을 팝업 형태로 상세히 확인할 수 있습니다.
- 국가별로 상이한 문화, 법규, 에티켓 정보를 제공합니다
- 탐색 페이지에서 선택한 여행지를 리스트에 추가하면, 마이페이지에서 즉시 나만의 체크리스트로 변환되고 사용자가 직접 준비물을 챙겼는지 하나하나 체크할 수 있는 기능을 제공하여 준비 누락을 방지합니다.
- 불필요해진 여행지는 리스트에서 즉시 삭제할 수 있으며, 삭제 시 상단 배지의 숫자가 실시간으로 갱신됩니다.

### 🤖 AI 기능
- 각 지역의 특색을 가장 잘 나타내는 기념품 리스트를 AI가 분석하여 제공합니다.
- 무엇을 사야 할지 고민하는 시간을 줄여주고, 추천 이유와 구매 팁을 함께 제공하여 사용자에게 실질적인 도움을 줍니다.

### 이 앱을 만든 이유
- 게임을 즐겨하지 않아 고민을 하다가 대학 시절, 강의 사이 쉬는 시간이나 이동 중에 친구들이 스마트폰으로 간단한 주차 게임을 즐기던 모습이 기억났습니다. 저 또한 한 때의 즐겁게 했어서 모바일 게임에서 손가락으로 조작 하는것을 키보드 환경에 적용해 구현해보자 싶어 이 앱을 제작하게 되었습니다.

- W/A/S/D 키를 통해 조작이 가능합니다

- 반대편 차선에서 마주 오는 차량(NPC)들이 존재하여, 단순 주차뿐만 아니라 도로 주행의 느낌을 줄 수 있습니다.

## 📖 3. 학습 앱
### 앱 이름: 판교 사투리 학습지
### 카테고리: [학습 앱]

배포 링크
https://gemini.google.com/share/c365958f34d0

### 이 앱을 만든 이유
- 한 때 판교 사투리가 인터넷상에서 엄청나게 바이럴 되면서, IT 업계 특유의 전문 용어와 영어 혼용이 신입 사원이나 외부 협력사와의 소통 문제로 번지는 것을 보았습니다.
이러한 현상을 단순한 유머로 소비하는 것을 넘어, 실질적인 비즈니스 커뮤니케이션 능력을 향상하고 서로의 언어를 이해하여 업무 효율을 높이자는 취지에서 이 학습 앱을 기획하게 되었습니다.

### 주요 기능
- 작심삼일로 끝나지 않도록 총 30일 분량의 단계별 커리큘럼을 제공하여 체계적인 학습을 유도합니다.
- 퀴즈에서 절반 이상 정답을 맞혔을 때만 'Clear' 표시가 붙으며 다음 Day가 해금되어, 성취감과 학습 긴장감을 동시에 제공합니다.
- 단순히 단어를 읽는 것에 그치지 않고, 뜻풀이와 용어를 매칭하는 퀴즈를 통해 암기 효과를 극대화합니다.
- 틀린 단어들만 따로 모아 저장하고 다시 복습할 수 있는 오답 관리 기능을 제공합니다.
- 모바일과 데스크톱 어디서든 편하게 학습할 수 있도록 최적화된 UX/UI 디자인을 적용했습니다.
- 학습 진도와 성적에 따라 '감자'부터 '씨레벨'까지 승급하는 요소를 도입했습니다.

### 2. 프롬프트 개선 과정
- 처음 결과물의 문제점은 무엇이었나요?
  - 처음에는 학습 분량이 하루치 정도로 매우 적었고, 디자인이 너무 단조로웠습니다. 또한 진도 반영 기준이 명확하지 않아 퀴즈를 풀기만 하면 무조건 완료 처리가 되는 단순한 구조였습니다.
- 어떤 식으로 프롬프트를 수정했나요?
  - 퀴즈형식 말고 학습지로 바꿀게, 30일 분량으로 내용으로 늘려줘, 중요한 단어는 복습을 위해 1~2개씩 중복 배치해줘, 퀴즈에서 50% 이상 맞혔을 때만 진도가 반영되게 로직을 수정해줘 와 같이 구체적인 수치와 비즈니스 로직을 명시했습니다.
- 몇 번의 반복을 거쳤나요?
  - 총 4~5번의 반복적인 피드백과 수정을 거쳐 현재의 앱이 완성되었습니다.

### 3. 효과적이었던 프롬프팅 전략
- 어떤 방식으로 요청했을 때 원하는 결과가 나왔나요?
  - 단순한 기능 나열보다는 절반 이상 맞혔을 때 진도 반영처럼 명확히 전달했을 때 코드가 정확하게 구현되었습니다. 또한, 실제 판교에서 쓰이는 예시 단어들을 직접 몇 개 던져주니 전체적인 데이터의 결이 잘 잡혔습니다.
- 반대로 효과가 없었던 방식은 무엇이었나요?
  - 한 번에 너무 많은 요구사항과 수정의 나열은 누락되거나 제대로 반영이 안되는 오류가 빈번히 났던것 같습니다.

### 4. 배운 점
- 기획, UI 구현, 로직 고도화, 데이터 보충 등 명확한 단계별 로드맵을 설정하고 하나씩 순차적으로 요구하는 방식이 가장 좋은 결과를 냈습니다. 
- 한 번에 모든 것을 해결하려 하기보다, 각 단계가 완료된 후 다음 단계로 넘어가는 점진적 개발 방식을 취할 때 오류가 적었습니다. 또한 정보가 디테일할수록, 그리고 제약 사항이 뚜렷할수록 산출물의 퀄리티가 상승한다는 점을 배웠습니다.

### 5. 리뷰어에게 피드백 받고 싶은 포인트
- AI를 활용한 오류 해결 시, 단순히 어떻게 고치냐고 묻는 것을 넘어 문제의 맥락과 기술적 배경을 구체적으로 설계하여 질문하는 능력이 중요하다고 생각합니다. 현직자분들이 보시기에, 사용자가 어떤 정보를 포함했을 때 이 사람은 AI를 도구로서 매우 능숙하고 밀도 있게 다룬다고 느끼시는지 궁금합니다.
- 혹시 현직자분들께서 오류 해결을 위해 AI를 활용하실 때, 5W1H과 같은 자신만의 질문 체크리스트나, 답변의 정확도를 비약적으로 높여주는 핵심 항목이 있으신지 궁금합니다.

## 🖇️️ 4. 페어 프롬프트 릴레이 앱
### 앱 이름: 추억놀이 : 동네모임 
### 카테고리: [페어 프롬프트 릴레이]

배포 링크
https://gemini.google.com/share/3aa813ee9016

### 이 앱을 만든 이유
- 최근 당근마켓을 통해 이웃 간의 관계 형성이 활발해지고 있지만, 본질이 중고거래 서비스이다 보니 단순 놀이나 친목 모임은 앱의 원래 성격과 섞여 정체성이 흐려지는 경향이 있다고 생각했습니다. 거래의 목적 없이 오직 함께 즐겁게 노는 것에만 집중할 수 있는 전용 플랫폼이 있으면 좋을것 같다고 생각했습니다.
- 지금 이 순간 재미있게 놀고 싶다는 명확한 목적 하나만으로 모일 수 있는 서비스를 기획했습니다. 중고거래 글들 사이에서 놀이 상대를 찾는 번거로움을 없애고, 오로지 추억의 놀이를 즐기기 위한 사람들만 모이는 공간을 지향합니다.
- 비슷한 시절의 추억을 공유하는 사람들끼리 만날 수 있도록 출생 연도 필터 기능을 넣었습니다. 이를 통해 처음 만나는 사이라도 공감대 하나만으로 금세 친구가 될 수 있는 커뮤니티 환경을 제공합니다.

### 주요 기능
- 숨바꼭질, 경찰과 도둑, 무궁화 꽃이 피었습니다 등 추억의 놀이를 테마로 한 모임 방을 자유롭게 개설하고 실시간으로 참여할 수 있습니다.
- 모임 생성 시 참여 가능한 출생 연도 범위를 설정할 수 있어, 비슷한 문화를 향유한 또래끼리의 밀도 높은 소통을 보장합니다.
- 현재 몇 명의 친구가 모였는지, 누가 참여 중인지 실시간으로 확인할 수 있어 모임의 활성화 정도를 즉각 파악할 수 있습니다.
- 모임장은 장소나 시간을 자유롭게 수정하거나 모임을 취소할 수 있으며, 일반 사용자는 자유롭게 입퇴장이 가능하여 부담 없는 참여를 유도합니다.
- 복잡한 가입 없이 닉네임만으로 활동할 수 있어, 개인정보 노출 부담 없이 순수하게 놀이 그 자체에 집중할 수 있는 환경을 제공합니다.
