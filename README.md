# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.


## 1. 🛠유틸리티

### 🎨 아스키파이(Asciify): Real-time ASCII Art & GIF Generator
> **"자신이 좋아하는 이미지를 텍스트 감성으로 즐겨보세요!"**

**Asciify**는 이미지, 애니메이션 GIF, 동영상을 실시간으로 **ASCII 텍스트 아트**로 변환해주는 세련된 웹 애플리케이션입니다. 브라우저에서 즉시 실행되며, 변환된 결과물을 다시 GIF로 녹화하거나 텍스트로 복사할 수 있는 강력한 기능을 제공합니다.

## 2. 📚학습

### 🧟코드 데드 3D(CODE DEAD 3D): Quarantine Report
> **"Kotlin Null-Safety 정밀 검역 프로토콜에 오신 것을 환영합니다."**

격리 구역에 들어오는 데이터(코드)를 분석하여 **NullPointerException(NPE)** 발생 여부를 판별하세요.
- **체력(LIFE)**: 총 3번의 기회가 주어지며, 오판 시 라이프가 차감됩니다.
- **미션**: 5개의 핵심 코틀린 널 세이프티 예제를 모두 통과하여 시스템을 복구하세요.
- **결과 리포트**: 게임 종료 후, 각 코드에 대한 상세한 기술적 분석 리포트를 제공합니다.

## 3. 🎮게임

### 데브 타자 연습(Dev Typer): 
> **AI가 생성하는 실시간 코드 스니펫으로 즐기는 개발자 전용 타자 연습 플랫폼**

**데브 타자 연습**은 단순한 문장이 아닌, 실제 개발 환경에서 사용하는 키워드와 코드 구문을 연습할 수 있는 웹 애플리케이션입니다. 구글의 **Gemini AI**를 연동하여 매번 새로운 연습 콘텐츠를 제공하며, 개발자에게 최적화된 UX/UI를 선사합니다.

##  4. ✨페어 프롬프트 릴레이

### 🧒추억놀이:동네모임#  추억놀이 동네 모임 (Memory Games)
> **"골목길의 추억을 현실로! 동네 친구들과 함께하는 오프라인 놀이 매칭 플랫폼"**

**추억놀이 동네 모임**은 숨바꼭질, 경찰과 도둑, 무궁화 꽃이 피었습니다와 같은 추억의 놀이를 함께 즐길 동네 친구들을 찾고 모임을 관리할 수 있는 **실시간 커뮤니티 웹앱**입니다.

## ✅ 프로그래밍 요구 사항
- 구현은 Gemini Canvas만 사용하고, 다른 AI 도구는 사용하지 않습니다.
- 프롬프트만으로 제약 조건 안에서 유용한 앱을 만드는 것을 목표로 의식적으로 연습합니다.
- 각 앱의 핵심 프롬프트에 명확한 성공 기준을 포함합니다.
- 각 앱의 첫 프롬프트에 최소한 아래 3가지를 명시합니다:
  - 목표 사용자
  - 핵심 기능 1개 이상
  - 금지하거나 제한할 구현 조건
