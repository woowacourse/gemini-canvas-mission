## 앱 이름: [AsyncLearningQuiz]
## 카테고리: [학습 앱]

### 배포 링크
[https://gemini.google.com/share/1589e16e1357]

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
  - JS에서 헷갈리는 비동기 문제를 직관적으로 이해하기 위해 제작
- 이 앱을 언제, 어떻게 사용할 건가요?
  - 비동기와 관련된 개념이 헷갈릴 때, 개념을 정확히 기억해야 할 때 퀴즈를 통해 반복학습할 수 있도록 사용

### 주요 기능
- 기능 1 : 총 25개의 문제은행에서 5, 10, 20, 25 개의 문제 갯수를 선택하여 퀴즈 시작
- 기능 2 : 정답/오답 선택 시 초록색/빨간색으로 표시 및 이유 해설
- 기능 3 : 문제를 섞지 않고 방금 푼 문제 세트 재풀이로 반복학습 기능
