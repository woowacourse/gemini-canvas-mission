# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 1. Commit Crafter (유틸리티 앱)
Commit Crafter는 Git 커밋 메시지 생성 도구입니다. 
- 사용자가 간략한 작업 요약을 입력하면 AI(Gemini)가 문맥을 분석하여 표준 컨벤션에 맞는 커밋 타입(Type)을 지정하고, 객관적이고 기술적인 어투의 제목과 본문을 자동 완성합니다.
- 직관적인 폼 입력과 실시간 터미널 미리보기, 클립보드 복사 기능을 제공하여 엄격한 히스토리 관리가 요구되는 프로젝트 환경에서 문서화의 일관성을 유지하고 작성 피로도를 낮추는 데 목적을 둡니다.

## 2. Neon Escape (게임)
Neon Escape는 정밀한 컨트롤과 피지컬을 요구하는 하드코어 2D SF 플랫포머 게임입니다.
- 자체적인 물리 엔진과 AABB 충돌 처리를 구현했습니다.
- 스테이지가 진행됨에 따라 다방향 대쉬와 더블 대쉬 같은 이동기가 순차적으로 해금되는 치밀한 레벨 디자인을 특징으로 합니다.

## 3. 우테코 생존 모의고사 (학습 앱)
우테코 생존 모의고사는 우아한테크코스 신규 크루들의 원활한 온보딩과 커뮤니티 적응을 돕기 위해 제작된 웹 애플리케이션입니다.
- 객체지향 설계와 클린 코드 같은 기술적 개념뿐만 아니라 페어 프로그래밍, 데일리 미팅, 리뷰 문화 등 우테코 특유의 협업 철학을 담은 문제 은행에서 8개의 퀴즈를 랜덤으로 출제합니다.
- 직관적인 점수 시각화는 물론, 코치진과 선배 수료생들의 피드백이 담긴 상세한 오답 노트 기능을 제공하여 크루들의 기술적 역량과 소프트 스킬 성장을 동시에 지원합니다.

## 4. 나의 소소한 주간 루틴 (페어 프롬프트 릴레이 앱)
나의 소소한 주간 루틴은 사용자가 지정한 요일이나 주간 목표 횟수에 맞춰 습관을 설정하고 달성도를 직관적으로 추적할 수 있는 웹 애플리케이션입니다.
- Firebase 기반의 인증 및 실시간 데이터베이스(Firestore)를 활용하여 개인의 루틴 진행 상황을 안전하게 저장합니다.
- 자신의 대표 루틴과 달성률을 다른 사용자와 공유하고 열람할 수 있는 가벼운 소셜 기능을 제공하여 꾸준한 목표 실천과 동기 부여를 돕습니다.
