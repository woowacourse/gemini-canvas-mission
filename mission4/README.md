# 💧 눈 건강 지킴이
### 배포 링크: https://gemini.google.com/share/9fad003152a5

### 프로젝트 개요

'눈 건강 지킴이'는 장시간 모니터를 응시하며 집중해야 하는 환경에서 안구 건조증 및 시력 저하를 예방하기 위한 웹 애플리케이션입니다. 사용자의 웹캠 환경 유무에 따라 눈 깜빡임 감지 또는 20-20-20 규칙 타이머를 제공하여 건강한 디지털 기기 사용 습관을 형성하도록 돕습니다.

### 목표 사용자

* 하루 종일 코딩을 하거나 모니터를 응시하는 개발자 및 학생
* 화면 집중으로 인해 무의식적으로 눈 깜빡임 횟수가 줄어드는 사람
* 별도의 복잡한 설치 없이 웹 브라우저만으로 안구 건강을 관리하고 싶은 사람

### 핵심 기능 요구사항

웹캠이 연결되어 있고 접근 권한이 허용된 경우 활성화됩니다.

#### 1. 실시간 눈 깜빡임 트래킹 및 통계
- 총 눈 깜빡임 횟수와 최근 1분 환산 깜빡임 빈도(BPM)를 계산하여 현재 눈 상태가 양호한지, 의식적인 깜빡임이 필요한지 직관적인 대시보드로 보여줍니다.
#### 2. 맞춤형 안구 건조 경고 시스템
- 사용자가 설정한 시간(예: 10초) 동안 눈을 깜빡이지 않으면 화면이 붉게 점멸하며 알림음이 발생해, 즉각적으로 눈을 깜빡이도록 유도합니다.
#### 3. 강력한 졸음 방지 알람
- 사용자가 3초 이상 눈을 감고 있는 것을 감지하면, 즉각적으로 긴급한 경고음과 함께 화면이 보라색으로 점멸하여 졸음을 쫓아냅니다.
#### 4. 개발자 친화적 UI & 다크 모드
- 주변 조도나 개발 환경에 맞게 원클릭으로 라이트/다크 모드를 전환할 수 있으며, 프라이버시를 위해 카메라 화면을 숨기는 기능도 제공합니다.


### 구현 및 프로그래밍 제약 조건

* AI 도구 제한: 오직 Gemini Canvas만을 사용하여 코드를 생성하고 다듬습니다. 다른 AI 코딩 어시스턴트는 사용하지 않습니다.
* 프롬프트 엔지니어링 훈련: 직접 코드를 짜기보다, 프롬프트의 제약 조건과 지시어만으로 유용한 앱을 완성하는 것을 목표로 합니다.
* 기술 스택: HTML5, CSS3, JavaScript만 사용합니다. 
    * React등 어떠한 프론트엔드 프레임워크나 빌드 도구도 사용하지 않습니다.
