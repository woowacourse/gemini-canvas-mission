# 🚀 우아한 성장 트래커 [🔗](https://gemini.google.com/share/0b1e364c3ea2)

> "단순한 미션 제출을 넘어, 엔지니어링 사고의 궤적을 기록하다!"
>
> 미션 설계 의도 분석과 AI 심층 피드백으로 완성하는 나만의 성장 로그

### 📋 프로젝트 소개

우아한 성장 트래커는 우아한테크코스의 방대한 미션 요구사항 속에서 핵심 설계 의도를 추출하고, 학습자의 고민이 담긴 회고를 분석하여 성취도를 정밀하게 측정하는 AI 기반 성장 관리 서비스입니다.

단순히 기능을 구현했는지 확인하는 수준을 넘어, 출제자가 의도한 '성장 포인트'를 얼마나 깊이 있게 고민했는지 객관적인 지표로 확인하고, AI 코치의 시선으로 분석된 맞춤형 피드백을 통해 자기주도적인 학습 경험을 제공받을 수 있습니다.

### ✨ 핵심 기능

1. **AI 미션 설계 의도 추출 시스템**

- README 심층 분석: 미션 요구사항 텍스트를 입력하면 Gemini 2.5 Flash API가 해당 미션의 본질적인 설계 의도와 핵심 학습 목표를 도출합니다.

- 카테고리별 성장 포인트: 객체지향, 테스트 코드, 클린 코드 등 프론트엔드 엔지니어로서 갖춰야 할 역량 카테고리를 자동 분류하여 구체적인 성장 요구사항을 제시합니다.

- 멀티 인풋 매니지먼트: 복잡한 미션 내용을 효과적으로 관리할 수 있도록 README 분할 업로드 및 실시간 제목 동기화 기능을 제공합니다.

2. **AI 기반 심층 성취도 평가 리포트**

- 회고록 대조 분석: 학습자가 작성한 회고록을 미션 목표와 대조하여, 단순히 정답을 맞혔는지가 아닌 '어떤 고민과 시도를 했는지'를 문장형으로 분석해 줍니다.

- 성장의 증거 발견: 코드와 고민 속에 녹아든 기술적 가치를 찾아내어 강점으로 정의하고, 보완이 필요한 지점을 엔지니어링적 관점에서 날카롭게 피드백합니다.

- Next Step 가이드: 분석 결과를 바탕으로 다음 단계의 성장을 위해 도전해볼 만한 구체적인 학습 방향과 액션 아이템을 제안합니다.

3. **데이터 시각화 & 인터랙티브 대시보드**

- 나의 성장 곡선: Chart.js를 활용하여 미션별 성취 점수의 변화 추이를 꺾은선 그래프로 시각화하여 역량의 우상향 곡선을 한눈에 파악할 수 있습니다.

- 미션 아카이빙: 평가가 완료된 미션은 '잠금(Lock)' 처리되어 수정이 제한되며, 학습의 궤적을 온전히 보존하는 나만의 포트폴리오 자산이 됩니다.

4. **사용자 중심의 몰입형 UX/UI**

- 반응형 사이드바: 수많은 미션 목록을 간편하게 탐색하고 관리할 수 있는 최적화된 내비게이션 환경을 제공합니다.
