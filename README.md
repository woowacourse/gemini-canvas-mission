# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.


## 🚀 앱 세부 설명

Gemini AI를 활용한 유틸리티부터 학습 도구까지, 총 4종의 웹 애플리케이션 프로젝트입니다.

### 🍴 1. 먹을래 말래 (유틸리티 앱)
> **"결정 장애 해결을 위한 스마트 메뉴 큐레이터"**
- **주요 기능:** 선택지가 너무 많거나 없을 때, 심리 분석형 질문을 통해 최적의 메뉴를 도출합니다.
- **AI 테크:** 사용자 선호도 분석 및 메뉴 추천 로직에 Gemini AI 활용.

링크 : https://gemini.google.com/share/306ca58447e8

### 💣 2. 눈치게임 : 이름편 (게임 앱)
> **"아이스브레이킹을 위한 초스피드 이름 퀴즈"**
- **주요 기능:** 팀원들의 이름을 재미있고 빠르게 외울 수 있도록 돕는 게임형 유틸리티입니다.
- **AI 테크:** 5초 타임어택과 위치 기반 퀴즈로 긴장감 넘치는 상호작용 제공.

링크 : https://gemini.google.com/share/7f62e4a2d6f4

### 🏗️ 3. 구조 연습장 (학습 앱)
> **"Android MVVM 설계가 어려울 때 찾는 구조 가이드"**
- **주요 기능:** 아이디어만 입력하면 복잡한 계층 구조(View-VM-Model)를 시각적인 카드로 설계해 줍니다.
- **AI 테크:** 앱 요구사항 분석 및 아키텍처 파일 구조 자동 생성.

링크 : https://gemini.google.com/share/09ab6c66fa40

### 🔗 4. 토끼 상담사 (페어)
> **"AI와 함께 완성하는 협업적 아이디어 빌딩"**
- **주요 기능:** 사용자가 고민이나 아이디어를 입력하면, 토끼 상담사가 질문을 던지며 생각을 정리해줍니다.
- **AI 테크:** 대화 맥락을 유지하며 질문 생성.

링크 : https://gemini.google.com/share/f70765264b1b
