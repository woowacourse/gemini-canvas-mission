### 이 앱을 만든 이유

> **어떤 문제/불편함을 해결하려고 했나요?**

유튜브 쇼츠, 릴스, 블로그 등에서 유용한 레시피를 발견하더라도 막상 요리를 할 때는 다시 찾기 번거롭고, 불필요한 서론과 잡담이 길어 실제 필요한 정보(재료, 조리 순서)만 빠르게 확인하기 어렵다는 문제를 해결하고자 했습니다.
또한, 요리 중 젖은 손으로 스마트폰을 조작하다 화면이 꺼지거나 스크롤이 불편해지는 상황을 개선하려 했습니다.

> **본인이 이 앱을 언제, 어떻게 사용할 건가요?**

냉장고에 자투리 재료가 남아 무엇을 해 먹을지 고민될 때 '냉장고 파먹기' 기능을 통해 아이디어를 얻고, 실제 주방에서 요리할 때는 스마트폰을 거치해 둔 뒤 제스처 스와이프로 넘겨볼 수 있는 '요리 모드'를 켜서 사용할 예정입니다.

### 주요 기능

- **레시피 스크랩 및 아카이빙:** URL(유튜브, 블로그 등)을 입력하면 요리 제목, 재료, 순서를 추출해 저장
- **요리 시인성 최적화 모드 (요리 모드):** 화면 꺼짐 방지가 적용되며, 젖은 손으로도 조작하기 쉬운 큰 폰트와 좌우 스와이프 제스처를 지원
- **사용자 커스텀 관리:** AI 추출 레시피를 자유롭게 수정하고, 원하는 카테고리로 분류 및 재료명으로 검색 가능

### AI 기능

> **어떤 AI 기능을 추가했나요?**

- Gemini API(gemini-2.5-flash)를 활용한 텍스트/URL 파싱 기능
- 사용자의 보유 재료 기반으로 새로운 레시피를 생성하는 기능 (LLM)

> **AI 기능이 앱에서 어떤 역할을 하나요?**

- 긴 블로그 글이나 영상 스크립트에서 불필요한 문맥을 제거하고, 핵심적인 요리 데이터(제목, 재료 목록, 조리 순서)만 규격화된 JSON 형태로 정제하여 반환
- 사용자가 입력한 '보유 재료'와 '원하는 요리 스타일'을 조합해 맞춤형 레시피를 즉석에서 창작

### 이 앱을 만든 이유

유명 러닝 액션 게임인 '템플런(Temple Run)'에서 영감을 받아, 신스웨이브(Synthwave)와 우주를 테마로 한 3D 런 게임을 제작했습니다.

### 주요 기능

- **동적 3D 트랙 및 장애물 생성:** 플레이어의 진행에 따라 곡선 트랙, 코인, 그리고 다양한 패턴의 장애물이 무작위로 자동 생성됩니다.
- **점수 비례 난이도 및 환경 변화:** 1,000점을 획득할 때마다 게임 속도가 점진적으로 증가하며, 배경과 트랙의 네온 컬러 테마가 변경되어 레벨업을 시각적으로 체감할 수 있습니다.
- **명예의 전당:** 실시간으로 상위 5명의 랭킹을 집계하고 보여줍니다.
- **랜덤 닉네임 생성기:** 닉네임 입력에 고민하는 유저 편의성을 위해 '형용사+명사' 조합의 재치 있는 무작위 닉네임을 자동 생성합니다.

### 이 앱을 만든 이유

> **어떤 문제/불편함을 해결하려고 했나요?**

프론트엔드 개발 중 이벤트 루프의 동작 원리나, Next.js의 렌더링 전략 등 추상적이고 복잡한 개념들을 단순히 읽는 것에 그치지 않고, 동작 과정을 단계별 애니메이션으로 시각화하여 프론트엔드 개발의 핵심 '멘탈 모델'을 빠르고 정확하게 구축하고자 했습니다.

> **본인이 이 앱을 언제, 어떻게 사용할 건가요?**

- 새로운 비동기 라이브러리를 사용하거나 복잡한 API 호출 로직을 설계할 때 이벤트 루프의 우선순위를 재확인하기 위해 사용
- Next.js 프로젝트 설정 시 서비스 성격에 맞는 최적의 렌더링 전략(SSR/SSG/ISR)을 결정하기 위한 가이드로 활용
- 추후 기술 면접 준비 시 핵심 개념을 다시 한번 리마인드하는 복습 도구로 활용

### 주요 기능

- **Next.js 렌더링 플로우 애니메이션:** SSR, SSG, ISR 각 방식에 따른 브라우저-서버-백엔드 간의 데이터 이동과 캐싱 과정을 실시간 패킷 애니메이션으로 구현했습니다.
- **이벤트 루프 단계별 시뮬레이터:** 특정 코드 예제가 실행될 때 Call Stack, Web API, Microtask/Task Queue의 상태 변화를 한 줄씩 추적하며 학습할 수 있습니다.
- **인터랙티브 타임라인:** 유튜브처럼 타임라인의 특정 지점을 클릭하여 원하는 단계의 동작을 즉시 확인할 수 있는 탐색 기능을 제공합니다.
- **상세 기술 가이드 제공:** 각 단계별 동작에 대한 구체적인 텍스트 설명을 병행하여 시각적 인지와 이론적 이해를 동시에 돕습니다.

> **어떤 문제/불편함을 해결하려고 했나요?**

온보딩 연극 미션 시 상대방 대사를 쳐줄 파트너가 없으면 타이밍을 맞추거나 실전처럼 연습하기 어렵다는 문제를 해결하고자 했습니다. 혼자서도 상대방과 호흡을 맞추며 자연스럽게 연습할 수 있는 환경이 필요했습니다.

온보딩 연극 미션을 위해 혼자 시뮬레이션 연습 때 사용할 예정입니다.

### 주요 기능

- **대본 자동 분리 및 편집 (에디터):** 정제되지 않은 대본 텍스트를 붙여넣으면 캐릭터와 대사를 자동으로 분류해 줍니다. 드래그 앤 드롭으로 대사 순서를 손쉽게 변경하거나 직접 텍스트를 수정 및 추가할 수 있습니다.
- **상호작용형 연습 모드 (롤플레잉):** 본인이 연기할 역할을 선택하면 해당 차례에는 음성 재생이 멈추고 직접 대사를 칠 수 있도록 대기합니다. 내 대사가 끝난 후 스페이스바를 누르면 상대방 차례의 대사가 이어서 재생됩니다.

### AI 기능

> **어떤 AI 기능을 추가했나요?**

- Gemini 2.5 Flash (Text): 비정형 텍스트 대본 구조화 기능
- Gemini 2.5 Flash TTS (Audio): 텍스트 음성 변환 기능

> **AI 기능이 앱에서 어떤 역할을 하나요?**

- **대본 파싱:** 사용자가 대략적인 대본 텍스트를 입력하면, AI가 문맥을 파악해 지문을 제외하고 실제 읽을 대사와 화자(캐릭터)를 JSON 형태로 정확히 분리 및 매핑
- **AI 파트너 음성 지원:** 연습 모드 진행 시, 내가 아닌 다른 캐릭터들의 대사를 각기 다른 AI 보이스로 실시간 생성하여 읽어줌으로써 실제 상대방과 대화하는 듯한 환경을 제공
