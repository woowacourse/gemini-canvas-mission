Stream API 완벽 파헤치기

인터랙티브 요소를 통해 스트림의 파이프라인과 다양한 메서드를 직접 체험해 보세요.

1. 파이프라인 흐름도 (Stream Pipeline)

스트림은 크게 데이터 소스(생성) ➔ 중간 연산(가공) ➔ 최종 연산(결과 도출)의 파이프라인으로 구성됩니다.
중간 연산은 여러 번 연결할 수 있으며, 최종 연산이 호출되어야 비로소 모든 계산이 실행됩니다(지연 연산).

① 생성

List.stream()
1
2
3

② 중간 연산

.filter(n -> n % 2 != 0)

③ 최종 연산

.collect(toList())

2. 중간 연산 (Intermediate Operations)

데이터를 원하는 형태로 가공합니다. 버튼을 클릭하여 원본 스트림 데이터가 어떻게 변환되는지 확인하세요.

현재 스트림 상태

3. 최종 연산 (Terminal Operations)

최종 연산을 호출하면 스트림이 닫히며(소비되며) 최종 결과를 반환합니다. 결과를 도출한 스트림은 회색으로 변하여 재사용할 수 없음을 나타냅니다.
