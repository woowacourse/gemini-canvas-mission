### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
 	- 우아한테크코스에 참여하는 크루들이 교육을 담당하는 여러 코치진의 얼굴과 닉네임을 빠르게 익히는 데 도움을 주고자 만들었습니다. 단순 암기가 아닌 퀴즈 형식을 통해 재미있게 정보를 습득할 수 있도록 하였습니다.

- 이 앱을 언제, 어떻게 사용할 건가요?

### 주요 기능

- 기능 1: 코치님들 이미지 업로드
- 기능 2: 시간 제한 및 객관식과 주관식 중 하나 선택 가능
- 기능 3: 남는 시간에 따라 상이한 힌트 제공
 	- level 1 : 코치 소개 문구
 	- level 2 : 글자 수
 	- level 3 : 초성 힌트
