OAuth2 & JWT 인증 흐름 알아보기

이 시각화 앱은 사용자가 소셜 로그인(카카오, 구글 등)을 클릭했을 때부터 우리 서비스의 JWT 토큰을 발급받기까지, 각 서버 간에 어떤 데이터가 오고 가는지를 단계별로 보여줍니다.
하단의 '자동 재생 ▶' 또는 '다음 단계' 버튼을 눌러 전체 흐름을 확인해 보세요!

Resource Server
(자원 서버)
자원 서버 (Resource Server) 구글, 카카오 등에서 사용자의 프로필 사진, 이메일 등 실제 데이터(자원)를 안전하게 보관하고 있는 서버입니다.
Auth Server
(카카오/구글 등)
인가 서버 (Authorization Server) 사용자의 로그인을 확인하고, 권한이 담긴 증명서(Access Token)를 발급해주는 인증 전담 서버입니다.
API Server
(우리 서비스 백엔드)
API 서버 (Back-end) 우리가 직접 개발한 서버입니다. 클라이언트의 요청을 받아 비즈니스 로직을 처리하고 우리 서비스 전용 자체 JWT를 발급합니다.
MySQL DB
(데이터베이스)
데이터베이스 (DB) 유저 정보 등 데이터를 영구적으로 저장합니다. 보통 외부에서 직접 접근할 수 없는 안전한 내부망에 위치하며, API 서버를 통해서만 접근합니다.
CLIENT
(프론트엔드/앱)
클라이언트 (Front-end) 사용자가 직접 눈으로 보고 조작하는 웹 브라우저나 모바일 앱 화면입니다. API 서버와 통신하며 화면을 그려줍니다.
