```
너는 웹앱 개발 전문가 AI 어시스턴트야. 나는 이번에 웹앱을 하나 개발할거야.

기술 스택은 HTML/CSS/JavaScript만을 활용해서 개발할거야. 그리고 다른 기술 스택을 절대로 사용해서는 안돼.

내가 만들고 싶은 것은 "집중 시간 체크 서비스"야.

애플리케이션의 기능은 다음과 같애.
1. 집중하고 싶은 시간을 설정할 수 있어. 하지만 직접 시간 입력이 되는 것이 아니라 선택하는 방식이야.
2. 선택하는 방식은 대한민국 KTX 기차표 느낌으로 서울 -> 부산 가는 시간만큼 집중. 부산 -> 대전 가는 시간만큼 집중. 이런 식으로 대한민국 지도를 보여준 다음 출발역과 도착역을 선택할 수 있도록 하는거야.
3. 여기서 추가적으로 종요한 점은 원래 KTX는 서울에서 부산 갈 때 여러 역을 거쳐서 가는 데 해당 서비스는 단순 직행이야. end to end로 시간을 만들거고, 여러 역을 걸쳐서 갈 수 있도록 추가할 수 있어. 예를 들어 부산 -> 서울 -> 대전 이렇게 선택할 수 잇는데, 이러면 부산 -> 서울 가는 시간과 서울 -> 대전이 합친 시간이 집중 시간이 되는거야.
4. 집중 시간이 선택되고 나면, 집중 UI는 대한민국 지도 위에서 추상화된 기차 이모지를 올려놓고, 시간안에 가는 모습을 보이고 싶어.

6. 도착이 완료됐다면 내 기차 여행(집중 시간)을 볼 수 있는 목록도 있으면 좋겠어.

디자인은 우아한 테크코스 느낌을 많이 났으면 좋겠어. 디자인에 수정 사항이 필요하다면 더 프롬프트를 줄게.

  - 운행 종료 버튼 클릭 시 아무 동작이 하지 않았습니다.
  - 거리 별로 시간이 정확하지 않았습니다. `서울 -> 대구가 30분, 서울 -> 광주가 30분` 이런 식으로 목적지마다 예상 시간이 제대로 적용되지 않았습니다.
  - 집중 시간을 측정할 때 지도 위에서 기차가 움직이듯이 만들고 싶었는데, 지도가 블러 처리되면서 새로운 창에서 집중 시간이 나타났습니다.

    ```
    ```

    ```
    ```

    ```

    ```
    ```

### 3. 효과적이었던 프롬프팅 전략

- 어떤 방식으로 요청했을 때 원하는 결과가 나왔나요?
  -  내가 생각한 요구사항을 매우 구체적으로 프롬프트를 작성했을 떄 원하는 결과를 얻을 수 있었습니다.
- 반대로 효과가 없었던 방식은 어떤게 있었나요?
  - 수행되지 않는 요청을 반복적으로 요청하거나 추상적으로 프롬프트를 작성했을 때 효과가 없었습니다.

### 4. 배운 점
- 최대한 구체적으로 작성하는 것이 중요하다는 것입니다.
  - 추가 요구사항을 적용할 때 `운행 중(집중 중) 3가지 음악이 사용되도록 넣고 싶어`로 프롬프트를 작성하였는데, 제가 생각한 것은 `집중 시간이 흘러갈 때 세 가지 음악을 사용자가 선택해서 변경할 수 있다`고 생각했습니다. 하지만 AI는 경로를 추가할 때 어떤 음악으로 갈지 선택하도록 만들어주었습니다. 다시 프롬프트를 봤을 때 제가 AI에게 요구했던 것이 생각보다 구체적이지 않았다는 것을 깨닫게 되었습니다.
- Gemini Canvas를 효과적으로 사용하기 위한 나만의 팁이 있다면?
  - 같은 세션에서 요구사항 적용이 실패한 작업에 대해 세 번 이상 반복해서 적용해달라고 요청하지 않기입니다. `운행 종료 로직 추가`를 위해 여러 번 새로운 프롬프트를 주었는데, 로직 적용이 계속 실패했습니다. 반복적으로 `운행 종료 로직이 현재 어떻게 돌아가고 있는지 분석하고 다시 적용해`와 같이 주었는데 이후부터는 AI가 해당 로직뿐만 아니라 다른 로직, 디자인 모두를 건드는 상황에 이르게 되었습니다. 그래서 이전 버전으로 되돌린 다음 새로운 세션에서 다시 운행 종료 로직 요구사항을 요청하였는데, 한 번에 적용하는 것을 볼 수 있었습니다. 그래서 수행되지 않는 요청을 반복적으로 하면 AI가 이상해진다는 것을 알 수 있었습니다.

### 5. 리뷰어에게 피드백 받고 싶은 포인트
- AI 사용 일지 초기 프롬프트에서 개선이 필요한 곳을 알고 싶습니다.
  1. 구체적으로, AI 역할 부여, 내가 만들고 싶은 것, 구현할 기능을 하나의 프롬프트를 작성할 때 AI가 잘 이해하도록 개행을 통해 나누었는데, AI가 더 잘 나눠서 구별하는 방법이 있을지 궁금합니다.
- 첫 번째 유틸리티 앱(`우아한 몰입 열차`)에서 추가되면 좋을 기능이 있는지 궁금합니다.
