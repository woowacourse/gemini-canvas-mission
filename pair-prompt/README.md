### 이 앱을 만든 이유
학습을 하는 경우 공부를 했지만, 이를 따로 내재화시키지 않으면 머릿속에 장기기억으로 저장되지 않는 문제점이 있습니다. 따라서 개인이 학습한 내용에 대해서 점검할 필요가 있었습니다.

따라서 CS학습을 위해 공부한 내용을 개인 맞춤형으로 테스트하고 싶다는 서로의 니즈를 반영하여, CS 학습 퀴즈 애플리케이션을 구축하였습니다. 

또한, 문제를 풀다 추가적인 학습 및 기억이 안 나는 경우에 다시 공부를 하는 대신 정돈되지 않은 지식들을 머릿속에서 스스로 내재화시킬 수 있도록 "소크라테스 챗봇"을 구축하였습니다. 사용자는 "소크라테스 챗봇"을 이용하여 더 깊게 생각해보고 고민해볼 수 있습니다.

#### 목표
사용자의 수준에 맞춘 적절한 난이도의 CS 문제를 출제하고, 사용자가 학습한 분야에 대해서만 학습하는 것이 목표입니다. 또한, 퀴즈를 통해 정돈되지 않는 학습된 내용을 장기기억으로 전환하는 것을 돕습니다.

#### 언제 사용할까요?
- 특정 학습을 진행한 이후에 개념 및 원리에 대해서 정리하고 싶을 때
- 공부를 했는데, 막상 기억에 남는 것이 많지 않을 때

#### 어떻게 사용할까요?
1. 공부를 한 이후 대목차와 세부 목차를 선택한 뒤, 세부사항을 서술형을 적습니다. (본인이 공부한 것 및 테스트하고 싶은 것)
2. AI가 문제를 생성해주면 문제를 풉니다.
3. 생각이 안 나거나 깊이 학습하고 싶다면 소크라테스 챗봇 버튼을 이용하여 산파술을 통해 정답을 도출하거나 부족한 부분을 학습합니다.

### 주요 기능
#### 기능 1
- 데이터베이스/운영체제/네트워크 등 대목차와 세부 목차, 난이도를 선택하면 Gemini AI가 O/X, 4지선다 객관식, 주관식을 적절히 섞어 총 10문제를 자동 생성합니다.
#### 기능 2
- 문제 풀이 중 모르는 부분이 생기면 챗봇에게 질문할 수 있으며, 챗봇은 정답을 직접 알려주지 않고 사용자가 스스로 답을 도출할 수 있도록 질문으로 유도합니다.

### AI 기능
#### 어떤 AI 기능을 추가했나요?
- Gemini AI를 활용한 퀴즈 문제 자동 생성 + 소크라테스 문답법 기반 챗봇

#### AI 기능이 앱에서 어떤 역할을 하나요?
- 사용자가 선택한 주제, 난이도, 추가로 학습하고 싶은 내용을 바탕으로 오류 없는 퀴즈를 생성하고, 챗봇은 학습자가 막히는 지점에서 “왜 그렇게 생각하나요?“, “그렇다면 이 상황에서는 어떻게 될까요?” 같은 방식으로 깊이 있는 사고를 이끌어냅니다.

디자인패턴
생성 패턴 (Creational) - 5가지
- Singleton - 인스턴스를 하나만 생성
- Factory Method - 서브클래스가 어떤 객체를 생성할지 결정
- Abstract Factory - 관련된 객체들의 패밀리를 생성
- Builder - 복잡한 객체를 단계적으로 생성
- Prototype - 기존 객체를 복사해서 생성

구조 패턴 (Structural) - 7가지
- Adapter - 호환되지 않는 인터페이스를 연결
- Bridge - 추상화와 구현을 분리
- Composite - 트리 구조로 부분-전체 계층을 표현
- Decorator - 객체에 동적으로 기능 추가
- Facade - 복잡한 서브시스템에 단순한 인터페이스 제공
- Flyweight - 공유를 통해 많은 객체를 효율적으로 지원
- Proxy - 다른 객체에 대한 대리/접근 제어

행동 패턴 (Behavioral) - 11가지
- Chain of Responsibility - 요청을 처리할 수 있는 객체를 체인으로 연결
- Command - 요청을 객체로 캡슐화
- Interpreter - 언어의 문법을 클래스로 표현
- Iterator - 컬렉션 요소에 순차적으로 접근
- Mediator - 객체 간 상호작용을 중재자가 담당
- Memento - 객체의 상태를 저장/복원
- Observer - 상태 변화 시 의존 객체들에게 자동 통지
- State - 내부 상태에 따라 행동을 변경
- Strategy - 알고리즘을 캡슐화해서 교체 가능하게
- Template Method - 알고리즘의 뼈대를 정의하고 세부 구현은 서브클래스에 위임
- Visitor - 객체 구조와 처리 로직을 분리

## 추가 프롬프트
### 1.
서술형 문제의 경우에는 Gemini AI한테 물어봐서 채점이 되게 하고싶어. 현재는 텍스트가 정확히 일치하지 않는 경우에는 오답이야. 예를 들어 정규화가 답인데, 정규화입니다. 라고 말하면 틀리고 있어. 이를 고쳐줘.

### 2.
너가 구현한 애플리케이션에서 조금 더 보완하고 싶은 부분을 알려줄게. 아래 내용대로 수정해줘.

1. 첫 화면에서 난이도 선택 아래에 문제 개수도 사용자가 직접 선택할 수 있으면 좋겠어. 10개를 기본으로 해놓고, -, +버튼으로 개수를 조절할 수 있으면 좋겠어.
2. 대목차, 소목차와 문제에서 띄어쓰기 잘못된 부분 있으면 수정해줘.
3. 대목차, 소목차 범위를 30% 반영하고, 사용자가 직접 입력한 추가 학습 사항을 70% 반영해서 문제를 출제해줘.

### 3.
현재 메인 페이지에서 추가 학습 사항을 반영하는 곳에 “(중요도 70%)“라고 써져있어. 또한, 마지막 페이지인 문제를 다 풀었을 때 보여주는 페이지에서도 “(적극 반영됨)“이라는 문구가 있어서 UX를 해치고있어. 이를 해결해줘.

### 4.
정답 및 오답 시 나오는 O, X 아이콘이 나타난 뒤로 3초동안 서서히 사라지게 UI 수정해줘

### 5.
[개요]

구현한 애플리케이션에 새로운 기능을 추가하고 싶어. 너는 지금부터 AI 챗봇 개발 전문가야. Gemini AI를 활용해 소크라테스 챗봇을 만들어줘. 사용자가 문제를 풀 때 궁금한 점이나 헷갈리는 점이 있을 때 스스로 결론에 도달할 수 있게끔 소크라테스 문답법 기반인 소크라테스 챗봇을 구현한 애플리케이션에 적용해줘.

[핵심 기능]
- 챗봇 버튼을 눌렀을 때 반투명 배경으로 바꾼 뒤 인포그래픽으로 기본 기능에 대해서 설명해주는 튜토리얼이 있어야 한다.
- 챗봇 버튼을 누르면 채팅창이 떠야한다.
- 챗봇의 답변은 사용자가 한 눈에 이해할 수 있도록 4줄 이하로 해야한다.

[목표 사용자]
- 학습 내용에 대한 깊이가 부족한 사용자
- 추가적인 학습을 하고싶은 사용자

[추가 요구사항]
- 튜토리얼은 화살표(인포그래픽)로 단계별로 챗봇 사용법을 알려줘야 한다.
- 챗봇의 말투는 시니어 개발자 멘토처럼 해줘.

[디자인 요구사항]
- 화면 오른쪽 하단에 로봇 모양 아이콘을 만들어줘.
- 채팅 화면은 카카오톡 형태와 비슷하게 하되, 그 외 모든 UI는 토스 UI와 동일하게 해줘.
- AI가 말하고 있을 때 (로딩 중) 말풍선에 “…”에서 “.” 이 하나씩 움직여서 인터렉티브하게 보였으면 좋겠어.
- 채팅창 크기는 화면을 가로 세로로 6등분을 해서 맨 우측 하단에 영역만큼의 크기로 해줘.

[제한 및 금지 구현 조건]
- 기존 애플리케이션은 변경사항 없이 그대로 유지하되, 새로운 기능을 추가한다.
- 챗봇은 절대 정답은 얘기하지 말고, 사용자가 스스로 정답을 찾을 수 있도록 질문만 해야한다.

### 6.
[현재 문제 및 수정사항]
- 현재 버튼을 누를 때마다 전체 화면이 깜빡거리는 문제가 발생하고 있으니 이를 해결해줘.
- 현재 챗봇 채팅방 화면 디자인이 카톡이랑 똑같은데, 카톡 메시지의 색상과, 채팅방 화면의 색상을 토스 UI에 맞춰서 수정해줘.
- 현재 챗봇의 채팅창의 제목 부분에 이모지가 들어가있는데, 이 이모지를 삭제해줘.
- 매 문제마다 채팅내역이 자동으로 초기화되도록 해줘.
- 챗봇 systemPrompt에 현재 해당하는 문제도 함께 AI에게 전달되어, 사용자의 질문에 맞는 더 정확한 답변을 반환하도록 해줘.
