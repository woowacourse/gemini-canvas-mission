# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

# 📄 유틸리티
## 앱 이름: 스터디 타이머
할 일 목록 관리와 시간 측정을 한 화면에서 해결하세요. 
스톱워치와 타이머를 동시에 활용해 학습 몰입도를 극대화하고, 오늘 하루의 집중된 시간을 시각적으로 확인하며 성취감을 느껴보세요.

# 💻 게임
## 앱 이름: 픽셀 점프 킹
복잡한 생각에서 벗어나 오직 위로 올라가는 것에만 집중해 보세요.
공부나 업무 중 짧은 휴식이 필요할 때 최고의 리프레시를 선사합니다.

# ✏️ 학습 앱
## 앱 이름: Compose master
자투리 시간을 활용해 Android Compose에 대한 퀴즈를 풀고 상세한 해설을 확인하며 실력을 탄탄하게 다져보세요.

# 🤝 페어 프롬프트 릴레이
## 앱 이름: 리뷰 딸깍
사진 한 장과 별점만으로 정성스러운 리뷰 초안을 순식간에 완성합니다.
글 쓰기 고민 없이 빠르게 텍스트를 생성하고 복사하여 리뷰 이벤트 참여의 번거로움을 해결해 보세요.
