# 🧩 Sudoku

**Sudoku**는 바닐라 자바스크립트(Vanilla JS)와 Tailwind CSS를 활용하여 제작된 세련되고 현대적인 웹 기반 스도쿠 게임입니다.  
사용자 친화적인 UI와 강력한 편의 기능을 통해 프리미엄 퍼즐 경험을 제공합니다.

---

## ✨ 주요 특징

### 🎯 4가지 난이도 제공
- 쉬움
- 보통
- 어려움
- 전문가  

자신의 실력에 맞는 모드를 선택하여 도전할 수 있습니다.

---

### 👁 정답 보기 기능 (제한적)
- 현재 선택한 칸의 정답 확인 가능
- 게임당 최대 **3회 제한**
- 전략적 사용이 필요한 긴장감 있는 시스템

---

### 📝 메모 모드
- 실제 종이 스도쿠처럼 후보 숫자 메모 가능
- 숫자를 다시 누르면 메모 삭제

---

### 🎨 스마트 하이라이트 기능
- 선택한 칸의 **행, 열, 3x3 박스 강조**
- 동일한 숫자가 입력된 다른 칸 자동 강조

---

### ⏱ 실시간 타이머
- 퍼즐 해결 시간 측정
- 기록 단축을 통한 도전 요소 제공

---

### 📱 반응형 디자인
- 데스크톱 & 모바일 최적화
- 다양한 화면 크기에서 자연스러운 레이아웃

---

## 🎮 게임 방법

### 1️⃣ 시작하기
난이도를 선택한 후 게임 시작  
빈칸을 클릭하여 선택합니다.

---

### 2️⃣ 숫자 입력
- 하단 숫자 패드 클릭
- 키보드 숫자 키(1-9) 입력 가능

---

### 3️⃣ 메모하기
- **메모 모드 활성화 후 숫자 입력**
- 작은 숫자로 후보 기록
- 다시 누르면 삭제

---

### 4️⃣ 지우기
- 지우개 버튼 클릭
- 또는 `Backspace` / `Delete` 키 사용

---

### 5️⃣ 정답 찬스
- 막힌 칸에서 **정답 보기 버튼 사용**
- 총 3회 제한

---

### 🏆 승리
모든 빈칸을 올바르게 채우면  
🎉 승리 화면과 함께 게임 종료

---
