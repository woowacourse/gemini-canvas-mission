### 💡 이 앱을 만든 이유

**어떤 문제/불편함을 해결하려고 했나요?**
우아한테크코스 본과정을 준비하며, 오랫동안 사용하던 Windows 노트북에서 Mac으로 기기를 변경했습니다. 하지만 과정이 순탄치 않았습니다. 기존 윈도우 단축키와 Mac의 단축키 체계가 너무 달랐고, 사소한 텍스트
커서 이동조차 마음대로 되지 않아 적응에 큰 어려움을 겪었습니다.
이에 저처럼 **"평생 윈도우만 쓰다가 맥으로 처음 넘어온 사용자(맥린이)"**들이 가장 헷갈려 하는 단축키와 OS 차이점을 눈으로만 보는 것이 아니라, **직접 눌러보며 손으로 빠르게 체득**할 수 있도록 돕기
위해 이 유틸리티 앱을 기획하게 되었습니다.

**이 앱을 언제, 어떻게 사용할 건가요?**

- Mac을 처음 구매한 날, OS의 기본적인 차이점과 필수 키보드 매핑을 학습할 때 가이드북처럼 사용합니다.
- 개발 환경(IntelliJ)이나 텍스트 편집 시 내가 모르는 유용한 단축키를 몸으로 익히고 싶을 때 '훈련소' 탭에 들어가 반복 연습합니다.
- Mac 사용 중 모르는 기능이 생겼을 때 바로바로 검색하거나 AI에게 질문하는 용도로 활용합니다.

### 🚀 주요 기능

- **⌨️ 인터랙티브 단축키 훈련소** - [ Mac 기본 단축키 / 📝 텍스트 편집 / 💻 IntelliJ 단축키 ] 3가지 카테고리를 지원합니다.
    - 사용자가 실제 키보드로 단축키를 입력하면 화면에서 이벤트를 감지하여 정답 여부를 즉각적으로 피드백해 줍니다. (예: 텍스트 편집 탭에서는 실제 타이핑 가능한 에디터 제공)
- **🏷️ 키보드 매핑 (이름표 떼기)**
    - 윈도우의 `Ctrl`, `Alt`, `Backspace` 등이 Mac의 어떤 키에 대응하는지 1:1로 직관적인 UI를 통해 비교해 줍니다.
- **🖥️ OS 핵심 차이점 안내**
    - 프로그램 종료 방식(X 버튼의 차이), 앱 설치 방식(.exe vs .dmg), 마우스 스크롤 방향 등 윈도우 유저가 가장 당황하는 3가지 구조적 차이점을 쉽게 설명해 줍니다.

### ✨ AI 기능 (Gemini API 활용)

본 앱은 구글 Gemini API를 활용하여 맥 초보자들의 학습 효율을 극대화하는 두 가지 AI 기능을 제공합니다.

1. **💡 AI 단축키 암기 꿀팁 (프롬프트 동적 주입)**

- **역할:** 단축키 훈련 중 특정 단축키가 잘 안 외워질 때, "✨ 왜 이 단축키인가요? AI 꿀팁 묻기" 버튼을 누르면 AI가 해당 단축키의 유래나 윈도우 유저 맞춤형 암기 연상법을 1~2문장으로 즉석에서
  생성하여 알려줍니다. (예: "Command + S에서 S는 Save의 약자입니다!")

2. **🤖 AI 맥린이 비서 (자연어 Q&A)**

- **역할:** 앱 내에 내장된 AI 채팅 봇입니다. 시스템 프롬프트를 통해 '친절한 Mac OS 가이드 AI'로 역할을 부여했습니다. 사용자가 "화면 캡처는 어떻게 해?"라고 자연어로 질문하면, 윈도우 사용자의
  눈높이에 맞춰 쉽고 직관적으로 핵심만 답변해 줍니다.
