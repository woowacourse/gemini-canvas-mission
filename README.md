## 🚀 핵심 프로젝트 요약 (Core Apps)

### 1.  네이밍 위저드 (Naming Wizard)
* **개발 동기**: '클린 코드' 철학을 바탕으로 네이밍 과정에서의 결정 피로 해소
* **핵심 기능**:
    * **AI 문맥 분석**: 단순 번역을 넘어 개발자의 의도를 파악한 최적의 변수/함수명 제안
    * **멀티 케이스 지원**: `PascalCase`, `camelCase`, `snake_case` 등 즉시 변환
    * **언어별 컨벤션**: JS, Python, Java 등 각 언어의 고유 스타일 가이드 반영

### 2.  서부의 보안관 (Western Sheriff)
* **개발 동기**: 플래시 게임의 향수와 직관적인 조작감을 통한 스트레스 해소용 스낵 게임 구현
* **핵심 기능**:
    * **무기 성장 시스템**: EXP 획득에 따른 자동 레벨업 (리볼버 → 샷건 → 개틀링 건)
    * **다양한 적 AI**: 건맨, 저격수, 폭탄병 등 5종 이상의 적과 고유 패턴을 가진 보스 레이드
    * **실시간 강화**: 전투 중 드롭되는 무작위 아이템(공격력 강화, 무적 등)으로 전략적 플레이

### 3.  JPA 영속성 컨텍스트 마스터 (JPA Persistence Master)
* **개발 동기**: 변경 감지(Dirty Checking), 1차 캐시 등 추상적인 JPA 메커니즘의 가시화 및 학습 장벽 완화
* **핵심 기능**:
    * **Dirty Checking**: 객체 수정 시 스냅샷 비교를 통한 자동 `UPDATE SQL` 생성 과정 시각화
    * **1차 캐시 시뮬레이션**: 동일 ID 조회 시 SQL 발생 없이 메모리에서 즉시 반환되는 `Cache Hit` 로그 확인
    * **Action Queue(쓰기 지연)**: SQL 저장소에 쌓인 명령들이 `commit()` 시점에 일괄 전송(`flush`)되는 메커니즘 구현

### 4. 인텔리제이 스텔스 러너 (IntelliJ Stealth Runner)
* **개발 동기**: 지루한 수업 시간에 할 수 있는 스텔스 게임 구현

* **핵심 기능**:
  * **Stealth UI Architecture**: 인텔리제이 New UI의 툴바, 프로젝트 트리, 탭 구성을 완벽히 재현하여 원거리 위장 성능 극대화
  * **Java Syntax Obstacles**: 아프리카 동물을 class, new, method 등 실제 자바 문법 형태의 코드로 형상화한 유니크한 장애물 시스템

  * **Real-time Terminal Feedback**: 게임 진행 및 가속에 맞춘 실시간 터미널 로그 출력과 게임 오버 시 Java 스택 트레이스 연출을 통한 컨셉 완성
