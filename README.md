# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

**✅ 제출 체크리스트**

- [x]  4개 웹앱 제출 (유틸리티 앱 1개 + 게임 1개 + 학습 앱 1개 + 페어 프롬프트 릴레이 1개)
- [x]  최소 1개 앱에 Gemini AI 기능 포함
- [x]  모든 앱이 배포 링크로 정상 동작함
- [x]  AI 사용 일지 작성 완료

**이 앱을 만든 이유**

- 어떤 문제/불편함을 해결하려고 했나요?
    - 근력을 성장시키기 위한 핵심 원리는 점진적 과부하라고 생각합니다. 하지만, 이전에 수행한 운동의 세트 수와 중량을 정확히 기록하지 않아, 찜찜한 기분이 든 채로 중량 설정을 했던 경험이 있습니다.
      따라서, 이 앱은 운동 기록을 달력 기반으로 정리하고, 세트, 중량, 반복 횟수를 체계적으로 저장하여 자신의 변화를 한눈에 확인할 수 있도록 돕기 위해 제작했습니다. 단순한 기록을 넘어, 지속적인 성장의 흐름을 관리하는 도구를 만드는 것이 이 앱의 목적입니다.
- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
    - 저는 매일 운동을 할 때마다 해당 앱을 사용하여 세트 수, 중량, 반복 횟수를 기록할 계획입니다.
      기록된 데이터를 통해 이전 운동과 비교하며 중량 증가 여부를 확인하고, 제 자신의 성장 과정을 눈으로 체감하고자 합니다. 운동을 하는 날마다 꾸준히 사용하며 점진적 과부하를 실천하는 데 활용할 예정입니다.

- 날짜별 운동 기록 저장 (캘린더 기반 UI)
- 운동 종목, 세트 수, 반복 횟수, 중량 입력 기능

**🎮 2. 게임**

**앱 이름**

- [사과게임: 점령]

**배포 링크**

https://gemini.google.com/share/28c81923209f

**이 앱을 만든 이유**

- 어떤 문제/불편함을 해결하려고 했나요?
    - 기존의 '사과 게임(숫자 합 10 만들기)'이 단순히 숫자를 지우는 방식이었다면, 여기에 **'땅따먹기'** 요소를 결합하여 전략적인 재미를 더하고자 했습니다. 친구와 로컬에서 대결하거나, 혼자 있을 때 AI와 두뇌 싸움을 즐기고 싶을 때 언제든 브라우저에서 가볍게 실행하여 즐길 수 있습니다.
- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
    - 저는 짧은 휴식 시간이나 이동 시간에 두뇌를 환기시키기 위한 용도로 이 앱을 사용할 계획입니다.
      간단하지만 집중력을 요구하는 게임 특성상, 공부나 작업 중간에 가볍게 플레이하며 사고력을 유지하는 데 활용하고자 합니다.

**주요 기능**

- 직사각형 점령 시스템: 숫자 합이 10인 영역을 드래그하여 자신의 색상으로 점령합니다.
- 소유권 탈취: 내가 선택한 영역 안에 상대방의 칸이 포함되어 있다면, 그 칸의 소유권을 뺏어올 수 있는 역전 시스템을 제공합니다.
- 네 변 인접 규칙: 선택한 직사각형의 가장자리 네 변에 반드시 숫자가 붙어 있어야 한다는 규칙을 적용하여 무분별한 영역 확장을 방지하고 전략성을 높였습니다.
- 패스 및 종료 로직: 더 이상 둘 곳이 없거나 전략적으로 턴을 넘길 수 있으며, 연속 2회 패스 시 게임이 종료되고 점령 칸 수로 승패를 가립니다.

**AI 기능 (해당되는 경우)**

- AI 대전 모드 (Hard Mode): 플레이어가 혼자서도 즐길 수 있도록 AI 대전 기능을 탑재했습니다.
- 최적의 수 탐색: AI는 현재 판에서 가장 많은 칸을 점령할 수 있는 최선의 직사각형 영역을 계산하여 플레이어를 압박하며, 더 이상 둘 수 있는 수가 없으면 스스로 턴을 패스하는 지능적인 판단을 내립니다.

- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
    - 저는 백엔드 개념을 복습하거나 면접을 준비할 때 이 앱을 활용할 계획입니다. 특정 개념이 헷갈릴 경우 인포그래픽을 통해 전체 구조를 다시 확인하고, 이어지는 퀴즈를 통해 이해도를 점검할 생각입니다.

**주요 기능**

- 백엔드 개념 시각화 및 상세 설명 기능
- 개념 확인 퀴즈 기능

**AI 기능 (해당되는 경우)**

- 어떤 AI 기능을 추가했나요?
    - AI 기반 자동 퀴즈 생성 기능을 추가하였습니다. 사용자가 학습한 개념을 기반으로 AI가 새로운 문제와 보기, 해설을 자동으로 생성합니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
    - AI는 단순히 고정된 문제를 제공하는 것이 아니라, 학습 내용에 맞추어 다양한 유형의 퀴즈를 생성하는 역할을 합니다. 이를 통해 사용자는 반복 학습 시에도 새로운 문제를 접할 수 있으며, 암기식 학습이 아닌 개념 이해 중심의 학습이 가능해진다고 생각합니다.

**2. 프롬프트 개선 과정**

- 어떤 식으로 프롬프트를 수정했나요?
    - "Rule 1~4"라는 구체적인 텍스트 가이드를 직접 주어 AI가 말을 바꾸지 못하도록 고정했습니다. 또한, 가장 마지막까지 적용되지 않았던 (Rule 2 의 선택한 직사각형의 네 변에는 각각 최소 하나 이상의 숫자가 영역 안쪽으로 인접해 있어야 합니다.) 부분을 다음과 같이 쉽게 이해할 수 있도록 수정했습니다.

      >
      >
      >
      > “”선택한 직사각형의 네 변에는 각각 최소 하나 이상의 버섯이 영역 안쪽으로 인접해 있어야 합니다.” 이 규칙을 지금 위반하고 있어 직사각형의 마주보는 대각선 방향으로 아무도 점령하지 않은 칸이 최소 1개 존재해야 그 안의 상대 영역을 점령할 수 있어야해

**3. 효과적이었던 프롬프팅 전략**

- 어떤 방식으로 요청했을 때 원하는 결과가 나왔나요?
    -  단계별로 큰 설계 단계를 먼저 정의한 뒤 프롬프팅을 진행하는 것이 효과적이었습니다.
        - 사과 게임 기본 구현 → 새로운 규칙 추가 → 세부 게임 환경 설정 (AI MODE와 2P MODE 분리)
    - 구체적인 텍스트 명시:
        - 규칙을 아주 자세히 설명해줬을 때 가장 효과적이었습니다.
        - 뿐만 아니라, 디자인 같은 부분도 자세히 설명해줘야 제가 원하는 방식으로 결과물이 도출되었습니다.
    - 특정 부분에서 수정이 필요할 때 "이 기능만 수정하고 나머지는 건들지 마"라고 단호하게 요청하는 방식이 효과적이었습니다.
- 반대로 효과가 없었던 방식은 어떤게 있었나요?
    - 처음부터 완벽한 프로그램을 한 번에 만들기 위한 프롬프팅은 오히려 비효율적이었습니다.
        - 원하는 기능을 모두 포함해 한 번에 요청하면 80~90% 수준까지는 빠르게 완성되지만, 이후 100% 완성도로 끌어올리는 과정이 오히려 더 많은 시간과 수정 비용을 요구했습니다.
        - 단계적으로 완성도를 높여가는 방식이 결과적으로 더 효율적이었습니다.
    - 지나치게 잦은 미세 수정 요청은 오히려 부작용을 초래했습니다.
        - 작은 수정 요청을 반복할 경우, 기존에 정상적으로 동작하던 로직이나 규칙 텍스트가 의도치 않게 변경되거나 삭제되는 현상이 발생했습니다.
        - AI의 맥락 유지 한계로 인한 할루시네이션으로 보여집니다.
