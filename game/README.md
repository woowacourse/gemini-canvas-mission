## 앱 이름: 천하제일 사주 배틀
## 카테고리: 게임

### 배포 링크
https://gemini.google.com/share/4554d93f3202

### 이 앱을 만든 이유
- 간단한 대결을 통해 두 사람 중에 승자를 가려내고 싶을 때
- 마침 간단한 사주 풀이, 오늘의 운세도 함께 보고 싶을 때
- 두 사람의 이름과 생년월일로 운세 점수 대결을 펼칠 수 있습니다.


### 주요 기능
- 사주풀이
- 오늘의 운세
- 행운의 아이템 추천
- 운세 점수화를 통한 대결 결과 계산

### AI 기능 (해당되는 경우)

**어떤 AI 기능을 추가했나요?**
- 사주풀이, 오늘의 운세 생성 기능
- 운세에 따른 점수 판단 기능
- 행운의 아이템 추천 기능

**AI 기능이 앱에서 어떤 역할을 하나요?**
- 사주풀이, 운세, 행운의 아이템을 실시간으로 생성하여 간단한 나의 운명을 확인할 수 있습니다.
- 운세 결과에 따라 점수를 판단하므로 예측할 수 없는 승부가 되며, 팔자가 좋지 않은 분도 승리할 희망을 안겨줍니다.
