# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 💻 1. 유틸리티 앱

### 요구사항

발표 자료에 삽입될 일러스트레이션을 생성하는 웹앱을 구현한다.

- 사용자가 스타일을 선택할 수 있도록 한다.
- 사용자가 원하는 이미지를 설명하는 텍스트를 입력받도록 한다.

### 앱 이름
PPT 에셋 생성

### 배포 링크
[PPT 에셋 생성](https://gemini.google.com/share/4f2b8a13fe3f)

### 회고



## 🎮 2. 게임

### 요구사항

2인용 전략 보드게임인 쿼리도를 인공지능과 대결할 수 있도록 구현한다.

- 혼자서 쿼리도를 플레이할 수 있도록 한다.
- 사용자가 난이도를 선택할 수 있도록 한다.
- 차례에 할 수 있는 행동(이동, 벽 설치)를 버튼으로 선택하여 행동할 수 있도록 한다.

### 앱 이름
쿼리도로 AI를 이겨라!

### 배포 링크
[쿼리도로 AI를 이겨라!](https://gemini.google.com/share/54ea43de05b7)

### 회고



## 📚 3. 학습 앱

### 요구사항

Java 컨테이너를 재미있게 학습할 수 있도록 웹앱을 구현한다.

- 파트를 Iterable, Collection, List, Set, Map, Stream으로 나누어 학습할 수 있도록 한다.
- 각 파트 별로 문제가 랜덤하게 출제되고 맞추지 못하면 다시 진행하도록 한다.
- 이전 파트를 통과하지 못하면 다음 단계로 진행할 수 없도록 한다.

### 앱 이름
던전을 탐험하며 배우는 Java 컨테이너

### 배포 링크
[던전을 탐험하며 배우는 Java 컨테이너](https://gemini.google.com/share/55ab6bea80f6)

## 🤝 4. 페어 프롬프트 릴레이 앱

### 요구사항

금연 시에 얻을 수 있는 효과·보상을 시각화 하여 금연의 동기부여를 할 수 있는 웹앱을 구현한다.

- 금연 유지 기간과 하루 평균 흡연량을 입력하면 절약한 금액과 늘어난 수명을 계산 하도록 한다.
- 절약한 금액을 토대로 구매할 수 있는 최대한의 보상을 이미지로 보여주도록 한다.
- 금연 유지 기간이 늘어날 수록 건강해지는 신체 변화를 나타내도록 한다.

### 앱 이름
금연 적금

### 배포 링크
[금연 적금](https://gemini.google.com/share/4e735949b8c5)
