### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
    - 두 사람이 공통으로 겪고 있던 문제를 정리해 보니, 우테코 교육장에 오기 전 필요한 물건을 두고 오는 일이 3일째 반복되고 있었습니다.
    - 이를 방지하고자 아침에 챙겨나가야 할 물건들을 미리 리스트에 작성하고 날씨에 맞는 추가 물품들을 챙길 수 있도록 했습니다.
    - 이를 통해 아침에 깜빡하고 가져오지 못하는 상황을 미연에 방지하고자 본 앱을 만들었습니다.

- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
    - 아침에 샤워 후 외출 준비를 할 때 어떤걸 챙겨야 할 지 체크리스트를 통해서 물건을 챙깁니다.
    - 현재 위치와 목적지의 날씨 정보를 각각 제공하기 때문에, 목적지에 맞는 추가 물품을 작성하고 함께 체크합니다.
    - 즉, 아침에 목적지를 정하여 외출할 때마다 이 앱을 사용할 예정입니다.

### 주요 기능

- 기능 1
    - 현재 위치와 목적지의 날씨를 기반으로 우산, 마스크, 선크림 등 날씨에 맞는 물건을 추천하고 날씨 정보를 제공합니다.
- 기능 2
    - 아침 모닝 루틴을 설정하여 아침에 어떤 것을 챙겨야 할 물건을 작성해놓고 체크합니다.
    - 현재 위치와 목적지의 날씨를 바탕으로 AI가 필요한 물건을 판단하여 추천합니다.

### AI 기능

- 어떤 AI 기능을 추가했나요?
    - 날씨 정보를 기반으로 외출 시 챙기면 좋을 물건을 자동으로 추천하는 AI 기능을 추가했습니다.

- AI 기능이 앱에서 어떤 역할을 하나요?
    - 사용자가 놓치기 쉬운 물건을 상황에 맞게 추천해주는 역할을 합니다.
