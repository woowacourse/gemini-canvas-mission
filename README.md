# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 애플리케이션 소개

### 오식완(유틸리티성 앱)

오식완은 복잡한 칼로리 계산이나 영양성분 검색 없이, 내가 먹은 음식을 평소처럼 글로 쓰기만 하면 AI가 알아서 영양 정보를 채워주는 스마트 식단 일기장입니다.
본인의 목표 영양성분 섭취량도 설정할 수 있어, 오늘 어떤 영양소를 얼마나 더 먹어야 하는지를 쉽게 파악할 수 있습니다.

### 우아한타자코스(게임)

인공지능(AI)이 내가 원하는 주제에 맞춰 끝없이 문장을 만들어주는 맞춤형 한글 타자 연습 게임입니다. 지루하고 똑같은 문장을 반복하는 대신, 매번 새로운 문장과 쫄깃한 난이도로 재미있게 타자 실력을 키울 수 있습니다.

### Deep Bubble(학습용 앱)

평소 궁금했거나 깊이 공부하고 싶은 주제를 시각적으로 재미있게 파고들 수 있는 인터랙티브 학습 서비스입니다.
사용자가 제시한 주제를 기반으로, 키워드가 거품 형태로 떠오릅니다.
거품을 터트려 해당 키워드에 대한 퀴즈를 풀이할 수 있고, 터진 거품은 세부 키워드를 담은 거품들로 나눠집니다.

### No worry(페어 릴레이 앱)

결정하기 힘든 고민이 생겼을 때, 다른 사람의 의견을 A vs B 형태의 투표로 물어볼 수 있는 서비스입니다.
주변 크루와의 토론 중 쉽게 결론이 나지 않는다면, 전체 우아한테크코스 크루를 대상으로 해당 주제에 대한 의견을 받아볼 수 있습니다.
