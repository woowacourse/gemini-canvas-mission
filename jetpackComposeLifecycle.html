Jetpack Compose Lifecycle

컴포즈의 탄생부터 소멸까지, 생명주기를 시각적으로 학습하세요.

생명주기 시각화 (Lifecycle Diagram)

1단계 Enter Composition
2단계 Recomposition (0회 이상 업데이트)
3단계 Leave Composition
각 원을 클릭하여 해당 단계의 상세 설명을 확인하세요.

컴포지션 시작 (Enter)

Compose가 처음 실행될 때 발생합니다. remember 블록이 초기화되고, LaunchedEffect가 시작됩니다. UI 트리에 컴포저블이 최초로 추가되는 순간입니다.

리컴포지션 (Recomposition)

관찰 중인 State가 변경될 때 발생합니다. Compose는 변경된 부분의 UI를 다시 그리기 위해 함수를 재실행합니다. 효율성을 위해 변경되지 않은 데이터는 건너뛰며(Skipping), 이 과정은 매우 빈번하게 일어날 수 있습니다.

컴포지션 종료 (Leave)

화면 전환이나 조건부 UI 출력(if문 등)에 의해 컴포저블이 더 이상 필요하지 않을 때 발생합니다. DisposableEffect의 정리(onDispose) 로직이 실행되며 자원이 해제됩니다.

핵심 정리 (Cheatsheet)

  • • Composition: UI의 구조를 정의합니다.
  • • remember: 리컴포지션 시에도 값을 보존하게 해줍니다.
  • • State<T>: 이 값이 바뀌면 컴포즈는 리컴포지션을 예약합니다.
  • • SideEffect: UI 구성 이외의 작업(네트워크, 로그)을 안전하게 처리합니다.
