# 🗓️ 툭(Took) - 텍스트로 던지는 일정 관리

시간과 일정 제목을 자유롭게 텍스트로 입력하면, AI가 자동으로 시간과 키워드를 추출하여 깔끔한 타임라인으로 정리해주는 웹 애플리케이션입니다.

복잡한 양식 입력 없이, 생각나는 대로 툭! 던지면 일정이 쓱! 정리됩니다.



## ✨ 주요 기능

**AI 기반 자동 추출**
- "오후 3시 팀 회의하고, 저녁 7시에 강남역에서 저녁식사"처럼 자연어로 입력
- Gemini AI가 시간(HH:MM)과 일정 제목을 자동 분석하여 구조화

**실시간 타임라인 시각화**
- 입력한 일정이 시간순으로 자동 정렬되어 타임라인에 표시
- 현재 시간 기준으로 지난 일정은 회색 처리 (취소선 + 비활성화)
- 각 일정 블록에서 삭제 버튼(X)으로 개별 삭제 가능

**누적 관리**
- 여러 번 나누어 입력해도 기존 일정과 함께 누적 저장
- 하나의 타임라인에서 하루 전체 일정을 한눈에 확인

**스마트 유효성 검사**
- 존재하지 않는 시간(25시, 111분 등) 입력 시 구체적인 오류 메시지 표시
- 잘못된 입력은 자동 정리되지 않고 수정 요구



## 🎯 사용 시나리오

**학생**: "오전 9시 수업, 오후 2시 과제 제출, 저녁 6시 동아리 모임" → 하루 스케줄 한 번에 정리

**직장인**: "오전 10시 주간회의, 점심 12시 반 거래처 미팅, 오후 4시 보고서 마감" → 업무 일정 빠르게 관리

**일상**: "아침 7시 기상, 9시 헬스장, 저녁 8시 치과 예약" → 개인 루틴 간편하게 기록
