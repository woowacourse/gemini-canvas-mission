# 🪐 StreamPlanet - 행성이가 안내하는 Stream API 학습 웹앱

Java Stream API의 핵심 개념을 인터랙티브하게 체험하며 학습할 수 있는 교육용 웹 애플리케이션입니다.

귀여운 마스코트 '행성이'와 함께 데이터가 흐르는 우주를 탐험하며, 컬렉션과 스트림의 차이부터 파이프라인 구조, 중간/최종 연산까지 자연스럽게 익힐 수 있습니다.


### 🎮 사용 방법
---

#### 1️⃣ 메인 화면 - Collection vs Stream 비교

**Collection 영역 (좌측)**
- 요소를 여러 번 클릭해도 계속 접근 가능 (초록색)
- 데이터를 메모리에 저장하여 언제든 반복 접근 가능

**Stream 영역 (우측)**
- 요소를 한 번 클릭하면 "소비됨" 상태로 변경 (회색)
- 소비된 요소를 다시 클릭하면 경고 메시지 표시
- **핵심**: 스트림은 일회용이며 재사용 불가!


#### 2️⃣ 학습 화면 - Stream API 완벽 파헤치기

**챕터 1: 스트림 흐름도**
- "▶ 파이프라인 실행" 버튼 클릭
- 생성 → 중간 연산(filter) → 최종 연산(collect) 과정을 애니메이션으로 확인

**챕터 2: 중간 연산 실습**
- 초기 데이터: [1, 2, 2, 3, 4, 5]
- filter, map, distinct, sorted 버튼을 클릭하여 데이터 변화 실시간 확인
- 중간 연산은 여러 번 연결 가능

**챕터 3: 최종 연산 실습**
- count(), collect(), reduce() 중 하나 선택
- 최종 연산 실행 후 스트림이 닫히는 것을 확인 (회색 표시)


#### 3️⃣ 퀴즈 화면 - StreamPlanet 탈출 퀴즈

- 총 5개의 문제로 학습 내용 복습
- 정답: 초록색 표시 + 해설 제공
- 오답: 빨간색 깜빡임 + 재시도 가능
- 모두 맞추면 학습 완료!
