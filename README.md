# Gemini Canvas Mission

Gemini Canvas로 제작한 4개의 웹앱 모음.

## 💻 1. 유틸리티 앱 — TapTempo (BPM 측정기)

**[배포 링크](https://gemini.google.com/share/c7bb32ec2404)**

### 만든 이유
음악을 듣다가 내가 듣는 곡이 어느 정도 빠르기인지 궁금할 때가 있었다.
직접 비트를 타면서 BPM을 측정하는 도구를 만들고자 했다.

### 주요 기능
- 버튼 클릭 / 스페이스바로 탭하면 BPM 측정
- 최근 8번의 탭만 활용하는 슬라이딩 윈도우 방식으로 템포 변화에 자동 적응
- 2초 동안 입력이 없으면 자동 초기화

### AI 기능
- Gemini API + Google Search Grounding을 활용해 곡 제목으로 BPM 검색
- 변박이 있는 곡(예: 보헤미안 랩소디)은 구간별 BPM 분리 설명

## 🎮 2. 게임 — 슈퍼헥사곤

**[배포 링크](https://gemini.google.com/share/0ae192c51c90)**

### 만든 이유
단순하면서도 재밌는 게임이라고 느껴져서 Gemini Canvas로도 구현해보고 싶었다.

### 주요 기능
- 버튼 클릭 / 스페이스 / 엔터 키로 게임 (재)시작
- 랜덤한 7가지 패턴의 육각형 장애물 생성
  - 기본 / 넓은 구멍 / 터널 / 반대편 구멍 / 지그재그 / 회오리 / Hyper 패턴
- 좌우 방향키 또는 화면 좌우 터치로 화살표 조작
- 60초마다 장애물 속도 증가 (1~5단계)
- 게임 오버 시 생존 시간 및 최종 스테이지 표시

## 📚 3. 학습 앱 — Java 버그 헌터

**[배포 링크](https://gemini.google.com/share/a9332983827d)**

### 만든 이유
컴파일 에러뿐만 아니라 발견하기 어려운 버그를 직접 수정하며, 숨은 버그를 찾는 능력을 기르고자 했다.

### 주요 기능
- Gemini AI가 난이도별 Java 버그 코드 10문제 자동 생성
  - 쉬움(컴파일 에러) → 보통(런타임 에러) → 어려움(논리 에러) → 마스터
- CodeMirror 기반 Java 코드 에디터 (괄호 페어링, Syntax highlighting)
- 코드 제출 시 Gemini AI가 정오답 판별 및 힌트/해설 제공
- 단계별 진행률 표시 및 코드 초기화 기능

## 🤝 4. 페어 프롬프트 릴레이 앱 — 우아한 메타버스

**[배포 링크](https://gemini.google.com/share/629f0c209f0b)**

**페어:** @simhokyung, @parkjiyeoung8297

### 만든 이유
우테코 크루들이 층별로 분리되어 교류가 적다는 점에서, 층간 경계 없이 메타버스상에서 크루들이 자유롭게 소통할 수 있는 공간을 만들고자 했다.

### 주요 기능
- 닉네임 입력 및 캐릭터 이모지 선택
- 2개의 마을(뽀롱뽀롱 / 둠바 부족) 선택 후 입장
- 방향키 / WASD로 캐릭터 이동
- 말풍선 채팅 (3초 후 자동 사라짐)
- 전체 채팅 로그 사이드바
- 실시간 접속자 목록 및 특정 크루 위치로 텔레포트
- Firebase Firestore 기반 실시간 멀티플레이어 동기화
