## 💻 1. 유틸리티 앱

### 앱 이름
`철학자의 서재 (미움받을 용기)`

### 배포 링크
https://gemini.google.com/share/73ffb8d33bf9

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?

```text
개발 혹은 공부를 하면서, 더 나아가 인생을 살아가면서 과거로부터 오는 후회와 현재로부터의 권태들은 우리를 항상 괴롭힙니다.

그리고 그런 고민들은 의외로 몇몇의 조언들과 작은 마인드셋의 변화로도 해결될 수 있습니다.
```

- 본인이 이 앱을 언제, 어떻게 사용할 건가요?

```text
최근 읽은 서적 <<미움받을 용기>>에 등장하는 아들러 심리학을 기반으로 하는 철학을 감명깊게 보았습니다.

해당 철학을 일상에 잘 접목시킬 수만 있다면 저 스스로 더욱 진취적이면서도 동요하지 않는 사람이 될 수 있을 것다고 생각했습니다.

그래서, 제가 일상에서 스트레스를 받거나 마음이 흔들리는 순간에 철학의 도움을 받고 평안을 얻고자 '철학자의 서재' 앱을 만들었습니다.   
```

### 주요 기능

- 아들러 심리학 맞춤 해석

```text
사용자의 고민을 '과제의 분리', '목적론', '타자공헌' 등 아들러의 5대 핵심 원칙에 즉각적으로 대입하여 상황을 재해석해 줍니다.
```

- 소크라테스식 문답 

```text
정답을 주입하지 않고, 부드러운 질문을 통해 사용자 스스로 깨달음을 얻도록 유도합니다.
````

### AI 기능

- Gemini API와 프롬프트 엔지니어링을 결합하여, 《미움받을 용기》 속 현명하고 단호한 '철학자' 페르소나를 AI로 구현했습니다.


- 단순한 텍스트 반응을 넘어, 사용자의 넋두리 속에 숨겨진 심리적 모순을 파악하고 대화의 흐름을 주도하는 1:1 맞춤형 멘토 역할을 수행합니다.

## 📚 3. 학습 앱

### 앱 이름
`자바 백엔드 학습 대시보드`

### 배포 링크
https://gemini.google.com/share/1900f62c1ed8

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?

```text
개발 관련 지식을 공부할 때면, 추상적인 개념을 이해하는 것이 어려울 떄가 많습니다.

제 경우에는 Spring MVC의 동작 순서나 JPA 영속성 컨텍스트 등의 개념들을 단번에 이해하는 것이 어려웠습니다.

백엔드들을 개념들을 시작적으로 보여주어 개념을 쉽게 이해할 수 있도록 하는 앱이 필요했습니다.
```

- 본인이 이 앱을 언제, 어떻게 사용할 건가요?

```text
Spring과 JPA의 동작 과정을 눈으로 확인하며 이해하고 공부할 때 사용할 것입니다.
공부 후, 다른 이에게 정보를 제공할 떄도 자료로 사용하면 유용할 것 같습니다.
```

### 주요 기능

- **Spring MVC 요청 흐름 시뮬레이션**

데이터 패킷이 DispatcherServlet, Controller 등을 거치는 과정을 애니메이션으로 보여주고, 각 단계에 맞는 실제 Java 코드를 함께 제공합니다.

- **JPA 영속성 컨텍스트 시뮬레이터**

버튼(`persist`, `remove` 등)을 클릭하여 메모리, 1차 캐시, 쓰기 지연 SQL 저장소 간의 엔티티 상태 변화를 실시간으로 확인합니다.

- **Java 핵심 개념 퀴즈**

Collections(List, Set, Map)와 Stream API에 대한 개념 확인 인터랙티브 퀴즈를 제공합니다.
