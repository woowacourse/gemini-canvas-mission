# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 💻 1. 유틸리티 앱: Voca Studio

나만의 학습 자료를 관리하고 암기하는 커스텀 단어장 솔루션입니다.

### 🔗 배포 링크
https://gemini.google.com/share/a08f4f0b6fe8

### 기획 의도

- **문제 해결**: 정해진 데이터만 제공하는 기존 앱의 한계를 넘어, 사용자가 가진 엑셀(CSV) 자료를 즉시 학습 카드로 변환합니다.

- **사용 시나리오**: PC에서 정리한 대량의 단어를 업로드한 후, 출퇴근 시간에 '자동 재생' 모드로 청취하고, 하루 끝에 '미암기 필터' 퀴즈로 최종 점검합니다.

### 주요 기능

- **CSV 대량 업로드**: 엑셀 데이터를 한 번에 추가하며, 중복 단어 자동 감지 기능을 지원합니다.

- **주제별 분류**: 토익, 비즈니스 등 카테고리별 집중 학습이 가능합니다.

- **플래시카드**: 원어민 TTS 발음 지원 및 0.5x~2.0x 속도 조절 기능을 제공합니다.

- **실시간 동기화**: 저장 버튼 없이도 PC와 모바일 어디서든 이어서 학습할 수 있습니다.

## 🎮 2. 게임: Neon Beat

사용자의 음악으로 즐기는 커스텀 리듬 액션 게임입니다.

### 🔗 배포 링크
https://gemini.google.com/share/cdd53dde34de

### 기획 의도

- **문제 해결**: 수록곡의 한계를 없애고, 사용자가 소장한 MP3 파일을 업로드하여 즉석에서 채보를 생성해 즐길 수 있도록 제작했습니다.

- **사용 시나리오**: 최신 유행 곡이나 좋아하는 아티스트의 앨범을 단순 감상을 넘어 직접 연주하는 경험을 하고 싶을 때 활용합니다.

### 주요 기능

- **MP3 커스텀 트랙**: 사용자 보유 파일을 추가하여 무한한 곡 리스트 구성이 가능합니다.

- **가변 BPM 시스템**: 난이도(Easy, Normal, Hard)에 따라 120~160 사이의 랜덤 BPM을 적용하여 매번 새로운 재미를 제공합니다.

- **정교한 판정**: Perfect부터 Miss까지 이어지는 판정 시스템과 신디사이저 타격 효과음으로 몰입감을 높였습니다.

## 📚 학습 앱: DroidVisualizer

안드로이드 핵심 개념을 시각적으로 학습하는 개발자 전용 비주얼 가이드입니다.

### 🔗 배포 링크
https://gemini.google.com/share/6b1dd274f636

### 기획 의도

- **문제 해결**: 생명주기(Lifecycle), 의존성 주입(Hilt) 등 추상적인 개념을 애니메이션으로 시각화하여 메서드 호출 순서와 데이터 흐름을 직관적으로 이해하도록 돕습니다.

- **사용 시나리오**: 기술 면접 준비 시 헷갈리는 시퀀스를 복기하거나, 실무 설계 시 Google 권장 가이드 코드를 참고하는 용도로 사용합니다.

### 주요 기능

- **프로세스 애니메이션**: MVVM 파이프라인, Hilt 객체 주입 과정을 단계별 시뮬레이션으로 확인합니다.

- **실시간 시나리오 테스트**: 화면 회전, 홈 버튼 클릭 등 실제 상황 발생 시의 시스템 콜백 흐름을 추적합니다.

- **최신 Kotlin 코드셋**: StateFlow, LazyColumn 등 구글 권장 최신 API 예제 코드를 수록했습니다.

- **AI 퀴즈**: Gemini가 최신 기술 명세를 바탕으로 'Process Death 대응' 등 실무적인 판단력이 필요한 퀴즈를 실시간으로 생성합니다.

## 🤝 4. 페어 프롬프트 릴레이 앱: 회고 AI 코치

STAR 프레임워크를 통해 단순 기록을 성장의 발판으로 바꾸는 회고 전문 가이드입니다.

#### Pair: @chohs4164

### 🔗 배포 링크
https://gemini.google.com/share/21e7f1f19a0f

### 기획 의도

- **문제 해결**: "오늘 뭐 했다" 식의 단순 나열을 방지하고, 논리적인 구성을 갖춘 심층적인 회고 작성을 유도합니다.

- **사용 시나리오**: 하루 일과를 마친 저녁, AI 코치의 질문에 답하며 경험을 구체화하고 논리적으로 교정된 회고록을 아카이빙합니다.

### 주요 기능

- **STAR Deep-Dive**: 상황(S), 과제(T), 행동(A), 결과(R) 중 누락된 요소를 찾아 구체화 질문을 던집니다.

- **논리 체크 피드백**: 모호한 표현(예: 열심히)을 감지하여 수치화되거나 명확한 표현으로 교정을 제안합니다.

- **대화형 UI**: 다크 모드를 지원하는 채팅 인터페이스를 통해 연속적인 대화로 생각을 심화합니다.

- **AI 인사이트**: 사용자의 맥락을 분석해 감정 상태를 파악하고, 학습 키워드를 추천하여 개인화된 성장을 돕는 '멘토' 역할을 수행합니다.
