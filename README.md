# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

--- 
## 앱 이름: SpaceStudy
## 카테고리: 유틸리티 앱

### 배포 링크
https://gemini.google.com/share/c824c3a9966f

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
  - 평소 몰입해서 공부할 때 주변의 방해를 차단하고자 앱이나 유튜브로 백색소음 ASMR을 즐겨 듣습니다. 하지만 대부분 딱딱하고 단조로운 2D 화면만 제공되어 아쉬웠습니다. 시각적인 몰입감을 극대화하기 위해 '실제 우주를 여행하는 듯한 3D 환경'을 결합하여, 누구나 더 쉽고 깊게 몰입할 수 있는 공간을 만들고 싶었습니다.

- 이 앱을 언제, 어떻게 사용할 건가요? 
  - 코딩, 독서, 공부, 명상 등 깊은 몰입이 필요한 순간에 켜둡니다. 집중할 태그와 목적지(시간)를 선택해 탑승권을 발급받은 뒤, 우주선이 목적지에 도착할 때까지 화면의 우주 풍경과 백색소음을 배경 삼아 할 일에 집중합니다.

### 주요 기능
- 목적지 기반 타이머: 달, 화성 등 실제 우주 천체까지의 거리에 비례하여 집중 시간이 자동으로 계산됩니다.
- 몰입형 3D 우주 비행: 화면을 뚫고 별이 스쳐 지나가며 행성이 다가오는 3D 전진 비행 연출을 제공합니다.
- 감성적인 발권 & 이륙 연출: 실제 항공권이 인쇄되는 UI와 이륙 안내 방송(TTS), 차임벨 소리로 몰입의 시작을 돕습니다.
- 집중 특화 백색소음: 우주선 내부에 있는 듯한 부드러운 핑크 노이즈와 엔진 공명음을 재생합니다.

## 앱 이름: SuperDino
### 카테고리: 게임

### 배포 링크
https://gemini.google.com/share/8db78d61501e

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
  - 인터넷 연결이 끊겼을 때 나오는 크롬 공룡 게임은 익숙해지면 너무 쉬워져서 금방 지루해지는 경향이 있었습니다. 이를 해결하기 위해 난이도 조절과 다양한 기믹이 추가된 확장된 버전의 공룡 게임을 만들고 싶었습니다.
- 이 앱을 언제, 어떻게 사용할 건가요?
  - 인터넷 연결이 안 돼서 지루할 때
  - dino 게임을 좀 더 즐기고 싶을 때

### 주요 기능
- 차징 점프 시스템: 장애물이 나오면 점프할 수 있습니다. 스페이스바를 누르는 시간에 비례하여(차징 게이지 표시) 점프의 높이가 달라져 세밀한 컨트롤이 필요합니다.
- 체력(HP) 시스템과 무적 시간: 단 한 번의 실수로 끝나는 원작과 달리, 3개의 하트가 주어집니다. 피격 시 잠시 무적 상태가 되며, 게임을 진행하다 보면 필드에서 회복 아이템(하트)을 얻을 수 있습니다.
- 다이내믹한 난이도 (레벨업): 일정 점수에 도달할 때마다 레벨업 알림과 함께 게임 속도가 빨라지며, 등장하는 장애물(선인장, 수풀)의 크기도 점점 커져 긴장감을 더합니다.
- 레트로 감성: 픽셀 아트 스타일의 그래픽과 자체 구현된 8비트 효과음을 통해 고전 게임의 향수를 느낄 수 있습니다.

## 앱 이름: Backend 30
### 카테고리: 학습 앱

### 배포 링크
https://gemini.google.com/share/720c6cb01ba8

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
    - 백엔드 개념을 공부할 때 방대한 양 때문에 여러 번 반복해서 외워도 계속 까먹는 일이 발생했습니다
    - 면접을 진행하거나 문제를 풀 때 이러한 문제 때문에 불편함을 겪어서 키워드 중심으로 외우기 위해서 애플리케이션을 개발했습니다
- 이 앱을 언제, 어떻게 사용할 건가요?
    - 복습 도구
    - 면접 직전 퀵 리뷰

### 주요 기능
- 로드맵 기반 스테이지 시스템: 기초 네트워크부터 고급 DB 엔진 구조까지 총 30단계의 스테이지 구성. 이전 단계를 100% 정답률로 클리어해야 다음 단계 해금
- 키워드 매칭 퀴즈: 질문에 대한 정답 키워드를 2~3개씩 선택하는 방식으로, 개념의 다각도 이해도를 측정
- Deep-Dive 해설 세션:
  - 키워드 해설: 정답 키워드가 문제와 어떻게 연결되는지 상세 설명.
  - 실무 활용 사례: 실제 프로젝트 환경에서 해당 기술이 적용되는 시나리오 제시.
  - Interview Prep: 실제 기술 면접 예상 질문과 논리적인 모범 답변 가이드 제공.
- 완전 학습 시스템: 틀린 문제는 즉시 다시 풀 수 있는 기회를 제공하여, 해당 회차의 모든 문제를 완전히 이해해야만 스테이지 클리어 인정.
- 진행 상황 저장: LocalStorage를 활용하여 별도의 로그인 없이도 사용자의 해금 현황 및 완료 기록 보존.
