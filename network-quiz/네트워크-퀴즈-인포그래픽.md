## 앱 이름: Network Quiz
## 카테고리: 인포그래픽/퀴즈

### 배포 링크
https://gemini.google.com/share/c8bed851bf54

### 이 앱을 만든 이유
- 프론트엔드 개발자로서 자주 헷갈리는 네트워크 개념(HTTP, DNS, CORS, REST, TCP)을 익히고 싶었다.
- 인포그래픽으로 구조를 파악하고, 퀴즈로 바로 확인하는 방식이 효율적이라고 판단했다.

### 주요 기능
- HTTP, DNS, CORS, REST API, TCP 총 5가지 네트워크 주제를 SVG 인포그래픽으로 시각화하여 제공한다.
- 인포그래픽을 보고 나서 Gemini가 생성한 관련 퀴즈를 풀 수 있으며, 로컬스토리지에 최고 점수가 저장된다.
- 퀴즈는 이전에 출제된 주제를 추적해 중복 없이 출제된다.

### AI 기능
- Gemini API의 responseSchema를 활용해 퀴즈 문제와 보기, 정답, 해설을 구조화된 JSON 형태로 생성한다.
- API 호출 실패 시 지수 백오프(1초→2초→4초) 재시도 로직으로 안정적인 응답을 보장한다.
- 선택한 네트워크 주제에 맞는 난이도와 맥락을 고려한 퀴즈를 한국어로 생성하여 제공한다.
