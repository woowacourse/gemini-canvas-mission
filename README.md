## 💻 1. 유틸리티 앱

### 앱 이름
FinSearch
### 배포 링크
https://gemini.google.com/share/a5ecd91b2130
### 이 앱을 만든 이유

- **어떤 문제/불편함을 해결하려고 했나요?**
  - 저희는 아키텍처 설계 및 구현 과정에서 다양한 기술적 문제를 직면합니다. 이 과정에서 저는 핀테크 기업들의 기술 블로그를 참고합니다. 문제는 너무 많고 번거롭게 찾아야 한다는 점입니다. 그래서 저는 이러한 기술 블로그들이 제공하는 RSS 피드를 이용해 기술 블로그들을 한 곳에 모아 보는 앱을 만들었습니다.
- **이 앱을 언제, 어떻게 사용할 건가요?**
  1. 개발자 지망생의 빠른 핀테크 기술 블로그 서치
  2. 기술적 문제에 직면했을 때 비슷한 기술 블로그 포스팅 서치

### 주요 기능
- **각 기술 블로그가 제공하는 RSS 피드를 이용해 포스팅 추출**
  - 앱 접속 시 각 기술 블로그가 제공하는 RSS 피드를 이용해서 포스트들을 추출합니다. 만약 RSS가 안된다면 Local DB의 포스팅을 사용하게 됩니다.
- **키워드 기반 기술 블로그 포스팅 검색**
  - 키워드를 이용해 기술 블로그 포스팅과 유사한지 검사하여 검색할 수 있습니다.
- **각 회사 별 최신 기술 블로그 포스팅 검색**
  - 앱 상단에서 핀테크 기업 별 기술 블로그 최신 포스팅을 최대 10개까지 확인 가능합니다.

### AI 기능
- **어떤 AI 기능을 추가했나요?**
  - AI가 키워드와 기술 블로그 포스팅의 검색을 진행하게 하였습니다.
- **AI 기능이 앱에서 어떤 역할을 하나요?**
  - 이 앱의 취지 자체가 기술적 문제에 직면했을 때 유사한 문제 해결 포스팅을 검색하기 위해 만들어졌습니다.
  - 그렇기에 핵심 역할을 담당합니다.

## 📚 3. 학습 앱

### 앱 이름
AI 기술 면접 트레이너
### 배포 링크
https://gemini.google.com/share/1e4816e2414c
### 이 앱을 만든 이유
- **어떤 문제/불편함을 해결하려고 했나요?**
  - 면접을 연습하기 위해서는 2가지 조건이 필요합니다. 1. 같이할 사람이 있거나, 2. AI에게 수동으로 면접리스트를 뽑고 하나하나 프롬프트로 조율하거나 입니다. 저는 이러한 상황이 매우 귀찮았습니다.
- **이 앱을 언제, 어떻게 사용할 건가요?**
  - 면접 연습을 해야하는 상황에 사용할 것 같습니다. 기초적인 질문은 AI가 만들어 채점하며 만약 자신만의 파트가 있다면 TXT 파일을 만들어 올려보세요! AI가 질문을 뽑아내서 채점해줄 것입니다.

### 주요 기능
- **각 카테고리 별 AI 질문 생성**
  - 각 카테고리 별 AI가 질문을 랜덤으로 생성합니다.
- **질문에 따른 사용자 응답 채점**
  - 사용자의 응답을 핵심 논리 위주로 검사합니다. 핵심 논리가 맞다면 지엽적인 논리는 제외되며 점수를 채점합니다.
- **TXT 문서 업로드 시 문서를 분석하여 면접 질문 도출 및 채점**
  - TXT 문서 업로드를 통해 사용자에게 최적화된 면접 질문 도출과 채점을 진행할 수 있습니다. 

### AI 기능
- **어떤 AI 기능을 추가했나요?**
  - 카테고리에 맞는 기초 질문 생성
  - 질문에 따른 사용자 응답 채점 및 솔루션
  - TXT 문서 분석 
- **AI 기능이 앱에서 어떤 역할을 하나요?**
  - 앱의 전체적인 기능을 담당합니다. 주로 문제 생성, 채점에 사용됩니다.

## 🤝 4. 페어 프롬프트 릴레이 앱
### 앱 이름: DailyMeet
### 페어
[@Jiihyun](https://github.com/Jiihyun)

### 배포 링크
https://gemini.google.com/share/72c47aeab363

### 이 앱을 만든 이유
- 우테코에서 '데일리(Daily)' 미팅 문화를 처음 접한 후, "팀원들과 어떻게 하면 데일리 일정을 더 원활하고 유쾌하게 소통할 수 있을까?"라는 고민에서 출발했습니다.
- 이 앱은 팀 단위 데일리 미팅을 지원하기 위해 제작되었습니다. 매일 랜덤으로 데일리 마스터를 지정하고, 미팅 기록을 캘린더에 저장하며, AI 기반 키워드 검색을 통해 색다른 데일리 주제를 추천받을 수 있도록 기획했습니다.

### 주요 기능
- **데일리 마스터 관리**: 오늘 및 내일의 데일리 마스터 안내 및 랜덤 선정
- **팀원 관리**: 데일리 미팅에 참여할 팀원 지정 기능
- **데일리 주제 추천**: 랜덤 데일리 주제 추천
- **AI 기반 키워드 검색**: 특정 키워드를 기반으로 한 AI 맞춤형 질문 및 활동 추천
- **기록 및 관리**: 데일리 타이머 제공 및 캘린더에 미팅 기록 저장
- **학습 지원**: 코딩 테스트 문제 추천 기능

### AI 기능 
- 매일 새로운 데일리 주제를 떠올리는 것은 생각보다 쉽지 않습니다. AI는 이러한 고민을 덜어주고 앱을 더욱 능동적으로 활용할 수 있게 돕는 핵심 역할을 합니다.
- 먼저 오늘의 데일리 주제를 제안해 주며, 만약 제안된 주제가 마음에 들지 않을 경우 특정 키워드를 입력해 AI를 통해 우리 팀에 딱 맞는 새로운 질문과 활동을 추천받을 수 있습니다.

## AI 사용 일지(AI 기술 면접 트레이너)

### 1. 초기 프롬프트
``` 
[타이틀 : AI 기술 면접 트레이너]
요구사항 :
 다양한 주제 카테고리로 면접 질문을 AI 기반으로 만들어주는 앱을 원합니다. AI가 질문을 만들고 사용자의 응답을 받아 점수를 환산하고 솔루션을 제공해주세요.
 또한 카테고리는 JAVA, SPRING, NETWORK, DB, OS, ORM 입니다.
제한사항 : HTML, CSS, JS를 사용하여 만들어주세요.
AI 응답 사항 : 
당신을 AI 면접관이라고 생각해주세요. 현업에서 자주 나오는 질문들을 위주로 선정해주세요.
```

### 2. 프롬프트 개선 과정
1. **처음 결과물의 질문이 너무 딥하게 나왔습니다.** 
```
다수의 스레드가 공유하는 복잡한 상태를 안전하고 효율적으로 관리해야 하는 고성능 시스템을 설계하고 있다고 가정해봅시다. 
이 시스템에서 동시성(Concurrency) 문제를 해결하기 위해 `synchronized` 키워드와 `java.util.concurrent.locks.ReentrantLock` 중 어떤 것을 선택할지 그 판단 기준과 각각의 장단점을 비교하여 설명해주세요. 
또한, 이러한 동기화 메커니즘이 보장하는 '원자성(Atomicity)' 외에, 스레드 간의 '가시성(Visibility)'을 보장하기 위한
 `volatile` 키워드의 역할과 Java Memory Model(JMM)이 가시성을 어떻게 강제하는지 심층적으로 설명해주세요

다수의 사용자가 동시에 접근하는 사용자 관리 대시보드 시스템을 설계하고 있다고 가정해봅시다. 
이 시스템은 특정 시간대에만 트래픽이 급증하며, 그 시점에만 500 Internal Server Error가 발생합니다. 
CPU, 메모리, 네트워크, 게이트웨이에는 문제가 없으며, 애플리케이션 로그에도 명확한 예외가 남지 않습니다. 평상시에는 정상 동작합니다.
 리소스 사용률은 정상인데 500 에러가 발생하는 이유를 설명해주세요. 
 애플리케이션 로그에 예외가 남지 않는 이유와 리소스 사용률은 정상인데 500에러가 발생하는 이유를 설명해주세요.
  Thread Pool, DB Connection Pool, Deadlock, Race Condition 가능성을 포함해서 설명해주세요.
```
2. **그래서 질문 수준을 신입에 맞춰 진행하며 딥한 문제도 좋지만 하나의 질문에 여러 개를 답해야하는 답변을 피해달라는 프롬프트를 작성했습니다.**
```
현재 완성한 프롬프트의 질문 수준은 너무 딥하며 신입에 맞춰 진행해주세요.
또한 딥한 문제도 좋지만 하나의 질문에서 여러개의 답을 해야하는 질문은 피해주세요.
```

3. **질문의 질은 개선이 되었지만 다른 문제가 있었습니다. 바로 채점 방식입니다. 채점 기준이 너무 엄격했습니다.**
```
실제 면접은 이렇게 점수가 엄격하지 않습니다.
 실제 면접처럼 핵심적인 논리가 맞다면 지엽적인 부분은 생략하더라도 좋은 점수를 주세요.
```

4. **면접 질문 선정 기능은 완성되었습니다. 여기서 저는 개인에 맞춘 질문을 선정할 수 있어야한다고 생각했습니다. 그래서 텍스트 파일 분석 기능을 넣었습니다.**
```
사용자가 TXT 파일을 업로드하면 AI가 그것을 분석해서 질문을 생성하고 채점을 할 수 있는 기능을 기존 기능 배너 밑에 만들어주세요. 또한 생성된 질문들은 팝업을 띄워 진행하게 해주세요.
```

### 3. 효과적이었던 프롬프팅 전략
- **효과적인 프롬프팅 전략** : AI가 정확하게 진행할 수 있도록 디테일하게 프롬프팅을 짜는게 중요했습니다. 위의 프롬프트처럼 TXT 파일 업로드 기능 만들어줘가 아닌 정확한 로직 흐름을 알려주는게 정확도가 높았습니다. 
- **비효율적인 프롬프팅** : 막연한 단어를 쓰지 않는게 중요한 것 같습니다. 막연하게 "만들어줘" 같은 단어보다는 "밑에 추가해줘" 이런식으로 진행해야 사용자 요구사항에 맞춰 정확히 만들어줍니다.

### 4. 배운 점
- **기능 구현은 차근차근**
  - Gemini Canvas를 효과적으로 사용하려면 먼저 메인 기능만을 요청한 뒤 세부 기능들을 조립하는 형식으로 진행해야 더 미세한 조절이 되는 것 같습니다. 
- **애매하게 말하지 말고 자세히 말해주자**
  - 프롬프팅 진행 시 요구사항 명세서처럼 작성하는 것이 효과적이라고 느꼈습니다. 
### 5. 리뷰어에게 피드백 받고 싶은 포인트
1. **질문의 깊이(Deep Dive)와 카테고리 선정에 대하여**
- 첫 번째 프롬프팅의 '너무 딥한 질문'은 사실 백엔드 개발자로서 성장하는 데 있어 아주 귀중한 재료입니다. 신입 수준에 맞추는 것도 중요하지만, 질문 자체가 개발자 성장과 관련 있다고 생각합니다. 제가 받고 싶은 피드백은 ""어느 카테고리가 깊이 있는 질문이 필요할까?""입니다. 리뷰어님의 생각을 공유해주세요.
2. **꼬리 질문에 대하여**
- 실제 면접과 유사한 환경을 위해 꼬리 질문 기능을 고민 중입니다. 다만, 학습 피로도가 높아질 수 있다는 우려가 있습니다. 리뷰어님은 이 앱이 사용자 편의성을 고려한 가벼운 연습 도구가 되길 바라시는지, 아니면 피로도가 높더라도 실전 감각을 확실히 키워주는 도구가 되길 바라시는지 의견이 궁금합니다.
