## 앱 이름: 💻 매일 코틀린
## 카테고리: 학습 앱

### 배포 링크
[https://gemini.google.com/share/182a5fbfc12e]

### 이 앱을 만든 이유
- 해결하고자 한 문제
  - 안드로이드 및 코틀린 개발자가 되고자 할 때, 방대한 언어 명세와 알고리즘 문제를 병행해서 학습하는 것이 쉽지 않습니다. 
  무엇을 공부해야 할지 고민하는 '결정 피로'를 줄이고, 매일 조금씩 꾸준히 공부하는 습관을 만들기 위해 제작했습니다.

- 사용 시점 및 방법
  - 매일 아침 혹은 일과를 마치기 전, 앱에 접속하여 자신의 레벨(초급~숙련자)에 맞는 오늘의 개념을 읽고 연결된 알고리즘 문제를 풉니다. 
  완료 후 '학습 완료' 버튼을 눌러 달력에 기록을 남기며 성취감을 얻습니다.

### 주요 기능
1. 📚 단계별 커리큘럼
   - 초급(문법 기초)부터 숙련자(코루틴, 멀티플랫폼)까지 총 80개 이상의 방대한 학습 세트를 제공합니다.
2. 📅 날짜별 미션 자동 배정
   - 날짜 데이터를 기반으로 매일 다른 개념과 알고리즘 문제가 자동으로 배정되어 중복 없는 학습이 가능합니다.
3. 🔗 알고리즘 플랫폼 연동
   - 백준, 프로그래머스 등 주요 코딩 테스트 플랫폼의 문제와 직접 연결하여 실전 감각을 키워줍니다.
4. ✅ 출석 체크 달력
   - Firebase를 통해 개인별 학습 완료 날짜를 저장하고 달력에 표시하여 시각적으로 학습 진도를 관리합니다.
5. 🎨 코틀린 브랜드 테마 UI
   - 코틀린의 공식 브랜드 컬러를 활용한 세련된 그라데이션 디자인과 반응형 레이아웃을 적용했습니다.
