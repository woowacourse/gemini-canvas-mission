# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

</br>

## 💻 1. 유틸리티 앱 - 메시지를 알잘딱깔센

<img width="2560" height="1600" alt="image" src="https://github.com/user-attachments/assets/c3cda109-7a7a-4c43-9504-dc0e31e37fe0" />

### 배포 링크

https://gemini.google.com/share/53b8b9891c0e

### 주요 기능

> 어렵고 귀찮은 메시지를 편하게 작성해보세요!
> 
- 메시지 초안을 특정 사람이나 상황에 맞게 다듬어야할 때, 아예 문장이 떠오르지 않을 때 사용할 수 있습니다.
- `보내려는 메시지 또는 상황/맥락`, `받는 사람`, `형식/어조`, `글자 수` 선택을 통해 자동으로 메시지를 생성합니다.
- 자주 하는 수정 요청을 퀵 버튼으로 제공하여 빠르게 반영이 가능합니다.

</br>

## 🎮 2. 게임 - Acoustic Chord

<img width="2560" height="1600" alt="image" src="https://github.com/user-attachments/assets/41db67d7-477a-48c4-b7c3-b0cea7109821" />

### 배포 링크

https://gemini.google.com/share/2cb6798e6b17

### 주요 기능

> 게임으로 재미있게(?) 기초 화성학을 마스터하고 청음 훈련을 해보세요
> 
- 초급(3화음), 중급(+7도), 고급(디미니쉬/어그먼트)까지 난이도 모드를 제공합니다.
- 문항 개수를 사용자가 스스로 설정할 수 있습니다. (10개 ~ 60개)
- 기초 화성학 이론 가이드와 문제별 음 구성 해설, 코드 라이브러리를 제공합니다.
