# 도전!! 숫자 야구!!!

> 친구와 함께 즐기거나 AI와 연습할 수 있는 숫자 야구 게임입니다.
> 게임 진행 이력과 추리 과정을 화면에서 바로 관리할 수 있습니다.

---

## 이 앱을 만든 이유

- 숫자 야구를 할 때마다 종이에 새로 기록해야 하는 **불편함**을 줄이기 위해 만들었습니다.
- 앱으로 진행하면 **플레이 기록**을 남길 수 있어 게임 흐름을 다시 확인하기 쉽습니다.
- 2인 플레이뿐 아니라 **AI 대전**을 통해 혼자서도 실력을 키울 수 있습니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| AI 대전 모드 (1인용) | 플레이어와 AI가 서로의 숫자를 맞추는 방식으로 진행됩니다. |
| 2인용 대전 모드 | 한 기기에서 친구와 번갈아 입력하며 숫자 야구를 즐길 수 있습니다. |
| 메모장 기능 | 후보 숫자를 체크하면서 추리 과정을 정리할 수 있습니다. |
| 경기 기록 확인 | 게임 결과와 진행 로그를 모아보고 이전 경기를 다시 확인할 수 있습니다. |

---

## AI 기능

- 1인용 모드에서 AI가 **상대 플레이어 역할**을 수행합니다.
- AI는 플레이어의 숫자를 추리하고, 플레이어는 AI의 숫자를 맞추는 **대결 구조**로 진행됩니다.
