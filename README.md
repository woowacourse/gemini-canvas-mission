## 💻 1. 유틸리티 앱

### 앱 이름

- PlateMaster

### 배포 링크

- [PlateMaster](https://gemini.google.com/share/61f189786fc6)

### 이 앱을 만든 이유

- 제가 뛰고 있는 대학 동아리 야구 리그는 전문 심판과 기록원이 없이 학생이 직접 심판과 기록원을 해야하는 상황임.

- 또한 그 지원 인원도 많지 않아 혼자서 기록원과 심판을 동시에 해야하는 상황이 발생하게 되고, 그 두개의 일을 동시에 처리하기는 어려운 상황이라, 심판일만 하고 기록은 포기하는 상황도 종종 발생하는 상황임.

- 폰으로 심판과 경기 상황 기록을 동시에 처리할 수 있으면 이 문제를 해결하기 좋을 것 같다는 생각이 들어 이 앱을 만들게 되었음.

### 주요 기능

- 스코어 및 이닝 관리
    - 점수 조작: AWAY(원정)와 HOME(홈) 팀의 점수를 버튼을 통해 직관적으로 조절 가능.

    - 이닝 표시: 현재 몇 회 초/말인지 자동으로 표시되며, 3아웃이 발생하면 팝업 알림과 함께 자동으로 공수교대 기능을 실행.

- 볼 카운트 및 주자 상황판
    - BSO 카운터: 하단의 BALL, STRIKE, OUT 버튼을 누르면 상단 상황판에 직관적으로 표시.

    - 볼카운트 자동 판단 : 4볼이 되면 자동으로 볼넷 출루가 기록되고, 3스트라이크 시 아웃 처리되며, 3아웃 시 이닝 교체.

    - 주자 조작: 화면의 1루, 2루, 3루 베이스를 직접 터치하여 주자를 임의로 배치하거나 지울 수 있으며, 'Clear' 버튼으로 루상을 한 번에 비울 수 있음.

- 상황별 맞춤 의사결정 
    - 단순히 안타/아웃만 기록하는 것이 아니라, 현재 루상의 주자 상황을 앱이 스스로 인식하여 그 상황에 맞는 경우의 수만 창으로 띄워줌, 편하게 기록 가능.

    - 안타 (1루타~3루타): 예를 들어 주자 1루일 때 1루타를 누르면 '주자 1·2루 진루', '1루 주자 3루 도달', '선행주자 아웃(야수선택)' 등의 세부 선택지가 나타나 상황에 따른 세부적인 판단을 기록할 수 있음.

    - 땅볼/플라이: 병살타, 홈 포스아웃, 희생플라이 등의 상황을 쉽게 기록 가능.

    - 특수/실책: 빈루 시에는 실책 출루만 뜨지만, 주자가 있을 경우 폭투(WP), 패스트볼, 보크, 각 주자별 도루 및 견제사(CS), 타격 방해 등 특수 상황을 정교하게 기록 가능. 볼카운트가 유지되어야 하는 상황(예: 도루, 폭투 등)도 자동으로 계산.

- 실시간 경기 기록 및 추출
    - 히스토리: 방금 일어난 모든 플레이(볼카운트, 진루 상황, 액션 등)가 시간과 함께 화면 하단 리스트에 실시간으로 텍스트 중계처럼 기록됨.

    - 매치 리포트 추출: 경기 중이나 종료 후 'Match Report' 버튼을 누르면 전체 경기 공식 기록지 요약본을 볼 수 있으며, 이를 클립보드에 복사 하거나 텍스트 파일(.txt)로 기기에 저장 가능.

## 🎮 2. 게임

### 앱 이름

- 동작 따라하기 챌린지

### 배포 링크

- [동작 따라하기 챌린지](https://gemini.google.com/share/369113169f1b)

### 이 앱을 만든 이유

- 사람들 끼리 처음 만난 순간에 아이스 브레이킹을 해야하는 할 수 있는 간단하면서 재미있는 게임이 뭘까라고 생각해봤을 때, 몸으로 할 수 있는 우스꽝스러운 것이 있으면 좋겠다는 생각을 하여 만들게 됨.

### 주요 기능

- 맞춤형 게임 설정
    - 플레이어 관리: 1명부터 3명까지 참여 인원을 설정하고 각자의 이름을 입력하여 대결 구도를 만들 수 있음.

    - 난이도 조절: '동작 표현 시간' 슬라이더를 통해 5초에서 30초까지 제한 시간을 조절할 수 있어, 숙련도에 따른 게임 진행이 가능.

- AI 기반 실시간 미션 생성
    - 무한한 미션: 미리 정해진 목록에서 고르는 방식이 아니라, 게임이 시작될 때마다 Gemini AI가 독특하고 창의적인 동작을 만들어 제안.

    - 힌트 제공: 동작 이름과 함께 어떻게 표현해야 하는지 AI가 작성한 짧은 가이드를 함께 제공.  

- Gemini AI 활용 이미지 유사도 정밀 심사 
    - 시각적 분석: 촬영된 사진 데이터를 Gemini AI에게 전달하여, AI가 사진 속 인물의 자세를 분석.

    - 유사도 점수: 제시된 미션과 실제 포즈가 얼마나 일치하는지 0~100점 사이로 정교하게 채점.

    - 위트 있는 심사평: 점수와 더불어 "팔의 각도가 예술이네요!" 같은 재치 있는 한국어 피드백을 제공.
 
- 결과 발표 및 우승자 결정
    - 유사도 점수가 가장 높은 사람이 우승자로 선정됨.

### AI 기능

- 표현할 동작 문제를 내는 기능
    - Gemini API의 텍스트 생성 기능을 활용하여 더욱 창의적이고 다양한 동작을 출제할 수 있도록 함.

- 사용자가 표현한 동작과 출제 동작의 유사도 검증 기능
    - Gemini API의 Image Understanding 기능을 활용하여 출제 동작과 플레이어가 표현한 동작이 어느정도 일치하는지 유사도를 정확하게 검증할 수 있도록 함.

## 📚 3. 학습 앱

### 앱 이름

- Java Stream Learner

### 배포 링크

- [Java Stream Learner](https://gemini.google.com/share/2c45460bbac5)

### 이 앱을 만든 이유

- 프리코스 때 자바를 제대로 하면서 가장 생소하고 어려웠던 부분이 Stream이었음.

- Stream의 각 명령어가 어떤 역할을 하는지 모르는 사람들을 위해 Stream의 각 명령어가 어떤 기능을 하는지 쉽게 보여주는 앱이 있으면 좋겠다는 생각을 함.

- 또한 Stream은 반복 숙달을 해야 늘 것 같다는 개인적인 경험에 비추어, Stream의 명령어들을 반복 숙달할 수 있는 퀴즈 앱의 기능도 위에 기능과 같이 있으면 좋겠다는 생각을 하여 제작하게 되었음.

### 주요 기능

 - Stream 시각화 학습
    - Java Stream의 중간 연산과 최종 연산이 데이터를 어떻게 처리하는지 애니메이션을 통해 직관적으로 보여줌.

    - 다양한 명령어 지원: filter, map, flatMap, sorted 등 13개의 중간 연산과 forEach, collect, count, reduce 등 10개의 최종 연산까지 실무에서 자주 쓰이는 대부분의 명령어를 지원.

    - 커스텀 데이터 입력: 기본 제공되는 예시 데이터 외에도 사용자가 직접 1, 2, 3, 4 처럼 쉼표로 구분하여 원하는 데이터를 입력하고 테스트 가능.

    - 실제 동작 원리 구현 (시뮬레이션): 데이터가 하나씩 파이프라인을 통과하며 변환되거나 버려지는 과정을 눈으로 확인하며 이해 가능.

- 순서 맞추기 퀴즈
    - 특정 입력 데이터를 원하는 출력 데이터로 바꾸기 위해, 어떤 Stream 명령어들을 순서대로 조합해야 하는지 맞추는 실전 퀴즈를 해볼 수 있음.

    - AI 기반 무한 문제 생성: Gemini API를 연동하여 고정된 문제가 아닌, 매번 새로운 숫자 및 문자열 처리 문제를 무작위로 생성하여 제공.

    - 드래그 앤 드롭 인터페이스: 화면에 흩어진 Stream 명령어 블록을 마우스로 드래그하여 원하는 순서대로 배치하여 문제를 해결.

### AI 기능

- 문제 출제 기능
    - 여러 문제를 랜덤으로 계속 출제하기 위해 Gemini API를 사용하여 매번 새로운 퀴즈를 제공할 수 있도록 함.

## 🤝 4. 페어 프롬프트 릴레이 앱

### 앱 이름

- AlgoStrategy

### 페어
- 제이콥(조경현) @khcho96

### 배포 링크

- [AlgoStrategy](https://gemini.google.com/share/1415af18242d)

### 이 앱을 만든 이유

- PS를 할 때, 개인적으로 중요하다고 생각하는 부분이 해당 문제에 어떤 알고리즘을 사용해야할 지 고르는 것이라고 생각함.

- 하지만, 이를 키우려면 많은 문제를 풀어봐야하고, 많은 시간이 들기 때문에 문제를 풀지않고 이 능력을 키울 수 있는 앱이 있었으면 좋겠다고 생각함.

- 모바일로 문제를 보면서 사용할 알고리즘을 생각해보고, 이를 피드백 받는 것만으로 시간을 효율적으로 쓰면서 PS 능력을 키울 수 있을 것이라고 생각하여 이 앱을 개발하게 됨.

### 주요 기능
- 맞춤형 난이도 선택 및 실시간 문제 탐색
    - 세밀한 난이도 분리: 사용자의 실력에 맞춰 초급, 중급, 고급 3단계 중 하나를 선택 가능.
        - 초급: 백준 브론즈 5 ~ 1, 실버 5 ~ 3 / 프로그래머스 Lv 1 ~ 2
        - 중급: 백준 실버 2 ~ 1, 골드 5 ~ 3 / 프로그래머스 Lv 2 ~ 3
        - 고급: 백준 골드 2 ~ 1, 플래티넘 5 ~ 4 / 프로그래머스 Lv 3 ~ 4
    - 실존 기출 문제 실시간 검색: DB에 저장된 문제를 꺼내는 것이 아니라, Gemini가 구글 검색을 통해 현재 백준/프로그래머스에 존재하는 실제 문제를 실시간으로 찾아옴.
    - 중복 출제 방지 로직: 한 번 풀었던 문제의 제목을 기억하여, 다음번 검색 시 똑같은 문제가 다시 나오지 않도록 차단.
- 가독성 높은 문제 렌더링 및 전략 퀴즈
    - 3단 분리 UI: 복잡한 문제 원문을 `문제 설명`, `입력`, `출력` 세 가지 깔끔한 카드로 완벽하게 분리하여 표현.
    - 수식 및 마크다운 완벽 지원: 코딩 테스트 문제에 자주 등장하는 복잡한 수학 수식($N^2$, $\sum$ 등)을 MathJax를 통해 깨짐 없이 렌더링하며, 입출력 예시 등은 마크다운 코드 블록으로 깔끔하게 표시.
    - 핵심 전략 6지선다 퀴즈: AI가 해당 문제를 풀기 위한 6개의 아주 구체적인 알고리즘 접근법을 제시. 사용자는 이 문제에 사용해야 할 것 같은 접근법을 선택.
- AI 심층 분석 리포트 제공 
    - 사용자가 전략을 선택하고 제출하면, AI가 사용자의 선택을 채점하고 다음과 같은 3단계 심층 리포트를 제공합니다.
        - 전략 판단 근거: 사용자가 선택한 방법이 맞는지 틀렸는지 알려주고, 특히 **데이터의 범위($N$의 크기)**에 따른 시간 복잡도를 계산하여 왜 그 알고리즘을 써야만 하는지 논리적인 근거를 제시.
        - 단계별 알고리즘 설계: 정답을 맞히기 위해 코드를 어떤 순서(1단계, 2단계...)로 짜야 하는지 논리적인 설계 프로세스를 제시.
        - 핵심 마스터리 개념: 해당 문제를 완벽히 이해하기 위해 알아야 하는 핵심 CS/알고리즘 이론을 요약, 사용자는 이를 통해 몰랐거나 부족한 알고리즘을 공부할 수 있음.

### AI 기능

- 문제 출제 기능 
    - Gemini 의 검색 API를 활용하여 백준, 프로그래머스의 특정 난이도 문제를 랜덤으로 가져오게 함.

- 심층 분석 리포트 제공 기능
    - Gemini가 사용자가 고른 알고리즘이 문제에 적합한지를 판단하고, 그 문제의 접근법을 제공함. 
    - 추가적으로 그 알고리즘에 대한 해설도 Gemini의 검색 API를 사용하여 제공함.

### 릴레이 프롬프트 회고
- 프롬프트의 스타일을 맞추자.
    - 결국 프롬프트는 언어적 표현.
    - 사람 개인개인의 글 쓰는 습관이 들어갈 수 밖에 없다.
    - 프롬프트를 쓰는 스타일이 달라서 그것을 맞추는 것이 중요하다고 생각함.
    - 그래서 프롬프트를 쓰는 규칙을 정하는 것이 AI에게 일관적인 답을 기대할 수 있다고 생각했음.
    - 따라서, 제이콥과 페어로 프롬프트를 짤 때, 규칙을 정하고 프롬프트을 짰음.
        - 특정 기능을 구현할때는 그 기능에 대한 설명과 함께 특정 예시를 첨부한다.
        - 특정 기능에 오류가 생겼을 경우에는 기댓값과 반례를 들어 설명을 추가적으로 덧붙인다.
        - Gemini AI API 등 기능을 들고 올 때에는, 사용해야할 도구를 명시한다.
    - 이런 규칙을 정하고 프롬프트를 짜니, 더욱 완성도가 있는 프롬프트가 나왔고, 서로 프롬프트에 대해 피드백하기가 좋았다고 생각함.

### 2. 프롬프트 개선 과정

- 처음 결과물의 문제점은 무엇이었나요?
    - 특정 동작을 랜덤으로 골라야하는데, 이를 정해진 리스트 내에서만 뽑아서 확장성이 부족했음.
    - 동작과의 유사도를 AI가 아닌 JS 내부 함수로 구현하려고 하여 이미지의 유사도 판단이 제대로 되지 않았음.
- 어떤 식으로 프롬프트를 수정했나요?
    - 특정 동작을 고르는 과정에서 AI Agent를 사용하여 고르라고 명시했음.
    - AI Agent를 사용하려고 하는 부분에 Gemini AI API를 사용하라고 사용하려는 API를 명확하게 이야기함.

- 몇 번의 반복을 거쳤나요?
    - 5번의 반복을 거쳤음.
    - 기능의 부족함이 있으면 수정하고, 추가하는 것이 주요 반복의 내용.
