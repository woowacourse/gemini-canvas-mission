💡 주요 개념 요약
  • SSR (서버 사이드 렌더링): 사용자가 요청할 때마다 서버에서 데이터를 새로 가져와 HTML을 만듭니다. 항상 최신 데이터를 보장하지만, 서버 부하가 있고 응답 시간이 다소 길 수 있습니다.
  • SSG (정적 사이트 생성): 빌드(Build) 시점에 한 번만 HTML을 만들어 둡니다. 요청이 오면 만들어둔 HTML을 즉시 반환하여 매우 빠릅니다.
  • ISR (증분 정적 재생성): 기본적으로 SSG처럼 동작하여 빠르지만, 설정된 시간(revalidate)이 지나면 백그라운드에서 데이터를 새로고침하여 캐시를 업데이트합니다.
