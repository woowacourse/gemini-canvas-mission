## 앱 이름: Youtube Shorts Counter (Shorts Tracker)
## 카테고리: 유틸리티 앱 (Chrome Extension)

### 배포 링크
현재 크롬 익스텐션 스토어 심사 중

### 이 앱을 만든 이유
- 짧은 영상(특히 유튜브 쇼츠)을 보다 보면 시간 감각을 잃고 과도하게 소비하게 되는 문제가 있음.
- 쇼츠는 UX 특성상 “끊기 어렵게 설계된 콘텐츠”라서 자기 통제가 어려운 경우가 많음.
- 단순 차단 앱이 아니라, 사용자가 스스로 소비량을 인지하고 조절할 수 있는 ‘피드백 도구’를 만들고자 하였음.

사용 시나리오:
- 집중해야 하는 날에 쇼츠 소비량 관리
- 공부/개발 몰입 중 디지털 디톡스 보조 도구
- 습관 트래킹 용도 (자기관리/미니멀 디지털 라이프)

---

### 주요 기능
- 유튜브 쇼츠 시청 개수 자동 카운트
- 일일 시청 제한 설정 기능
- 제한 도달 시 브라우저 알림 제공
- 최근 7일 시청 통계 시각화 (주간 트래킹)
- 전체 데이터 초기화 기능
- ON/OFF 토글로 간단한 활성화 제어

## 프로젝트 구조

```txt
.
├── manifest.json
├── background.js        # 알림, 탭 감지 등
├── popup.html           # 팝업 UI
├── popup.js             # 팝업 로직 (카운트/설정/통계 렌더링)
└── icon.png             # 확장 프로그램 아이콘 (128x128)
```

## 설치 방법 (개발용 로드)

1. 이 레포를 다운로드/클론
   ```bash
   git clone https://github.com/<YOUR_ID>/youtube-shorts-counter.git
   ```

2. Chrome 주소창에 아래로 이동  
   ```
   chrome://extensions
   ```

3. 우측 상단 **개발자 모드** ON

4. **압축해제된 확장 프로그램을 로드** 클릭

5. 프로젝트 폴더(`manifest.json`이 있는 폴더)를 선택

설치가 완료되면 툴바에서 확장 프로그램 아이콘을 눌러 팝업을 확인

---

## 사용 방법

1. 확장 프로그램 팝업에서 우측 상단 스위치를 켭니다. (켜짐/꺼짐)
2. "일일 시청 제한"에 숫자를 입력하고 **설정** 클릭
3. 유튜브 쇼츠를 시청하면 카운트가 증가
4. 제한에 도달하면 알림 발생
5. 통계 탭에서 최근 7일 기록과 주간 총 시청을 확인

---

## 권한(permissions) 설명

`manifest.json` 기준으로 아래 권한을 사용

- `storage` : 일일 카운트, 제한 값, 주간 기록 저장
- `tabs` : 유튜브 쇼츠 탭/URL 감지 및 카운트 트리거
- `notifications` : 제한 도달 시 알림 표시
