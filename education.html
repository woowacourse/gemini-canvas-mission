💡 MVC란 무엇인가?

Model (모델) 애플리케이션의 데이터와 비즈니스 로직을 담당합니다. (Service, Repository, Entity 등)
View (뷰) 사용자에게 보여지는 화면이나 출력 데이터입니다. (Thymeleaf, JSP, JSON 등)
Controller (컨트롤러) 사용자의 요청을 수신하고 모델과 뷰 사이에서 흐름을 제어합니다.
