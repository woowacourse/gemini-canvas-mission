# 🎲 3D SHELL GAME
### 배포 링크: https://gemini.google.com/share/b947eec522cb

### 프로젝트 개요

'3D SHELL GAME'는 사용자의 순간적인 집중력을 테스트하고 시각적 추적 능력을 길러주는 인터페이스 중심의 웹 애플리케이션입니다. 단순히 운에 맡기는 게임이 아니라, 컵의 이동 속도와 패턴을 단계별로 조절하여 사용자가 몰입 상태를 경험하고 짧은 시간 내에 정신을 맑게 깨울 수 있도록 돕는 집중력 강화 도구로도 사용할 수 있습니다.

### 목표 사용자

- 짧은 게임을 통해 자신의 관찰력과 집중도 상태를 체크하고 싶은 사람
- 복잡한 규칙 없이 직관적인 즐거움을 원하는 사용자

### 핵심 기능 요구사항

#### 1. 게임 환경 및 난이도 설정

사용자가 자신의 집중도 수준에 맞춰 게임의 난이도를 정의하는 단계입니다.

- **단계별 난이도 구성:** 컵의 개수(3개~5개)와 섞이는 속도, 섞이는 횟수를 조절하여 초보자부터 전문가 모드까지 설정 가능합니다.
- **시각적 테마 선택:** 사용자의 눈 피로를 줄이기 위한 다크 모드/라이트 모드 및 컵과 공의 색상 커스터마이징 기능을 제공합니다.

#### 2. 인터랙티브 게임 실행 및 판정

실제 게임이 진행되는 핵심 인터페이스입니다.

- **애니메이션 시퀀스:** 공이 특정 컵에 들어가는 모습을 먼저 보여준 뒤, 컵들이 무작위로 위치를 바꾸는 애니메이션을 부드럽게 구현합니다.
- **사용자 선택 및 결과 피드백:** 섞기가 끝난 후 사용자가 컵을 클릭하면 해당 컵이 들리며 공의 유무를 확인합니다. 성공 시 축하 효과음/이펙트를, 실패 시 공이 있었던 위치를 강조하여 보여줍니다.
- **연속 성공 기록:** 사용자가 틀리지 않고 연속으로 맞춘 횟수를 기록하여 성취감을 고취합니다.

### 구현 및 프로그래밍 제약 조건

- **AI 도구 제한**: 오직 Gemini Canvas만을 사용하여 코드를 생성합니다. 다른 AI 코딩 어시스턴트는 사용하지 않습니다.
- **프롬프트 엔지니어링 훈련**: 직접 코드를 짜기보다, 명확한 성공 기준과 제약 조건을 포함한 프롬프트 지시어만으로 유용한 앱을 완성하는 것을 목표로 합니다.
- **기술 스택**: HTML5, CSS3, JavaScript만 사용합니다. React 등 어떠한 프론트엔드 프레임워크나 빌드 도구도 사용하지 않습니다.
