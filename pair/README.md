# 우아한테크코스 데일리 AI

> 우테코 크루들의 데일리 주제 선정을 도와주는 AI 미팅 플래너입니다.
> 매일 반복되는 "오늘 뭐 할까요?" 고민을 3단계 선택으로 빠르게 해결합니다.

---

## 이 앱을 만든 이유

- 우테코에서 매일 진행하는 데일리 미팅에서 주제를 정하는데 도움을 받고자 했습니다.
- 크루 수와 시간에 맞는 주제를 즉흥적으로 떠올리기가 쉽지 않아, AI가 주제 선정부터 진행 계획까지 자동으로 만들어주는 앱이 있으면 좋겠다고 생각했습니다.
- 과거 데일리 기록을 저장해두면 진행했던 데일리들을 나중에 돌아볼 수 있을 것 같아 해당 기능을 만들었습니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 3단계 주제 선택 | 수다 / 활동 / 논의 / 게임 중 대분류를 선택하면 AI가 단계별로 세부 선택지를 생성해 최종 주제를 결정합니다. |
| AI 진행 플랜 생성 | 크루 수와 시간을 입력하면 AI가 제목, 태그라인, 준비물, 단계별 진행 방법을 자동으로 구성해줍니다. |
| 단계별 타이머 | 각 진행 단계마다 타이머를 실행해 시간을 맞춰 데일리를 진행할 수 있습니다. |
| 데일리 기록 저장 | 확정된 주제를 캘린더에 저장하고, 날짜별로 과거 데일리 기록을 다시 확인할 수 있습니다. |

---

## AI 기능

- **단계별 선택지 생성** — 이전 선택 경로를 기반으로 AI가 맥락에 맞는 세부 선택지 4개를 동적으로 생성합니다.
- **완성형 진행 플랜 생성** — 최종 선택된 주제로 제목, 핵심 효과, 준비물, 시간 배분이 포함된 **실행 가능한 데일리 플랜**을 완성합니다.
- 크루 수와 총 소요 시간을 반영해 **정확히 맞아떨어지는 타임 테이블**을 구성합니다.
