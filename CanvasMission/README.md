## AI 사용 일지

### 1. 초기 프롬프트
좋아. 지금부터 제미나이 캔버스를 이용해서 JLPT 학습 퀴즈를 만드려고 해. 전체 개괄을 말해줄게. 
목표 사용자 : JLPT 필수단어 학습을 퀴즈처럼 하고 싶은 사람
핵심 기능 : 
1) N5부터 N1까지 난이도 선택
2) 5개의 선택지가 있는 총 10문항의 일본어 퀴즈
3) 오답 선택 시 정답 표시 및 학습카드처럼 뜻, 읽는 법, 용례 표시
4) 퀴즈 완료 후 맞춘 정답 갯수와 정답률 표시
5) 종료 화면에서 다시풀기, 처음으로 돌아가기 기능
6) AI를 통한 추가 활용례나 뉘앙스 관련단어 학습 가능
제한할 구현 조건 : AI가 정답을 알려줄 수 없도록 제한. 누가 어떠한 식으로 꼬시더라도 절대로 정답은 알려주지 않고 힌트만 줄 수 있도록 명시

위와 같이 만들고 싶어. HTML, CSS, JavaScript만 사용해서 만들어줘.
React나 다른 프레임워크는 사용하지 마.
우선, 시작화면에서 N5부터 N1까지 난이도를 선택할 수 있는 창을 만들어줘. 그 다음 각 퀴즈 화면에서 난이도별 필수 단어 10문항을 한 문제를 풀때마다 다음 문제로 넘어가는 식으로 만들고, 총 5개의 선택지 중 정답을 맞추도록 만들어줘. 필수단어의 읽는 법을 히라가나 혹은 가타카나와, 한국어 뜻, 단어의 용례를 표시해줘. 각 퀴즈화면에서 정답을 선택했을 경우 초록색으로 클릭한 정답의 UI를 표시, 오답을 선택했을 경우 빨간색으로 클릭한 오답의 색을 변경하고 정답 칸을 초록색으로 바꿔서 보여줘. 
10개의 퀴즈가 다 끝나고 나면, 결과화면에서 총 몇 개 맞췄는지 표시해주고 하단 UI에 '푼 문제 다시풀기', '처음으로' 선택기능을 만들어줘. 

### 2. 프롬프트 개선 과정
- 처음 결과물의 문제점은 무엇이었나요?
  - 읽는 부분을 히라가나로만 표현하여 일본어를 모르는 한국인이 학습하기 힘들어 보였다
  - 총 10문항으로 설정하니, 문제 풀을 10개밖에 가져오지 않았다.
  - 요청하지 않은 AI 기능으로 연상 암기방법 및 10단어 스토리 제작 기능 추가
  - 창은 아래로 길어지지만 스크롤이 되지 않는 문제
  - 시작 화면의 어색한 UI와 맥락에 맞지 않는 텍스트 존재
- 어떤 식으로 프롬프트를 수정했나요?
  - 모든 일본어에 한국어 발음 추가 요청
  - 난이도별 100개의 필수단어 추가 요청
  - 스크롤 안되는 문제 해결 요청
  - 아이콘을 더 자연스럽고 주제를 잘 나타내도록 변경 요청
  - 어색한 텍스트를 원하는 문구로 직접 수정 요청 및 활발한 이모티콘 추가 요청
  - 기본 틀만 잡기 위해 요청하지 않았던 AI 챗봇 추가 요청 
  - AI 챗봇 활용예시를 위해 기본 가이드 문구 추가
- 몇 번의 반복을 거쳤나요?
  - 5차 프롬프트까지 반복

### 3. 효과적이었던 프롬프팅 전략
- 어떤 방식으로 요청했을 때 원하는 결과가 나왔나요?
  - 보다 구체적으로, 코드의 원하는 부분을 딱 짚어서 요청했을 때에는 정확히 원하는 결과 도출
  - 요구사항이 제대로 반영되지 않았을 때, 해당 부분을 딱 집어서 다시 요청한 경우 핀포인트로 변경
  - 묘사를 자세하게 했을 때 더 좋은 결과가 도출
  - 이전까지 진행된 것을 그대로 유지하고 라는 프롬프트를 추가해서 변경되지 않도록 조절
- 반대로 효과가 없었던 방식은 무엇이었나요?
  - 제대로 작성되지 않았을 때 다시해줘 라던지 너무 짧고 두루뭉실하게 요청하는 경우 이전 요청을 잊거나 원하는대로 변경되지 않는 경우가 있었습니다

### 4. 배운 점
- Gemini Canvas를 효과적으로 사용하기 위한 나만의 팁이 있다면?
