## 💪 1. 유틸리티 앱 : 혈자리 가이드  
### 배포 링크
https://gemini.google.com/share/40bf6228efcb

<br> 

### 이 앱을 만든 이유
- **어떤 문제/불편함을 해결하려고 했나요?** <br>
: 근육통이나 통증이 있을 때 매번 검색을 하고 혈자리를 찾는 것이 귀찮게 느껴질 수 있다. 직관적인 인터랙션으로 통증 부위에 맞는 혈자리를 찾도록 해결하고자 했다.

- **이 앱을 언제, 어떻게 사용할 건가요?** <br>
: 목 ,어깨,허리 등 통증이 발생했을 때 신체 모형에서 아픈 부위를 선택하고 증상을 고르면 완화 가능한 혈자리와 지압 방법을 확인하는 용도로 사용한다.

<br>

### 주요 기능
- 상세 통증 위치 선택
- 증상 선택 기반 혈자리 추천
- 간단 지압 방법 안내

## 🐰 2. 게임 : 바니런  
### 배포 링크
https://gemini.google.com/share/def36e231387

<br> 

### 이 앱을 만든 이유
- **어떤 문제/불편함을 해결하려고 했나요?** <br>
: 수업이나 회의 시간에는 키보드나 마우스를 사용하기 어려우므로 입력 장치 없이도 플레이할 수 있는 게임을 만들고자 했다.

- **이 앱을 언제, 어떻게 사용할 건가요?** <br>
: 웹캠을 켜둔 상태에서 눈 깜빡임만으로 캐릭터를 점프시키며 장애물을 피하는 간단한 러닝 게임으로 사용한다.

<br>

### 주요 기능
- 눈 깜빡임 기반 점프 조작
- 장애물 회피 러닝 게임
- 하트 생명 시스템
- 거리 기반 점수 표시 및 게임 오버 화면

## ☕ 3. 학습 앱 : Java Quiz  
### 배포 링크
https://gemini.google.com/share/527821a64d95

<br> 

### 이 앱을 만든 이유
- **어떤 문제/불편함을 해결하려고 했나요?** <br>
: 출퇴근 시간 같은 짧은 시간에 공부하고 싶어도 문제를 찾거나 준비하는 과정이 번거롭다. 카테고리 선택만으로 바로 문제를 풀 수 있도록 만들어 학습 진입 장벽을 낮추고자 했다.

- **이 앱을 언제, 어떻게 사용할 건가요?** <br>
: 이동 중이나 대기 시간에 카테고리를 선택해 생성된 자바 문제를 풀고 해설을 확인하는 용도로 사용한다.

<br>

### 주요 기능
- 카테고리 선택 기반 문제 생성
- 10문제 풀이 및 정답 확인
- 해설 제공 및 반복 학습
