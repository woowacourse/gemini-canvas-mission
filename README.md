## 5. 화면 구성

### 5.1 디자인 콘셉트

macOS 런치패드(Launchpad)를 모티브로 한 다크 테마 인터페이스. 어두운 배경 위에 아이콘들이 그리드로 배치되며, 아이콘을 클릭하면 하단에 상세 정보 패널이 나타나는 구조이다.

### 5.2 레이아웃 구조

| 영역            | 구성 요소                                              |
| --------------- | ------------------------------------------------------ |
| 상단 바         | 타이틀 (“우테코 포털”) + [+] 자료 추가 버튼            |
| 아이콘 그리드   | 이모지 아이콘 + 자료 제목 (macOS 런치패드 스타일 배치) |
| 상세보기 패널   | 선택한 자료의 제목 + [열기] 버튼 + [삭제] 버튼         |
| 모달 (오버레이) | 자료 추가 입력 폼                                      |

### 5.3 아이콘 구성

각 아이콘은 macOS 앱 아이콘과 유사한 둥근 사각형 형태로 표현한다.

**아이콘 영역:** 둥근 모서리 사각형(rounded square) 배경 + 중앙에 이모지
**제목 라벨:** 아이콘 하단에 자료 제목 표시 (1줄, 초과 시 말줄임)
**그리드 배치:** 반응형 그리드, PC에서 한 줄에 5~6개, 모바일에서 3~4개
**호버/선택 효과:** 호버 시 밝기 변화, 선택 시 강조 테두리 또는 배경

### 5.4 상세보기 패널

아이콘 그리드 하단에 위치하며, 아이콘 클릭 시 슬라이드 또는 페이드 애니메이션으로 나타난다.

**제목:** 선택한 자료의 전체 제목
**[열기] 버튼:** 클릭 시 외부 URL을 새 탭에서 열기
**[삭제] 버튼:** 클릭 시 확인 후 해당 자료 삭제

### 5.5 자료 추가 폼 (모달)

[+] 버튼 클릭 시 모달이 열리며, 다음 항목을 입력한다.

| 필드 | 필수 | 설명                               |
| ---- | ---- | ---------------------------------- |
| 제목 | Y    | 자료명 (아이콘 하단에 표시될 이름) |
| URL  | Y    | 외부 링크 주소                     |

저장 시 아이콘 그리드에 새 아이콘이 즉시 추가된다. 이모지는 기본 아이콘(:pushpin:)으로 자동 지정한다.

### 2. 프롬프트 개선 과정

- 처음 결과물의 문제점은 무엇이었나요?
  1. 원하는 로고 이미지 구현 불가
  2. 사파리 브라우저(M1 에어 기준)에서 특정 아이콘 클릭 시 흰 화면이 발생하는 현상
- 어떤 식으로 프롬프트를 수정했나요?
  1. 외부 이미지 대신 벡터(SVG) 형식을 활용하여 로고를 직접 구현하도록 수정
  2. 오류의 정확한 원인 분석을 AI에게 요청한 뒤, 그 결과를 바탕으로 수정 지시
- 몇 번의 반복을 거쳤나요?
  7번 이상

### 3. 효과적이었던 프롬프팅 전략

- 어떤 방식으로 요청했을 때 원하는 결과가 나왔나요?
  기획서의 디테일이 부족할 수 있음을 고려하여,AI에게 주요 기능을 기준으로 기획서 작성을 부탁하고 AI에게 부족한 점을 묻고 내용을 보완했습니다. 그 후 캔버스 작업을 시작하니 원하는 동작이 정확하게 구현되었습니다.
- 반대로 효과가 없었던 방식은 무엇이었나요?
  미흡 사례: 지시 대상이 불분명하여 의도와 다른 결과가 도출됨
  (예: 이미지를 지워줘" 등 범위가 넓은 명령)
  개선 방안: 객체의 명칭과 위치 정보를 포함하여 지시의 정확도 향상
  (예: 상단 헤더 영역 우측 로고 이미지 삭제"와 같이 구체화)
