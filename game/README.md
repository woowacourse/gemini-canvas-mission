# 🏎️ 회전 카트 랠리 [🔗](https://gemini.google.com/share/b891cd0efc45)

> "눈보다 빠른 손가락의 전쟁!"
>
> 찰나의 순간, 회전하는 이미지 속에서 정답을 찾아내는 우정 파괴 로컬 멀티플레이 게임

### 📋 프로젝트 소개

회전 카트 랠리는 닌텐도의 '마리오 파티' 미니게임을 오마주하여 제작된 웹 기반 캐주얼 게임입니다.

단순히 똑같은 그림을 찾는 것을 넘어, 모든 이미지가 고속으로 회전하는 상황에서 미세한 실루엣의 차이를 포착해야 합니다. 단 10초의 제한 시간 동안 친구들과 키보드 하나를 나누어 쓰며 펼치는 박진감 넘치는 순발력 대결을 경험해 보세요.

### ✨ 핵심 기능

1. **초고속 회전 매칭 시스템**

- 동적 감속 엔진: 10초의 카운트다운 동안 이미지가 빠르게 회전하다가 시간이 흐를수록 서서히 멈추며 정답이 드러나는 긴장감을 제공합니다.

- 정밀한 형태 변별: 단순히 색깔이 아닌 깃발의 곡률, 로켓의 불꽃 갈래, 로봇의 눈 모양 등 찰나의 순간에 형태적 특징을 포착해야 하는 높은 몰입감을 선사합니다.

- 랜덤 문제 은행: 총 8종의 엄선된 이미지 세트 중 매 게임마다 3라운드가 무작위로 출제되어 매번 새로운 플레이 경험을 제공합니다.

2. **로컬 멀티플레이 난투**

- 최대 4인 대결: 별도의 장비나 네트워크 연결 없이 키보드 하나로 최대 4명이 동시에 접속하여 즉석 대결이 가능합니다.

- 실시간 선착순 점수제: 정답을 먼저 맞힌 순서대로 차등 점수가 부여되어 플레이어 간의 치열한 심리전과 순발력 경쟁을 유도합니다.

3. **마리오 카트 스타일 테마 UI**

- 비주얼 오마주: 화려한 원색 테마, 체크무늬 레이싱 깃발, 트랙 배경 등을 통해 마치 실제 카트 레이싱을 즐기는 듯한 신나는 분위기를 연출했습니다.

- 다이나믹 HUD: 상단 스코어보드를 통해 플레이어의 점수와 답변 상태를 실시간으로 확인하고, 라운드 종료 시 화려한 우승 세레머니를 제공합니다.

4. **유동적인 반응형 레이아웃**

- 3단계 세로 반응형: 화면 높이(Height)에 따라 UI 요소들의 크기가 유기적으로 조절되는 특수 미디어 쿼리를 적용하여, PC부터 모바일 가로 모드까지 모든 환경에서 잘림 없는 플레이가 가능합니다.
