# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 앱 소개
### 1. 유틸리티 앱 - QuestTracker
#### https://gemini.google.com/share/7bd14d3ba52d
```
🎮 퀘스트 트래커 (Quest Tracker)

퀘스트 트래커는 여러 게임의 일일, 주간, 월간 숙제를 한눈에 관리하는 심플한 웹 기반 일정 관리 프로그램입니다.

💡 언제 사용하나요?

복잡한 RPG 게임 숙제(일일/주간/월간)를 한곳에서 관리할 때

영양제 섭취, 운동 등 반복적인 일상 루틴을 체크할 때

언제든지 게임을 켜지 않고 진행 상황을 확인하고 싶을 때

✨ 주요 기능 요약

🕹️ 게임별 카드 관리: 게임 단위로 숙제 카드를 만들고 목록을 무한히 추가할 수 있습니다.

⏰ 완벽한 자동 초기화: 설정된 주기에 맞춰 체크박스가 자동으로 해제됩니다. (일일 00시, 주간 월요일 00시, 월간 1일 00시)

☁️ 클라우드 자동 저장: 사용자별 고유 공간에 실시간으로 데이터가 동기화되어, 언제 다시 접속해도 그대로 유지됩니다.

☁️ 로컬 자동 저장: 클라우드를 사용할 수 없는 상황에서도, html 파일 하나만으로 로컬 데이터가 저장됩니다.

✏️ 직관적인 텍스트 편집: 복잡한 창 이동 없이, 텍스트를 클릭해 즉시 내용을 수정할 수 있습니다.

### 2. 게임 - JLPTQuizGame
#### https://gemini.google.com/share/abdeabda25f8
```
🌸📚 JLPT AI 퀴즈 게임

"제미나이(Gemini) AI와 함께 뉘앙스까지 마스터하는 JLPT 단어 학습 게임 앱"

JLPT N5~N1 필수 단어를 퀴즈로 풀고, AI 튜터와 실시간으로 대화하며 깊이 있게 학습할 수 있는 인터랙티브 웹 애플리케이션입니다. 단순 암기를 넘어 문맥과 뉘앙스 중심의 맞춤형 학습을 제공합니다.

✨ 핵심 기능 (Key Features)

🎯 수준별 단어 퀴즈

N5(입문) ~ N1(마스터) 레벨별 필수 단어 5지 선다형 퀴즈 (총 250단어 내장)

정답 시 발음, 뜻, 예문이 담긴 '학습 플래시카드' 제공

🤖 실시간 AI 튜터 (Gemini 연동)

화면 우측에 상시 대기하는 챗봇에게 단어의 뉘앙스, 유의어, 힌트 등을 실시간 질문

강력한 프롬프트 제어로 정답은 절대 알려주지 않고 힌트만 제공하여 스스로 학습 유도

🧠 AI 연상 암기 비법 생성

잘 안 외워지는 단어는 버튼 한 번으로 재치 있는 '연상 암기 문장' 즉석 생성 (예: 다베루 -> 다 배부를 때까지 먹다)

📖 맞춤형 복습 이야기 (Storytelling)

퀴즈 완료 후, 방금 푼 10개의 단어를 모두 활용한 '짧은 일본어 스토리(해석 포함)'를 AI가 창작하여 문맥 속 복습 지원

### 3. 학습 앱 - AsyncLearningQuiz
#### https://gemini.google.com/share/1589e16e1357
```
🚀 JS 비동기 마스터 퀴즈

우테코 프론트엔드 크루들을 위한 자바스크립트 비동기 동작 원리 완벽 정복 퀴즈 앱입니다.
바닐라 JS(HTML/CSS/JS)만으로 가볍고 빠르게 구현되었습니다.

🎯 제작 목적

자바스크립트의 가장 큰 장벽인 '비동기(Asynchronous)' 흐름을 직관적으로 이해하기 위해 만들어졌습니다.
단순한 문법 암기를 넘어, 이벤트 루프(Event Loop), 콜 스택(Call Stack), 그리고 큐(Macrotask/Microtask Queue)의 우선순위를 정확히 짚고 넘어갈 수 있도록 설계했습니다. "이게 왜 먼저 찍히지?"라는 궁금증을 해소해 보세요!

💡 언제 사용하나요?

- 개념이 헷갈릴 때: Promise, setTimeout, async/await의 실행 순서가 머릿속에서 엉킬 때

- 크루들과 토론할 때: 페어 프로그래밍 중 비동기 관련 주제로 깊게 딥다이브(Deep Dive)하고 싶을 때

- 면접/미션 대비: 프론트엔드 CS 기본기인 자바스크립트 엔진의 동작 원리를 빠르고 확실하게 복습하고 싶을 때

✨ 주요 기능

🎲 랜덤 셔플 출제: 25개의 문제 은행에서 원하는 개수(5, 10, 20, 전체)를 선택하면 문제와 보기가 매번 새롭게 섞여 출제됩니다.

💡 즉각적인 피드백과 해설: 정답/오답 여부는 물론, "왜 그런지" 이유를 설명해 주는 상세한 해설을 바로 확인할 수 있습니다.

🔄 효율적인 복습: 결과 화면에서 내가 방금 푼 문제 세트만 다시 풀어보며 약점을 보완할 수 있습니다.

⚡ Zero Dependency: 어떤 프레임워크나 라이브러리 설치 없이, index.html 파일 하나만 열면 브라우저 환경에서 즉시 실행됩니다.
```
