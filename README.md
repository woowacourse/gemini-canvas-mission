# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 1.유틸리티 앱 💻

### 앱 이름: 스마트 메모장
### 카테고리: 유틸리티 앱

### 배포 링크
https://gemini.google.com/share/8d79f79ae357

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?   
  꼼꼼하게 기록해야 한다는 부담감 때문에 오히려 정리를 미루게 되는 불편함을 해결하고 싶었습니다. 메모장에 아무렇게 적어놓은 파편화된 정보라도 AI가 즉각적으로 구조화하고 요약해 준다면, 사용자는 기록에 대한 부담 없이 언제든 필요한 정보를 시각적으로 편하게 확인하고 다음 할 일을 추천받을 수 있습니다.
- 이 앱을 언제, 어떻게 사용할 건가요?   
  페어 프로그래밍이나 팀 프로젝트 중 발생하는 수많은 아이디어와 결정 사항들을 잊어버리지 않게 그때그때 기록합니다. 회의나 작업이 끝난 후 산만하게 적힌 메모들을 AI 요약 기능을 통해 핵심 인사이트와 얻을 계획입니다.

### 주요 기능
- 기능 1   
    필요한 메모 제목과 내용을 저장합니다.
- 기능 2   
    저장된 메모를 수정하고 삭제합니다.
- 기능 3   
    가독성 없이 아무렇게나 적어놓은 기록을 ai가 내용 다듬기, 핵심 포인트, 할일 추천을 통해 정리합니다.
- 기능 4   
    메모가 여러 개 존재하는 경우 ai 전체 요약을 누르면 모든 메모를 3-4줄 정도로 간단하게 요약해줍니다.

### AI 기능 (해당되는 경우)
- 어떤 AI 기능을 추가했나요?   
    적어놓은 메모를 요약해주는 기능입니다. 

- AI 기능이 앱에서 어떤 역할을 하나요?   
  메모장에 산만하게 적힌 기록들을 AI가 가독성 있게 다듬고 핵심 포인트 3~4가지로 간다한게 요약합니다. 단순히 정리에서 끝나는 것이 아닌 기록된 내용을 심층 분석하여 사용자가 지금 바로 실천해야 할 일을 우선순위에 따라 추천함으로써 일정 관리를 돕습니다.

## 3. 학습 앱 📚
### 앱 이름: 자바 튜토리얼
### 카테고리: 학습 앱

### 배포 링크
https://gemini.google.com/share/32fa97075a52

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?   
  자바와 프레임워크를 학습하며 생소한 개념이나 문법을 마주할 때, 구글링 후 노션에 옮겨 적는 기존의 수동적인 방식의 불편함을 해결하기 위해 AI가 복잡한 개념을 시각적인 인포그래픽으로 구조화하고 학습한 내용을 점검할 수 있는 맞춤형 퀴즈를 생성하게 했습니다.
- 이 앱을 언제, 어떻게 사용할 건가요?   
  기존에 저장된 개념들을 AI가 생성한 맞춤형 퀴즈로 풀어보며 부족한 부분을 반복적으로 점검할 계획입니다. 또한, 학습 범위가 넓어지면서 생소한 개념이나 기술 스택이 생기면 새로운 분야를 추가하고 카테고리화 할 계획입니다.
### 주요 기능
- 기능 1   
  자바 핵심 개념을 인포그래픽/퀴즈로 제공합니다.
- 기능 2   
  선택한 학습 분야의 퀴즈 생성하기 버튼을 누르면 ai가 즉석으로 문제를 생성합니다.
- 기능 3   
  새로운 학습 주제를 추가할 수 있도록 했습니다. 

## 4. 페어 프롬프트 릴레이 앱 🧑‍🤝‍🧑

### 페어: @bin1225 @alstj2384

  우테코 LMS, 생활 가이드북, 알쓸크잡 등 파편화된 정보들을 한곳에 모아둘 공간이 필요했습니다. 크루들이 유용한 페이지나 자신의 프로젝트 결과물을 자유롭게 공유할 수 있도록 했으며, 특히 페어나 조원의 위치를 파악하기 위해 매번 슬랙 DM을 보내야 했던 번거로움을 해결하고자 닉네임 기반의 실시간 위치 및 상태 공유 기능을 더했습니다.

  우테코 LMS, 가이드북 등 필수 정보가 필요할 때마다 여기저기 헤매지 않고 즉시 접속할 수 있는 통합 허브로 활용할 계획입니다. 또한, 페어나 조원에게 위치를 묻기 위해 슬랙 DM을 보내는 번거로움을 없애고자, 자신의 실시간 위치와 상태를 공유하는 소통 창구로 사용하려 합니다. 직접 만든 웹앱이나 유용한 정보를 크루들과 자유롭게 나눌 예정입니다.

### 주요 기능
- 기능 1   
  크루들의 이름을 저장하고 현재 위치와 상황을 공유할수 있는 기능을 제공합니다. (미션, 회의, 협업, 노는 중)
- 기능 2   
  크루들에게 필요한 정보들을 제공합니다. 크루들이 필요에 따라 정보를 공유하거나 자신의 결과물을 올릴 수 있는 기능을 제공합니다.
- 기능 3   
  크루들의 원활한 소통을 위해 말투를 교정할 수 있는 기능을 제공합니다. 

### AI 기능 (해당되는 경우)
- 어떤 AI 기능을 추가했나요?   
  말투 교정기(전파 교정기)에 ai 기능을 추가했습니다. 

- AI 기능이 앱에서 어떤 역할을 하나요?   
  크루들이 서로 원활하게 소통할 수 있도록, AI가 적절한 말투와 표현을 제안합니다. 이를 통해 처음 만나는 페어나 조원 사이의 어색함을 줄이고, 올바른 피드백 문화를 형성하는 데 기여합니다. 


## AI 사용 일지

### 1. 초기 프롬프트
처음 Gemini에게 입력한 프롬프트를 그대로 적어주세요.   
- 지금부터 메모를 저장하고 요약하는 웹앱을 만들거야. html,css,javascript만 사용해서 구현해줘. 다른 언어나 프레임워크는 사용할 수 없어. 
  먼저 핵심적인 기능은 사용자가 아무렇게나 작성 메모를 저장하는 기능, 저장된 메모를 ai를 통해 정리하는 기능이야.
### 2. 프롬프트 개선 과정
- 처음 결과물의 문제점은 무엇이었나요?
  전체 내용을 보존하며 가독성을 높이는 것이 목적이었으나, AI가 임의로 내용을 생략하고 3~4줄의 짧은 요약본만 결과물로 내놓았습니다.
- 어떤 식으로 프롬프트를 수정했나요?   
  저장된 메모를 3-4줄 정도로 요약하는 기능을 별도로 분리해달라고 요청했습니다. 그 다음 원문 내용을 생략없이 정리하여 보여주고, 핵심 내용을 5개 정도 뽑아서 제시하달라고 요청했더니 원하는 결과물이 나올 수 있었습니다. 
- 몇 번의 반복을 거쳤나요?   
  약 두 번의 반복을 거쳤습니다. 

### 3. 효과적이었던 프롬프팅 전략
- 어떤 방식으로 요청했을 때 원하는 결과가 나왔나요?   
  사소한 부분이라도 '한 번의 프롬프트에는 하나의 요청만' 담는 원칙을 세우고, 대신 그 내용을 아주 상세하게 작성했습니다. 처음에는 핵심 기능 3개를 한꺼번에 요청해 보기도 했지만, AI가 의도를 완벽히 파악하지 못해 구현 결과가 만족스럽지 않았습니다. 그래서 전체적인 큰 틀을 먼저 제시한 뒤, 세부 요구사항은 하나씩 순차적으로 요청하는 방식을 택했을 때 가장 정확한 결과물을 얻을 수 있었습니다.
- 반대로 효과가 없었던 방식은 무엇이었나요?   
  구체적인 가이드 없이 단순히 결과물이 마음에 들지 않으니 다시 만들어달라고 반복 요청하는 방식은 효과가 없었습니다. 사용자가 원하는 디자인 패턴이나 동작 방식을 명확하게 명시하지 않으면 효과가 없다는 점을 확인했습니다.
### 4. 배운 점
- Gemini Canvas를 효과적으로 사용하기 위한 나만의 팁이 있다면?   
  아무리 작은 기능이라도 원하는 바를 정확하고 구체적으로 정의해야합니다. 단순히 '요약 기능을 만들어줘'라고 모호하게 요청했을 때는 의도와 다른 방향으로 흘러갔지만, 요구사항을 잘게 쪼개어 상세히 전달하니 불필요한 수정 과정 없이 훨씬 수월하게 원하는 결과에 도달할 수 있었습니다.
