📊 백엔드 DB 연동 가이드

1. 실시간 클라우드 DB 연결

앱을 실행하면 내장된 클라우드 DB(Firestore)의 `public/data/benefit_stores` 경로에 접속하여 실시간 동기화(onSnapshot)를 시작합니다.

2. 빠른 초기화 로직 (Silent Seeding)

기존의 무거운 크롤링 대기 화면 대신, DB가 비어있을 경우 백그라운드에서 조용히 기본 데이터를 채워넣고 사용자에게는 즉시 메인 화면을 보여줍니다.

3. Gemini AI 실시간 혜택 검색

DB에 존재하지 않는 매장 검색 시, Google Gemini API의 구글 검색(Grounding) 기능을 사용하여 실시간으로 인터넷 정보를 가져오고 JSON 포맷으로 파싱하여 화면에 보여줍니다.

4. Vanilla JavaScript 아키텍처

React 프레임워크 없이 순수 HTML, CSS, JS만으로 가상 DOM(Virtual DOM)과 유사한 상태 기반 렌더링을 구현하여 가볍고 빠르게 동작합니다.
