## 💻 1. 유틸리티 앱

### 앱 이름
⚡Slotify (자투리 시간 활용 앱)

### 배포 링크
https://gemini.google.com/share/e83331264ec1
### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
  - 평소에 낭비되는 자투리 시간이 많다고 느꼈다.
  - 평소에 시간을 내서 학습하기는 싫은 토익 스피킹 공부와, 상식 공부, 뉴스 읽기를 자투리 시간을 활용하여 해결하고자 했다.   
  - 버스/지하철/카페/병원처럼 기다리는 짧은 시간(3~10분) 이 생길 때, 그 시간을 활용하기 위한 앱을 만들었다.

- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
  - #### 언제
    - 카페에서 주문을 기다릴 때
    - 버스 정류장에서 버스를 기다릴 때
    - 병원에서 순서를 기다릴 때
    - 이외에도 무엇을 하기에는 애매한 3~10분의 시간이 비는 모든 경우
  - #### 어떻게
    - 카페 주문을 기다리는 3분동안, 3분 코스를 선택하여 영어회화 1문장 + 상식퀴즈 1문제 + 오늘의 뉴스 1개를 읽으며 시간을 활용한다.
    - 출퇴근 버스를 기다리는 5분동안, 5분 코스를 선택하여 시간을 활용한다.
    - 병원에서 순서를 기다리는 10분동안, 10분 코스를 선택하여 시간을 활용한다.

### 주요 기능

- 기능 1
  - 3분/5분/10분 3가지 코스중 하나를 선택하면 그 시간에 맞는 학습을 제공
- 기능 2
  - 코스를 선택하면 해당 시간에 맞게 영어 회화/상식 퀴즈/오늘의 뉴스 세 섹션으로 콘텐츠가 구성되어 제공  
- 기능 3
  - 복습 기능 제공
    - 퀴즈는 선택 즉시 정답/오답을 보여주고, 해설(설명)을 표시한다.
    - 틀린 문제는 자동으로 ‘오답 퀴즈 복습’ 섹션에 저장된다.
    - 복습 탭에서 오답을 다시 풀어 맞추면 완료 처리(완료 배지 표시)가 된다.
    - 오늘 학습한 영어 문장을 ‘영어 표현 복습’ 섹션에 모아두고, 영어 문장을 가리는 토글을 제공하여 한글만 보고 문장을 유추할 수 있게 한다.


### AI 기능 (해당되는 경우)

- 어떤 AI 기능을 추가했나요?
  - Gemini API를 이용한 ‘오늘의 뉴스 브리핑 생성’ 기능을 추가했다.
  - 매일 AI가 주요 뉴스 주제를 선정하고 상세 요약을 생성하도록 구성했다.
- AI 기능이 앱에서 어떤 역할을 하나요?
  - 사용자가 코스를 실행했을 때 Today's Briefing 섹션에 “오늘의 뉴스”를 자동 생성해준다. 
  - 3분 코스에는 뉴스 1개, 5분 코스에는 뉴스 2개, 10분 코스에는 뉴스 3개를 제공하는 방식으로 짧은 시간에도 읽을 가치 있는 한 덩어리의 뉴스를 제공한다.

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
  - 평소에 컬렉션/스트림을 공부하다 보면 어떤 자료구조/연산을 언제 쓰는지가 헷갈렸는데, 이에 도움이 되는 앱을 만들고자 했다.
  - 해당 내용을 복습할 때, 강의/블로그/노트가 여기저기 흩어져 있어서 보기가 불편했다.
  - 이에 따라 “짧게 풀고(퀴즈) → 바로 확인하고(해설) → 필요한 개념을 즉시 찾아보고(치트시트) → 틀린 것만 다시 푼다(오답노트)” 흐름을 한 앱 안에서 해결하고자 했다.

- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
  - 공부 시작 전 워밍업: 컬렉션/스트림 중 하나를 선택해 빠르게 퀴즈를 풀며 오늘 약한 부분을 확인한다.
  - 학습 중 막힐 때: 치트시트에서 카테고리를 클릭해 개념 요약과 짧은 코드 예시를 즉시 확인한다.
  - 학습 마무리 복습: 오답노트에서 틀린 문항만 다시 풀고, 맞히면 복습 완료로 처리해 약점을 정리한다.

### 주요 기능

- 기능 1
  - 컬렉션/스트림 퀴즈 2가지 옵션 선택 제공
- 기능 2
  -  즉시 채점 + 해설 표시
     - 답안을 선택하면 정답/오답을 바로 표시하고, 아래에서 해설을 확인할 수 있다.
- 기능 3
  - 오답노트 복습(틀린 문제만 재도전) 
    - 다시 맞추면 복습 완료 표시(✓)
    - 문항 상단에 Collection/Stream 카테고리 배지를 작게 표시해 유형을 빠르게 구분할 수 있다.
- 기능 4
  -  치트시트를 통한 개념 정리 제공
  - List/Set/Map, equals&hashCode, Iterator, 시간복잡도, Stream 중간/최종 연산, Optional, Collectors 등 카테고리를 좌측에서 선택하면 우측에 핵심 요약 + 짧은 코드 예시가 표시된다.

```
짧은 시간에 영어회화/상식/뉴스로 머리를 “워밍업”하고 싶은 사람을 대상으로 하는 앱을 만들어줘.

- 사용자가 3분,5분,10분 시간 카테고리를 선택하면 시간에 맞게 영어회화 문장과 상식퀴즈, 
오늘의 뉴스 요약을 보여줄거야. 
   - 3분같은 경우에는 영어회화(토익 스피킹에 유용하게) 1개 + 상식퀴즈 1개 + 뉴스 요약 3줄 1개 / 
   - 5분은 좀 더 길게 
   - 10분은 더 길게 이런식으로 구성을 할거야.

"HTML, CSS, JavaScript만 사용해서 만들어줘. React나 다른 프레임워크는 사용하지 마."
```
### 2. 프롬프트 개선 과정
- 처음 결과물의 문제점은 무엇이었나요?
  - 상식퀴즈와 영어 문장의 양이 부족하여 같은 문제들이 반복되어 나오는 문제가 있었다.
  - 영어 문장의 발음을 들을 수 있는 기능이 없었다.
  - 처음 홈화면에서 화면 아래부분이 잘리는 문제가 발생함.
  - 3분코스나 5분 코스, 10분코스를 하고나서 홈 화면으로 돌아가는 버튼이 없었음.
  - 처음 홈화면에서 각 코스별 아이콘 디자인이 아쉬웠음.
  - 오늘의 뉴스 요약이 AI를 이용하는 것이 아니라, 하드코딩되어있었음.
  - 오답 퀴즈와 영어 문장을 복습할 수 있는 기능이 없었음.
  
- 어떤 식으로 프롬프트를 수정했나요?
  - 초기에 만들어진 앱을 직접 사용해보면서, 필요한 기능들을 추가하고 수정했음. 
  - 각각 앱 내부에 최소 100개의 영어회화 문장과, 100개의 퀴즈들이 있었으면 좋겠다고 프롬프트를 수정함.
  - 영어 문장의 발음을 들을 수 있도록 기능을 추가 요청함.
  - 홈 화면이 잘리지 않도록 수정을 요구함.
  - 코스를 실행하고, 홈 화면으로 돌아갈 수 있는 버튼을 만들어달라고 요청함.
  - 각 코스의 아이콘을 3분 코스 이모지는 커피로, 5분 코스 이모지는 버스, 10분코스 이모지는 병원으로 해달라고 요청함.
  - 오늘의 뉴스 요약을 하드 코딩이 아닌, Gemini API를 사용하여 생성해달라고 요청함.
  - 복습 탭을 어떻게 구성할지 구체적으로 요청함.
    -  홈화면 제일 하단에 복습 탭을 만들고 복습 탭에는 아래 두 섹션을 보여준다:
       - A) 오답 퀴즈 복습
         - 오답으로 저장된 문항을 다시 풀 수 있다.
         - 다시 맞추면 복습 완료 처리되어 완료로 표시.
         - 맞출경우 해설을 표시.
         - 원하면 삭제할 수 있게 삭제 기능도 추가.
       - B) 영어 표현 복습
         - 오늘 본 영어 표현을 모아 보여주고, “가리기/보이기(뜻 숨기기)” 토글 제공. 가리는건 영어 문장을 가리도록 설정.
         - “복습 완료” 체크 가능.
         - 원하면 삭제할 수 있게 삭제 기능도 추가.
         - 영어 표현 부분에서 삭제랑 발음 버튼 겹치지 않게 주의.


- 몇 번의 반복을 거쳤나요?
  - 최종 완성까지 19번의 반복을 거쳤다.

### 3. 효과적이었던 프롬프팅 전략

  - 원하는 요구사항을 구체적으로 제시할수록 원하는 결과가 잘 나왔다. (ex 구체적인 숫자 제시)
