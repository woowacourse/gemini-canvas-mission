우아한 레이싱

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
설치나 무거운 프로그램 실행 없이, 웹 브라우저 접속만으로 즐길 수 있는 게임이 필요했습니다. 
복잡한 룰을 외울 필요 없이 '장애물을 피하며 가장 빠르게 달린다'는 원초적인 재미와 속도감, 다양한 아이템들을 제공하여 일상 속의 답답함을 해소하고자 했습니다.

- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
공부나 코딩, 업무 중간에 짧은 휴식이 필요할 때 플레이할 것입니다. 
1~2분 내외의 짧은 플레이 타임 동안 최고 기록을 경신하기 위해 집중력을 발휘하며 기분 전환을 하는 용도로 사용할 계획입니다.

### 주요 기능

- 기능 1
* 다이내믹 1인칭 드라이빙 & 물리 엔진
 단순한 이동을 넘어 속도에 비례한 카메라 흔들림(Shake), 코너링 시 차체 기울어짐, 속도감에 따른 시야각(FOV) 변화 등을 구현하여 실제 운전석에 앉은 듯한 극대화된 몰입감을 제공합니다.
    
* 긴급 회피 액션 (Dash) 순간적으로 위기를 탈출할 수 있도록 Shift + 방향키를 이용해 차선 하나를 눈 깜짝할 새 이동하는 액션 요소를 더했습니다.
- 기능 2
* 하이 리스크 하이 리턴 점수 시스템 
 안전하게 느린 속도로 달리면 점수가 거의 오르지 않지만, 충돌의 위험을 안고 최고 속도를 유지하면 점수 획득량이 기하급수적으로 폭발하는 시스템을 통해 플레이어의 도전을 유도합니다.

- 기능 3
* 아이템 
    * 🟡 노란 보석 (부스터): 3초간 시야각이 찢어지듯 넓어지며 다른 차들을 튕겨내는 무적 초고속 돌진.
    * 🔵 파란 보석 (보호막): 치명적인 충돌을 1회 완벽하게 방어해 주는 쉴드 전개.
    * 🟣 보라 보석 (소형화): 차체가 낮아지고 좁아져, 촘촘한 장애물 사이를 요리조리 피하는 데 특화.

- 기능 4 
* 장애물
    * 절차적 무한 맵 & 동적 장애물 다가오는 일반 차량, 역주행 차량, 그리고 차선 중앙을 막는 공사 바리케이드가 끊임없이 랜덤하게 생성되며, 진행 거리에 따라 난이도가 자연스럽게 증가합니다.
