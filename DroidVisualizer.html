코루틴(Coroutines) 가이드

Non-blocking 비동기 프로그래밍 모델

일시 중단(Suspend) 메커니즘

특정 루틴이 실행 도중 스레드를 차단하지 않고 상태를 저장한 후 실행을 일시 중단하였다가, 조건이 충족되면 재개(Resume)하는 제어 흐름입니다.

구조화된 동시성

CoroutineScope를 통해 코루틴의 수명을 관리하며, 상위 스코프 종료 시 하위 작업을 계층적으로 취소하여 리소스 누수를 방지합니다.

01. Scope

코루틴이 실행되는 수명 범위를 정의합니다. 생명주기 객체와 바인딩됩니다.

02. suspend

비차단(Non-blocking) 방식으로 일시 중단될 수 있는 함수임을 나타내는 수정자입니다.

03. Job

실행 중인 코루틴 작업에 대한 핸들러로, 취소 및 상태 관찰을 수행합니다.

안드로이드 아키텍처 (MVVM)

관심사 분리를 통한 계층 구조화

비즈니스 로직과 UI 로직을 분리하여 모듈성, 테스트 가능성, 유지보수성을 극대화하는 MVVM(Model-View-ViewModel) 패턴을 분석합니다.

MVVM Pattern 실무 예제 코드

1. Data Layer UserRepo.kt 
data class User(val id: Int, val name: String)

class UserRepository(private val api: ApiService) {
    suspend fun getUser(id: Int): User {
        return api.fetchUser(id)
    }
}
2. ViewModel MainViewModel.kt 
class MainViewModel(private val repo: UserRepository) : ViewModel() {
    private val _userState = MutableStateFlow<User?>(null)
    val userState: StateFlow<User?> = _userState.asStateFlow()

    fun loadUser(id: Int) {
        viewModelScope.launch {
            _userState.value = repo.getUser(id)
        }
    }
}

Hilt Framework

Dagger 라이브러리를 기반으로 안드로이드 수명 주기에 최적화된 표준 DI 컨테이너를 자동으로 구성합니다.

Hilt 계층 구조

  • @Singleton: 앱 프로세스 단위 유지
  • @ActivityScoped: 액티비티 인스턴스 단위
  • @ViewModelScoped: ViewModel 수명 주기 유지

Hilt (Dependency Injection) 실무 예제 코드

1. Application Setup MyApplication.kt 
@HiltAndroidApp
class MyApplication : Application() {
    // Hilt가 종속성 그래프의 루트를 생성하도록 강제함
}
2. Module Definition NetworkModule.kt 
@Module
@InstallIn(SingletonComponent::class)
object NetworkModule {
    @Provides
    @Singleton
    fun provideApiService(): ApiService {
        return Retrofit.Builder()...build().create(ApiService::class.java)
    }
}
3. Constructor Injection UserRepository.kt 
class UserRepository @Inject constructor(
    private val apiService: ApiService // Hilt가 자동으로 인스턴스를 주입
) {
    suspend fun fetchData() = apiService.getData()
}
4. Android Entry Point MainActivity.kt 
@AndroidEntryPoint
class MainActivity : AppCompatActivity() {
    @Inject lateinit var analytics: AnalyticsAdapter // 필드 주입

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        analytics.trackEvent("Activity_Created")
    }
}
