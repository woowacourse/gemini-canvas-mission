# 🫂 걱정마소
### 배포 링크: https://gemini.google.com/share/4efd1ad11e90

### 프로젝트 개요

'걱정마소'는 일상에서 마주하는 심리적 압박감을 관리하고, 사용자가 존경하는 인물의 철학을 통해 실질적인 조언을 얻을 수 있는 유틸리티 웹 애플리케이션입니다. 단순히 멘토의 명언을 나열하는 방식이 아니라, 설정된 페르소나가 사용자의 현재 상황에 맞춰 직접 대화하듯 조언해줌으로써 깊이 있는 동기부여와 정서적 지지를 제공합니다.

### 목표 사용자
- 존경하는 위인이나 멘토의 가치관을 일상에 적용하고 싶은 사람
- 자신의 고민을 털어놓고 그분들의 관점에서 해결책을 듣고 싶은 사람

### 핵심 기능 요구사항

#### 1. 멘토 페르소나 설정 및 데이터 구축
사용자가 조언을 구할 대상의 데이터를 정의합니다.

- **공인/위인 모드 (AI 기반)**: 인물 이름을 입력하면 AI가 해당 인물의 생애, 철학, 어투를 분석하여 페르소나를 자동으로 구축합니다.
- **개인 멘토 모드 (수동 입력)**: 부모님이나 은사님 등 개인적인 멘토의 성함, 핵심 가치관, 평소 자주 하시는 말씀과 성격을 직접 입력하여 맞춤형 페르소나를 생성합니다.

#### 2. 페르소나 기반 상황 맞춤형 코칭
설정된 멘토가 사용자의 상황에 개입하여 조언을 건네는 핵심 인터페이스입니다.

- **상황 입력 & 분석**: 사용자가 현재 겪고 있는 고민을 입력하면 멘토의 페르소나가 이를 인식합니다.
- **역할극 조언**: "만약 이 상황에서 멘토라면 어떻게 했을까?"라는 질문에 대해, 멘토 특유의 말투와 철학을 반영한 구체적인 대응 방안과 위로를 제공합니다.

### 구현 및 프로그래밍 제약 조건

- **AI 도구 제한**: 오직 Gemini Canvas만을 사용하여 코드를 생성합니다. 다른 AI 코딩 어시스턴트는 사용하지 않습니다.
- **프롬프트 엔지니어링 훈련**: 직접 코드를 짜기보다, 명확한 성공 기준과 제약 조건을 포함한 프롬프트 지시어만으로 유용한 앱을 완성하는 것을 목표로 합니다.
- **기술 스택**: HTML5, CSS3, JavaScript만 사용합니다. React 등 어떠한 프론트엔드 프레임워크나 빌드 도구도 사용하지 않습니다.
