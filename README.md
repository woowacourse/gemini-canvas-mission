# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

------


## ✅ 제출 체크리스트

- [x] 4개 웹앱 제출 (유틸리티 앱 1개 + 게임 1개 + 학습 앱 1개 + 페어 프롬프트 릴레이 1개)
- [x] 최소 1개 앱에 Gemini AI 기능 포함
- [x] 모든 앱이 배포 링크로 정상 동작함
- [x] AI 사용 일지 작성 완료

## 💻 1. 유틸리티 앱

### 앱 이름
Woowa Hub - 슬기로운 우테코 생활

### 배포 링크
https://gemini.google.com/share/7fc9cf648031

### 이 앱을 만든 이유

    1. slack, LMS 등 여러 곳에서 나온 공지사항을 내 편의대로 정리하고 싶다.
    2. 우테코 생활동안 필요한 대부분의 기능을 하나의 앱에서 제공하고 싶다.
    우테코 동안 필요한 모든 것을 공지사항, 생활, 과제, 페어프로그래밍, 팀프로젝트 등의 카테고리로 정리한 서비스를 기획하였다.


- 어떤 문제/불편함을 해결하려고 했나요?   
  LMS,LMS+, 찜꽁, Slack 공지사항, 과제 등 너무 많은 정보들이 제공되다보니, 공지사항을 빠트리는 문제가 발생했다.     
  <br>
  이번 웹앱 과제를 하는 동안에도 LMS, 깃허브, Slack을 번갈아가며 내용을 확인하는 과정이 필요했다.     
  LMS에는 과제 관련 공지사항이 있고, 미션 제출 장소에 pr template이 있고, slack에서 제출방법이 추가로 공지되어있었다.    
  개발 할 당시에 세 군데를 왔다갔다하면서 찾는 어려움이 있었다.      
  <br>
  또한 slack을 통한 채팅 형식의 공지가 많아서 관련 공지사항을 놓치거나, 필요할 때 바로 찾지 못하는 어려움이 있다.    
  과제를 제 날짜에, 공지사항을 빠트리지 않고 완료하고자 이 서비스를 기획했다.    


- 본인이 이 앱을 언제, 어떻게 사용할 건가요?   
우테코 동안 필요한 대부분의 기능을 넣었기 때문에, 우테코 동안 수시로 사용할 수 있다.    
과제와 공지사항을 나의 편의대로 정리해, 놓치는 것이 없도록 할 것이다.

### 주요 기능

- 공지사항 : 원하는 대로 공지를 등록할 수 있다.    
  오늘에 해당하는 공지이면 오늘의 공지칸에 뜨고, 그 외의 공지의 경우 전체 공지사항에 뜬다.   
  실시간으로 올라오는 슬랙 공지, 과제 공지, 내가 하고자 하는 오늘의 투두 리스트 등 나에게 공지하고 싶은 모든 사항을 공지로 등록할 수 있다.
  
- 생활 : 생활에 필요한 링크나 소식들을 작성하고 확인할 수 있다. 주로 변동성이 적은 내용들이 적힌다.
- 과제 : 과제를 캘린더 뷰에 등록하고, 완료 여부를 체크 할 수 있다.     
   또한, 과제를 누르면 과제 관련 설명, 제출 링크, 마감 기한을 확인할 수 있고, 하단에 과제 댓글을 작성해 slack에서 추가로 공지된 사항을 모아볼 수 있게 하였다.
- 페어 프로그래밍 : To-do 리스트로 할일을 작성하고, 완료 표시가 가능하다.
- 팀프로젝트 : To-do 리스트로 할일을 작성하고, 완료 표시가 가능하다.

### 배포 링크
https://gemini.google.com/share/3f43d925375f

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?     
서버에 대해 공부해야하는데, 내용이 어려워서 관련 용어나 지식에 대해 익숙해지고 싶었다.    
매일 매일 조금씩 진도를 나가기 위해, 하루 한 세트 가볍게 서버 지식을 습득할 수 있는 앱을 만들었다.     


- 본인이 이 앱을 언제, 어떻게 사용할 건가요?    
우테코 등교해서 본 타임이 시작하기 전이나 이동 중 잠시 기다릴 때, 간편하게 사용할 것 같다.

### 주요 기능
- 핵심 기술 퀴즈 (3문제) : 객관식으로 답을 선택하는 퀴즈이다.
- 개념 플래시카드 (3문제) : 개념 카드를 뒤집으면 설명이 나오는 플래시 카드이다.
- 데일리 기술 트렌드 : 제미나이가 조사한 최신 기술 트랜드 요약을 제공한다.
- 모의 기술 면접 : 면접 질문에 서술형으로 답변을 작성하면, 제미나이가 100점 만점 기준으로 채점하고 피드백과 모법 답안을 제공한다.
- 전체 요약 : 오늘 수행한 4가지 유형을 인포그래픽으로 정리해서 보여주고, 시니어 개발자의 꿀팁까지 제공한다.

### AI 기능 (해당되는 경우)

- 어떤 AI 기능을 추가했나요?        
AI를 이용해서 데일리로 풀거나 익힐 개발 문제를 자동 생성하였다.        
또한, 모의 면접에 대한 답변을 채점하고, 피드백 내용을 생성하는데 활용하였다.


- AI 기능이 앱에서 어떤 역할을 하나요?

서버 관련 문제 출제, 기술 트렌드 정보 수집, 면접 답변 채점 등에서 사용한다.

1. 핵심 기술 퀴즈 (3문제) - AI로 문제 출제 
2. 개념 플래시카드 (3문제) - AI로 개념 선별
3. 데일리 기술 트렌드 - AI로 기술 트렌드 선별
4. 모의 기술 면접 - AI 문제 출제 및 답변 채점
5. 전체 요약 : AI로 퀴즈 해설 및 시니어 개발자의 꿀팁을 제공

### 2. 프롬프트 개선 과정

- 처음 결과물의 문제점은 무엇이었나요?

  요구사항을 추가할수록 제미나이가 예전에 얘기했던 요구사항을 기억 못하는 문제가 발생했다.    
  초반에 설명했던 디자인 컨셉 등이 모두 변경되어, 이미 완성했던 기능이나 디자인을 다시 만들어달라고 요청해야했다.


- 어떤 식으로 프롬프트를 수정했나요?  
 이 문제점의 원인으로 LLM이 상 최근 메세지들을 좀 더 중요하게 보고 반영하려고 하기 때문이라고 생각했다.
  <br>그래서 내비게이터로 세부적인 수정사항을 하면서, 지속적으로 전체 프롬프트도 갱신하였다.

1. 내비게이터 차례일 때     
  세부적인 수정사항의 경우 해당 부분에 대해 번호를 매겨서 나열하였다.     
  before, after를 기준으로 설명하려고 노력했고, 기존 서비스가 있다면 그 예시를 말해주었다. (discord 대화창 처럼 해줘)      


2. 프롬프트 차례일 때    
이미 만족한 디자인과 틀의 경우 변경이 없었으면 했다.   <br>그래서 제미나이가 결과물을 제대로 만들었을 때, 해당 디자인과 틀을 전체 프롬프트에 세부적으로 적어두었다.
   <br>기능의 경우 "해당 버튼을 누르면 데이터를 조회해줘" 와 같이 디자인과 함께 제시하였다.

### 3. 효과적이었던 프롬프팅 전략

구체적인 위치와 기능을 설명해주고, 기존 서비스의 예시를 제공해주면 AI가 잘 알아들었던 것 같다.


- 반대로 효과가 없었던 방식은 어떤게 있었나요?    
페어로 돌아가면서 프롬프트를 작성해서 그런지, 해당 부분을 수정해달라고 프롬프트를 넣으면 수정 과정에서 기존에 완성되어있던 부분이 변경되어버리는 문제가 있었다.    <br>
이 문제를 해결하고자, 주기적으로 프롬프트를 갱신하고 입력해주었다.

### 4. 배운 점

- Gemini Canvas를 효과적으로 사용하기 위한 나만의 팁이 있다면?

1. 프롬프트를 누적해서 작성하기   <br>
  계속 내비게이터처럼 수정사항에 대해서만 프롬프트를 작성하면, 이전에 완성됐던 결과물들까지 모두 변경되는 경우를 많이 겪었다.   <br>
  그래서 내가 원했던 요구사항들을 프롬프트에 누적해서 갱신해주고, 의도하지 않은 큰 변경이 생겼을 때 다시 전체 프롬프트를 입력해주었다.  <br>
  또한, 내가 요청사항으로 넣었던 것을 반영하면서, 제미나이가 변경 내역을 설명해주는데,   <br>
  이때,제미나이가 사용한 어휘들을 활용해서 프롬프트에 추가하면 제미나이와 좀 더 수월하게 소통할 수 있었다.  <br>
  이를 통해서 제미나이가 수정하는 결과물의 오차가 적어지도록 하였다.  <br>
2. 수정사항 반영  <br>
  수정사항을 요구할때는 before를 먼저 제시하고, 내가 원하는 after를 제시해서 반영하고자 하였다.   <br> 또한 기존 서비스가 있다면 그 예시를 들어서 설명하였다.
3. 디자인   <br>
수정사항을 그림으로 그리듯이 설명하는 것이 유용했는데,   
특히 "오른쪽 상단, 하단" 와 같이 위치를 지정해주고, 내가 원하는 디자인, 버튼 등을 적용해달라고 하는 것이 유용했다.
