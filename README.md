# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

### 3. 효과적이었던 프롬프팅 전략

- 어떤 방식으로 요청했을 때 원하는 결과가 나왔나요?
    - 복잡하거나 여러 작업을 한꺼번에 추상적으로 지시하는 것 보다 자세하고 간단하게 요청을 여러번 하는 것이 원하는 상태와 유사하게 만드는 결과가 있었습니다.
    - 새로운 기능을 추가할 때 기존의 상관 없는 다른 기능의 데이터들을 일부 삭제하거나 수정하는 결과가 있었는데, 이 데이터를 명시적으로 수정하지 말 것을 지시하여 기존의 데이터를 유지할 수 있었습니다.
- 반대로 효과가 없었던 방식은 어떤게 있었나요?
    - 다른 웹 사이트에서 데이터 크롤링을 유도하거나 이미지를 가져오는 작업들은 요청 시 비교적 잘 수행하지 못하는 경향이 있었습니다. 일부는 수행을 했지만 대부분은 이미지가 렌더링되지 않거나 사이트의 데이터를 전혀 가져오지 못했습니다.
    - 기능의 마음에 들지 않는 부분에 대해 수정을 요청했을 때 마음에 들던 해당 기능의 일부분도 삭제하거나 수정해버리는 경우가 있었습니다.

### 4. 배운 점

- Gemini Canvas를 효과적으로 사용하기 위한 나만의 팁이 있다면?
    - LLM에는 기억의 기능이 약하거나 없는 것으로 보여 기존의 삽입된 데이터 같이 반드시 수정하거나 삭제하지 않길 바라는 것은 다른 요청을 하기 전에 명시적으로 그 부분에 대한 수정과 삭제를 하지 말 것을 명시해야 데이터 삭제를 방지할 수 있습니다.
    - 명령을 내릴 때는 구체적으로 내려야 하고 잘 만들어준 부분에 대해서는 칭찬을 통해 해당 부분의 제거와 수정을 방지할 수 있었습니다.
