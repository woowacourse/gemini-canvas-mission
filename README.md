# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 💻 1. 유틸리티 앱

### 앱 이름

Git Command Finder

### 배포 링크

https://gemini.google.com/share/8c2c53ba0de5

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
  - 개발자들이 복잡한 Git 명령어를 사용할 때 발생할 수 있는 실수를 줄이고, 명령어 실행 후의 결과를 직관적으로 이해하기 어려운 점을 해결하고자 했습니다.
  - 에러가 났을 때 구글링을 하고, 내 상황에 맞게 명령어를 변형하고, 커밋 컨벤션을 맞추기 위해 고민하는 등 분산된 개발 리소스를 하나로 모아주는 통합 도구가 필요했습니다.
- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
  - 우아한테크코스 과정이나 개인 프로젝트에서 복잡한 브랜치 전략을 관리해야 할 때 주로 사용할 계획입니다. 특히 새로운 Git 명령어를 시도하기 전 결과를 미리 시각적으로 확인하는 용으로 예정입니다.

### 주요 기능

- 사용자가 처한 상황(예시: "마지막 커밋 메시지를 수정하고 싶어", "특정 브랜치의 커밋 하나만 가져오고 싶어")을 입력하면 그에 맞는 정확한 Git 명령어를 안내합니다.
- 명령어를 실행했을 때 Git 브랜치 구조가 어떻게 변하는지 Mermaid.js를 활용해 인포그래픽으로 보여줍니다. 이를 통해 명령어의 효과를 시각적으로 미리 이해할 수 있습니다.
- 패닉에 빠지기 쉬운 상황을 대화형으로 해결합니다. "커밋은 하셨나요?", "푸시도 하셨나요?" 등의 질문에 클릭만 하면 안전한 복구 명령어를 도출해 냅니다.
- reset --hard나 push -f 등 작업 내역을 영구적으로 삭제하거나 덮어씌울 위험이 있는 명령어가 감지되면, 강렬한 시각적 경고(Pulse Animation)를 띄워 사용자의 주의를 환기합니다.

### AI 기능 (해당되는 경우)

- 어떤 AI 기능을 추가했나요?
  - Gemini AI를 활용한 Git 명령어 추천 및 시각화 기능을 탑재했습니다. 사용자가 현재 상황을 설명하면 적절한 Git 명령어를 제안하고, 실행 전후의 상태를 Mermaid.js를 이용해 그래프 형태로 미리 보여줍니다.
  - 개발자가 작성한 거친 작업 내용이나 복잡한 git diff 결과를 AI에게 넘기면, 팀 협업에 필수적인 Conventional Commits에 맞추어 제목, 본문, 타입(feat, fix 등)이 완벽히 구조화된 메시지로 자동 요약 및 번역해 줍니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
  - 사용자가 복잡한 Git 작업을 수행하기 전 그 결과를 시각적인 인포그래픽으로 미리 확인하게 함으로써, 명령어 오용으로 인한 실수를 방지하고 Git 워크플로우에 대한 이해도를 높이는 길잡이 역할을 합니다.

## 🎮 2. 게임

### 앱 이름

Aim Master

### 배포 링크

https://gemini.google.com/share/495ddc2c7bb1

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
  - FPS 게임을 본격적으로 시작하기 전, 가볍고 빠르게 마우스 감각을 깨울 수 있는 웜업 환경이 필요했습니다. 기존의 에임 연습 프로그램들은 별도로 무거운 프로그램을 설치해야 하거나, 브라우저 기반이더라도 마우스 감도 조절이나 다양한 타겟 패턴 등 FPS 유저에게 꼭 필요한 디테일한 설정이 부족하다는 불편함이 있었습니다. 이를 해결하기 위해 웹 브라우저 접속만으로 즉시 플레이 가능하고, 실제 게임과 유사한 마우스 잠금 및 감도 조절 기능을 갖춘 가벼운 에임 트레이너를 기획했습니다.
- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
  - FPS 게임을 플레이하기 직전에 손풀기용으로 사용할 예정입니다. 1회 플레이 타임이 30초로 매우 짧기 때문에 게임 매칭을 기다리는 동안 2~3판 정도 가볍게 즐기며 동체 시력과 반응 속도를 끌어올리고, 그날의 컨디션에 맞춰 마우스 감도를 점검하는 용도로 활용할 것입니다.

### 주요 기능

- 시스템 마우스 커서를 숨기고 게임 화면에 조준점을 고정시키는 Pointer Lock API를 적용했습니다. 이를 통해 설정에서 유저가 자신에게 맞는 '마우스 포인터 이동 속도(감도)'를 세밀하게 조절하여 실제 FPS 게임과 유사한 조작감을 구현했습니다.
- 단순히 나타났다 사라지는 과녁이 아니라, 벽에 튕기며 이동하는 일반, 크기가 변해 타이밍을 맞춰야 하는 펄스, 무작위 위치로 순간이동하는 텔레포트 3가지 타겟을 구현해 예측 불가능한 상황을 연출했습니다. 또한, 점수가 높아질수록 타겟의 기본 이동 속도가 빨라져 후반부 긴장감을 높였습니다.
- 과녁 명중 시 +5점, 배경을 잘못 클릭(미스 클릭)하거나 과녁을 맞추지 못해 자연 소멸할 경우 -1점을 부여합니다. 미스 시에는 화면이 붉게 점멸하는 시각적 피드백을 주어 정확도를 높이도록 유도했습니다.
- 플레이 도중 ESC 키를 누르면 즉시 커서 잠금이 해제되며 게임이 일시정지 됩니다. 시작 및 재개 시에는 3초 카운트다운을 제공하여 플레이어가 완벽히 준비할 수 있는 시간을 부여해 사용자 경험을 크게 개선했습니다.

## 📚 3. 학습 앱

### 앱 이름

Switch Tailwind

### 배포 링크

https://gemini.google.com/share/c1a08a09d416

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
  - 기존의 CSS 문법에 익숙한 개발자들이 Tailwind CSS의 독특한 클래스 기반 방식에 적응하는 데 겪는 어려움을 해결하고자 했습니다. 매번 공식 문서를 찾아보지 않고도 직관적으로 CSS 속성이 Tailwind 클래스로 어떻게 대응되는지 익히고, 실무에서 자주 쓰이는 유틸리티 클래스를 빠르게 습득할 수 있도록 돕기 위해 만들었습니다.
- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
  - 프로젝트에 Tailwind CSS를 도입하거나, 특정 CSS 속성을 Tailwind로 어떻게 구현해야 할지 영감이 필요할 때 사용할 예정입니다. 학습 탭의 인포그래픽을 보며 개념을 정리하거나, 퀴즈와 실습을 통해 실력을 점검하며 생산성을 높이는 도구로 활용할 것입니다.

### 주요 기능

- 인포그래픽을 활용하여 CSS 문법이 Tailwind CSS로 변환되는 규칙을 한눈에 보여줍니다. 특히 초보자가 헷갈리기 쉬운 반응형 디자인이나 레이아웃 등의 기본 문법이 실제로 화면에 어떻게 렌더링되는지 시각적 예시로 제공하여 구조적인 이해를 돕습니다.
- 주어진 CSS 코드를 Tailwind CSS로 변환하는 연습 문제를 풀거나, 실습 에디터에서 목표 UI를 보고 직접 Tailwind 클래스를 입력하며 즉각적인 렌더링 피드백을 확인하는 환경을 제공합니다. 이를 통해 채점 결과와 해설을 제공받으며 실전 감각을 빠르게 익힐 수 있습니다.

### AI 기능 (해당되는 경우)

- 어떤 AI 기능을 추가했나요?
  - AI CSS 변환기 기능과 퀴즈/실습 탭에서의 AI 문제 생성 기능을 추가하였습니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
  - 사용자가 표준 CSS 문법이나 기존 레거시 코드를 입력하면, AI가 문맥을 분석하여 가장 최적화되고 깔끔한 Tailwind CSS 클래스 조합으로 즉시 변환해 주는 역할을 합니다.
  - 또한, 퀴즈와 실습 탭에서는 미리 고정된 문제를 푸는 방식에서 벗어나, AI가 사용자의 선택 분야와 난이도(Lv.1 ~ Lv.5)에 맞춰 매번 완전히 새로운 퀴즈와 목표 UI를 실시간으로 무한히 생성합니다. 이는 사용자의 단순 암기를 방지하고, 매번 새로운 실무 밀착형 문제를 통해 응용력을 기르도록 돕는 역할을 수행합니다.

  - 렌더링 에러가 발생했을 때 내가 원인을 추측하기보다, "현재 브랜치가 A인데 B 커밋을 가져오는 상황에서 Mermaid render Error가 났어"처럼 현상과 에러 로그를 그대로 캔버스에 전달하였을 때, 원하는 결과가 나왔습니다.
- 반대로 효과가 없었던 방식은 어떤게 있었나요?
  - "브랜치가 3개 이상이어도 작동하게 해줘" 같은 추상적인 지시는 효과가 없었습니다. AI는 구체적인 규칙(예: "checkout 전에 반드시 branch 생성 명령어를 먼저 적어라")을 수립해 주어야만 일관된 코드를 생성했습니다.

### 4. 배운 점

- Gemini Canvas를 효과적으로 사용하기 위한 나만의 팁이 있다면?
  - 코드가 작동하지 않거나 에러 메시지가 떴을 때, 내가 원인을 분석하려고 애쓰기보다 화면에 뜬 에러나 막히는 상황을 있는 그대로 캔버스에 전달하는 것이 가장 빠르게 해결책을 얻는 방법이었습니다.

### 5. 리뷰어에게 피드백 받고 싶은 포인트

- 프로젝트 초기 프롬프트를 작성할 때 앱의 기본 뼈대를 먼저 잡아주는 것이 효과적이라는 것을 배웠습니다. 하지만 UI 레이아웃, 세부 기능 명세, 기술 스택 등을 어느 수준까지 상세하게 기재하고 시작하는 것이 AI와 협업할 때 가장 효율적이고 파편화를 막을 수 있는지 리뷰어님의 실제 경험과 팁이 궁금합니다.
