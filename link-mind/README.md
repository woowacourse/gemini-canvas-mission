## 카테고리: 유틸리티 앱(페어 프로그래밍)

### 이 앱을 만든 이유
- 저장해둔 링크가 많아질수록 “어디에 뭘 저장했는지” 기억이 안 나고, 다시 찾는 데 시간이 듦
- 링크를 모아두는 것만으로는 충분하지 않고, **제목/요약/태그/폴더 같은 메타데이터**까지 함께 관리되어야 활용도가 올라감
- 단순 북마크가 아니라, **읽음/안읽음 관리 + 자주 보는 링크 + 리마인드**까지 포함한 링크 보관함을 만들고 싶었음
- Gemini를 활용해 링크의 성격을 빠르게 파악하고, 사용자가 원하는 톤으로 소개글을 수정해 저장하는 경험을 제공하고자 했음

사용 시나리오:
- 개발/학습 자료 링크를 폴더별로 정리하고, 안 읽은 링크만 모아보기
- 자주 참고하는 링크를 “인기 링크”로 빠르게 접근
- 하루 뒤에 다시 봐야 하는 링크(문서/강의/PRD)를 리마인드로 놓치지 않기
- 제목/태그 검색으로 과거에 저장한 링크를 즉시 재발견

---

### 주요 기능
- **URL + 메타데이터 저장**
  - URL, 제목, 설명/요약, 태그, 폴더를 함께 저장
- **폴더 기반 링크 관리**
  - 기본 폴더 제공 + 사용자 폴더 생성/삭제
  - 폴더 삭제 시 내부 링크는 “기본” 폴더로 안전 이동
- **읽음/안읽음 관리**
  - 링크 열기 시 자동으로 읽음 처리
  - 카드에서 읽음 상태 토글 가능
  - “안 읽은 링크”만 필터링
- **자주 조회한 링크(인기 링크)**
  - 링크 열기 시 viewCount 증가
  - “자주 찾는 링크” 메뉴에서 viewCount 기준 정렬
- **검색**
  - 제목 또는 태그 기반 즉시 검색
- **리마인드 알림**
  - 저장 시 “24시간 후 알림” 체크 가능
  - 지정 시간이 지나면 Toast 알림으로 리마인드 표시
- **AI 분석(Gemini) 기반 메타데이터 자동 생성**
  - URL에서 웹페이지 HTML을 로드하여 제목/설명/썸네일 추출
  - 추출된 실제 텍스트를 기반으로 Gemini가 **제목/2문장 요약/태그** 제안
  - 사용자는 AI 제안 결과를 그대로 저장하거나 직접 수정 가능
  - 유튜브 링크의 경우 **채널명 감지 + 고화질 썸네일 자동 추출** 지원

---

### 구현/기술 포인트
- **브라우저 단에서 동작하는 단일 페이지 웹앱(SPA)** 형태로 동작
- **localStorage 기반 영구 저장**
  - `lm_links`: 링크 데이터 저장
  - `lm_folders`: 폴더 목록 저장
- **메타데이터 추출(웹페이지 HTML 파싱)**
  - `og:title`, `og:description`, `og:image` 등 메타 태그 우선 활용
  - 유튜브 링크는 videoId를 파싱해 `img.youtube.com` 썸네일을 사용
- **Gemini 연동 시 안전장치**
  - “제공된 실제 텍스트 기반으로만 요약”하도록 시스템 프롬프트로 제한
  - 결과는 JSON 형식으로만 반환받아 UI에 반영
