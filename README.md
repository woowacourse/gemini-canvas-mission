# 🚀 Gemini Canvas Web App Collections

Gemini AI를 활용하여 제작한 4가지 웹 애플리케이션 컬렉션입니다. 유틸리티, 게임, 학습, 생활 밀착형 서비스까지 다양한 영역의 결과물을 확인하실 수 있습니다.

## 📱 애플리케이션 목록

### 1. **AlgoLog (알고로그)** 📝

_코딩 테스트 기록의 번거로움을 해결하는 스마트한 동반자_

- **배포 링크**: [https://gemini.google.com/share/660cf7c5e5e4](https://gemini.google.com/share/660cf7c5e5e4)
- **제작 이유**: 코딩 테스트를 풀고 나면 노션에 문제 정보를 하나하나 직접 입력해야 해서 번거로운 점을 해결하고 싶었습니다. 문제 링크/코드만 넣으면 AI가 정보를 자동 채워주고, 잔디/차트로 약점 유형을 한눈에 파악하기 위해 제작했습니다.
- **주요 기능**:
  - 문제 정보 자동 추출 (Gemini API 활용)
  - AI 채점 및 피드백 (제출 코드 기반)
  - 활동 잔디 히트맵, 난이도 비율, 알고리즘별 그래프 등 데이터 시각화
  - 문제 목록 검색 및 다크모드 지원
- **AI 기능**:
  - 링크 기반 데이터 추출 (사이트명, 문제번호, 난이도, 알고리즘 분류 등)
  - 코드 분석 기반 종합 피드백 생성 (개선점 및 최적화 방향 제안)

### 2. **十二將棋 (십이장기)** ♟️

_지략과 전술이 맞붙는 12칸의 전장_

- **배포 링크**: [https://gemini.google.com/share/1acdf70789c0](https://gemini.google.com/share/1acdf70789c0)
- **제작 이유**: 예능 '더 지니어스'의 인기 게임인 십이장기를 친구들과 함께 즐기고 싶어 제작했습니다.
- **주요 기능**:
  - 2인 로컬 플레이 (이름 및 선공 설정 가능)
  - 각 플레이어 시점별 화면 전환 (동일 보드, 시점만 변경)
  - 말의 종류별(장, 상, 왕, 자/후) 한자 표시 및 이동 가능 표식 제공
  - 포로 사용 기능 및 무르기 지원
  - 경기 기록 저장 (승자, 턴 수, 승리 이유 등)
- **게임 규칙**:
  - 12칸의 판에서 상대 왕을 잡거나, 자신의 왕이 상대 진영에 들어가 한 턴을 버티면 승리

### 3. **바이브코테 (Vibe Coding Test)** 🔥

_코딩은 AI에게 맡기고, 당신은 논리에만 집중하세요_

- **배포 링크**: [https://gemini.google.com/share/cf27c7f935f0](https://gemini.google.com/share/cf27c7f935f0)
- **제작 이유**: 코드를 먼저 치기보다, 문제를 어떻게 풀지 ‘논리적으로 설계하는 능력’을 빠르게 연습하고 싶어 제작했습니다.
- **주요 기능**:
  - 난이도(Lv 1~5) 기반 AI 문제 생성
  - **풀이 논리 제출**: 코드가 아닌 텍스트로 접근 방식 제출
  - AI 채점: 사용자의 논리를 분석해 0~100점 채점 및 상세 피드백 제공
  - 정답 코드 다국어 변환 (Gemini API 활용)
  - 타이머 및 전체 풀이 기록 평균 관리
- **AI의 역할**: 출제자, 채점자, 튜터 역할을 동시에 수행하여 설계 중심의 학습을 지원

### 4. **모닝빵 (Morning Bbang)** 🥐

_당신의 완벽한 아침을 굽는 루틴 메이커_

- **배포 링크**: [https://gemini.google.com/share/9ca2116a1000](https://gemini.google.com/share/9ca2116a1000)
- **제작 이유**: 교육장에 오기 전 필요한 물건을 챙기지 못하는 일을 방지하고자 만들었습니다. 실시간 위치와 목적지의 날씨를 고려한 스마트한 체크리스트가 필요했습니다.
- **주요 기능**:
  - 실시간 날씨 정보 및 기상 특보 카드
  - 맞춤형 아침 루틴 관리 (진행률 표시)
  - AI 기반 소지품 추천 (오늘 날씨와 상황 고려)
- **AI 기능**: 날씨 정보를 분석해 우산, 마스크, 선크림 등 상황에 맞는 외출 필수품 자동 판단 및 추천
