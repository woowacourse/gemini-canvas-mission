## 앱 이름: ☯️ 사주 AI 도사
## 카테고리: 🦾 유틸리티 앱

### 배포 링크
[https://gemini.google.com/share/5602a2eb710e]

### 이 앱을 만든 이유
- 해결하고자 한 문제
  - 기존 사주 서비스는 한자 위주의 복잡한 화면과 어려운 전문 용어 때문에 초보자가 접근하기 어려웠습니다.
    또한, 단순히 텍스트만 나열되는 방식은 인생의 전체적인 사주 흐름을 파악하기에 직관성이 떨어졌습니다.
- 사용 시점 및 방법
  - 자신의 성향이 궁금하거나 올해의 운세 흐름을 파악하고 싶을 때 사용합니다.
    생년월일시를 입력하여 인생 그래프를 확인하고, 궁금한 점은 실시간 AI 채팅을 통해 바로 질문할 수 있습니다.

### 주요 기능
1. 🧮 정밀 만세력 산출
- 인공지능의 계산 오류(환각 현상)를 방지하기 위해 앱 내부 알고리즘으로 연/월/일/시주를 정확히 계산합니다.
2. 🔥 오행 시각화 대시보드
- 사주 8글자의 배경색을 오행(목, 화, 토, 금, 수) 고유 색상으로 표시하여 기운의 분포를 한눈에 보여줍니다.
3. 📈 SVG 인생 총운 그래프
- 0세부터 80세까지의 대운 흐름을 꺾은선 그래프로 시각화하여 인생의 성수기를 파악할 수 있게 돕습니다.
4. 🧚 신살 및 귀인 판별
- 도화살, 역마살, 천을귀인 등 주요 신살을 정밀 로직으로 추출하여 설명합니다.

### AI 기능
- 어떤 AI 기능을 추가했나요?
  - Gemini 2.5 Flash 모델을 활용한 '사주 통변 및 실시간 상담' 기능을 추가했습니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
  - 계산된 사주 명식과 신살 데이터를 바탕으로 사용자에게 친절한 풀이를 제공합니다.
    특히 사용자의 추가 질문에 대해 문맥을 유지하며 명리학적 조언을 건네는 인터랙티브한 상담가 역할을 수행합니다.   

## AI 사용 일지

### 1. 초기 프롬포트
"초보자를 위한 사주 웹앱을 만들어줘. 
처음 시작할 때 생년월일시를 입력하고, 양력 유무와 성별과 태어난 장소를 입력하게 해줘. 
자체 공식을 이용해서 사주 팔자 글자들을 보여주고, 
기본적인 인생 사주를 읋어줘. 그러고 나서 궁금한 점을 질문을 받아.
html/css/js 만을 사용해서 코드를 작성해줘."

### 2. 프롬포트 개선 과정
- 문제점
  - 초기 결과물에서 AI가 사주 팔자(60갑자)를 계산할 때 틀린 글자를 제시하는 '환각 현상'이 발생했습니다.
  또한 모든 글자의 배경색이 주황색(토)으로만 나오는 UI 버그가 있었습니다.
- 수정 방식
  - AI에게 계산을 맡기지 않고, 직접 자바스크립트로 만세력 계산 로직을 짜게 한 뒤 "이 계산 결과가 정답이니 이것을 바탕으로 풀이만 해라"라고 지시를 강화했습니다. 
  UI 수정을 위해 구체적인 CSS 색상 코드와 레이아웃 구조를 명시했습니다.
- 반복 횟수: 약 15회 이상의 반복 수정을 통해 디자인과 로직의 완성도를 높였습니다.

### 4. 배운 점

  '계산은 코드(JS)가, 해석은 AI가' 하는 역할 분담이 앱의 신뢰도를 높이는 핵심임을 배웠습니다.

### 5. 리뷰어에게 피드백 받고 싶은 포인트
- 순수 자바스크립트로 구현된 만세력 알고리즘과 AI 풀이 간의 연결이 자연스러운지, 그리고 인생 그래프의 시각적 요소가 유틸리티 앱으로서 충분한 정보를 전달하고 있는지 피드백을 받고 싶습니다.
