# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 💻 1. 유틸리티 앱

### 앱 이름
Lean Roulette
### 배포 링크
https://gemini.google.com/share/ed6227b91bbd

### 이 앱을 만든 이유

- 현대인은 다양한 선택지 속에서 결정을 어려워하는 경우가 많습니다. 기존 랜덤 추첨 방식은 모든 선택지를 동일 확률로 처리해 실제 선호도를 반영하지 못하는 한계가 있습니다. 이 앱은 각 선택지에 가중치를 적용하여 사용자의 마음에 더 가까운 결과를 도출하도록 돕기 위해 제작했습니다.

### 주요 기능

- 가중치 기반 확률 자동 계산 및 랜덤 추첨
- 룰렛 애니메이션 및 결과 모달 출력
- 결정 히스토리 자동 저장 (localStorage 기반 유지)
- AI 선택지 추천 기능
- AI 장단점 분석 기능

## 🎮 2. 게임

### 앱 이름
Emoji Pair Game
### 배포 링크
https://gemini.google.com/share/79b4203ad931
### 이 앱을 만든 이유

- 앱 설치나 회원가입 없이 웹 브라우저에서 즉시 실행 가능한 가볍고 직관적인 두뇌 훈련 게임을 제공하고자 제작했습니다. 짧은 시간 동안 집중력을 환기할 수 있는 간단한 기억력 게임을 목표로 설계했습니다.

### 주요 기능

- 난이도 조절 (Easy 4x4 / Medium 4x5 / Hard 6x6)

- 실시간 타이머 및 시도 횟수 트래킹

- 3D 카드 뒤집기 및 매칭 애니메이션

- 모바일·태블릿·데스크톱 반응형 UI

## 📚 3. 학습 앱

### 앱 이름
Android Flow Lab
### 배포 링크
https://gemini.google.com/share/2ded1a7deaf8

### 이 앱을 만든 이유

- 안드로이드 입문자들이 Activity·Fragment 생명주기와 MVVM 데이터 흐름을 텍스트만으로 이해하기 어렵다는 문제를 해결하기 위해 제작했습니다. 정적인 다이어그램이 아닌, 직접 클릭하며 체험하는 시각적 학습 도구를 제공하고자 했습니다.

### 주요 기능

- Activity 생명주기 시뮬레이션 (onCreate → onDestroy)

- MVVM 데이터 흐름 애니메이션 시각화

- 13문항 객관식 퀴즈 및 해설 제공



## 🤝 4. 페어 프롬프트 릴레이 앱

### 앱 이름
고전 양궁 대결
### 페어
@First_woosun, @todays-sun-day

### 배포 링크
https://gemini.google.com/share/2231b056f4cb

### 이 앱을 만든 이유

- 과거 플래시 게임 시절의 로컬 2인용 대전 감성을 설치 없이 웹에서 즉시 즐길 수 있도록 구현하고자 제작했습니다. 단순한 물리 요소(각도·파워·바람)를 활용한 전략적 대전 재미를 제공하는 것을 목표로 했습니다.

### 주요 기능

- 로컬 멀티플레이 (한 기기에서 2인 대전)

- 선공 선택 시스템

- 바람 기반 물리 시스템 및 충전식 파워 조절

- 부위별 피격 판정(헤드샷 추가 데미지 및 추가 턴)

- 자해/자멸 전략 요소 구현
