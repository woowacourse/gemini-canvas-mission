# 🚀 Java & Spring Deep Dive (AI Quiz App)

**Java & Spring Deep Dive**는 Java와 Spring 프레임워크의 심화 개념을 학습하기 위해 설계된 **AI 기반 대화형 퀴즈 애플리케이션**입니다. 단순 암기식 퀴즈에서 벗어나, Google의 Gemini AI를 활용하여 실시간으로 고품질의 심층 질문을 생성하고 상세한 해설을 제공합니다.

---

## ✨ 주요 특징

### 🤖 AI 실시간 문제 생성
- **Gemini 2.5 Flash** 모델 연동
- 매번 새로운 문제를 생성하여 중복 없는 학습 경험 제공
- 단순 문법을 넘어선 아키텍처 중심의 질문 구성

---

### ⚙️ 맞춤형 학습 설정
- **주제 선택**: Java, Spring, 또는 혼합(Mixed) 테마 지원
- **3단계 난이도**: 
  - **쉬움**: 기초 개념 및 API 사용법
  - **보통**: 디자인 패턴 및 핵심 메커니즘
  - **어려움**: JVM 내부 구조, 프록시 동작, 성능 최적화

---

### 💡 심층 피드백 시스템
- **개별 해설**: 모든 선택지에 대한 정답/오답 근거 제공
- **도전 기능**: '다시 도전'을 통해 스스로 정답을 찾을 기회 제공
- **풀 분석**: 전체 선택지에 대한 심화 가이드 확인 가능

---

### 📊 오답 분석 리포트
- 틀린 문제만 모아보는 집중 복습 모드
- 자신의 지식 빈틈을 시각적으로 확인
- 최근 학습 이력 기반의 오답 대시보드

---

### 📱 반응형 UI/UX
- **Modern Design**: Tailwind CSS 기반의 깔끔한 인터페이스
- **Cross Device**: 데스크톱, 태블릿, 모바일 완벽 최적화
- **Interactive**: 부드러운 화면 전환과 애니메이션 효과

---

## 🕹 사용 방법

### 1️⃣ 학습 설정
메인 화면에서 학습하고자 하는 **주제**와 본인에게 맞는 **난이도**를 선택합니다.

---

### 2️⃣ Deep Dive 시작
버튼을 클릭하면 AI가 약 2~3초 내로 주제에 최적화된 5개의 심층 질문을 생성합니다.

---

### 3️⃣ 퀴즈 진행 및 분석
- 문제를 읽고 최선의 답을 선택합니다.
- 틀렸을 경우, AI가 분석한 **오답의 이유**를 먼저 확인하며 사고를 교정합니다.
- '심층 해설 보기'를 통해 정답의 원리를 완전히 체득합니다.

---

### 4️⃣ 최종 리포트
모든 문제를 풀고 난 후 **점수**를 확인하고, **오답 분석 리포트**를 통해 최종 복습을 마칩니다.

---
