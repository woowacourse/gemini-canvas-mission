# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.


## 💻 1. 유틸리티 앱

### 앱 이름
우아한 핑계
### 배포 링크
https://gemini.google.com/share/cb398ef58bfa
### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
사회생활을 하다 보면 회식, 지인 약속, 운동 등 참석하기 싫지만 거절하기 난감한 상황이 자주 발생합니다. 
매번 적절한 핑계를 생각하느라 스트레스를 받고, 자칫 인간관계가 상할까 봐 걱정하는 현대인들의 '거절 스트레스'와 '귀찮음'을 해결하고자 했습니다.
- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
혹은 주말에 누워있고 싶은데 친구가 부를 때 등 약속을 피하고 싶을 때 
앱을 켜서 상황과 대상을 입력하고 생성된 문구를 바로 복사하여 보낼 것입니다.

### 주요 기능

- 기능 1
* 맞춤형 핑계 생성 기능: 대상(상사, 친구 등), 상황, 그리고 원하는 톤앤매너(정중, 유머, 반박불가 등)를 조합하여 상황에 딱 맞는 변명거리를 생성합니다.

- 기능 2
* 원클릭 복붙 기능: 모바일 환경을 고려하여 생성된 텍스트를 드래그할 필요 없이 버튼 한 번으로 클립보드에 복사해 메신저로 바로 전달할 수 있게 합니다.
### AI 기능 (해당되는 경우)

- 어떤 AI 기능을 추가했나요?
Gemini API를 활용한 텍스트 생성 기능을 추가했습니다.

- AI 기능이 앱에서 어떤 역할을 하나요?
사용자가 선택한 옵션(대상, 상황, 톤)을 조합하여 자연스러운 1인칭 대화체의 메신저용 핑계 문구를 실시간으로 창작해 냅니다. 
고정된 텍스트가 아닌, 매번 새로운 상황에 맞는 유연하고 창의적인 문장을 만들어내는 핵심 엔진 역할을 합니다.

## 🎮 2. 게임

### 앱 이름
우아한 레이싱
### 배포 링크
https://gemini.google.com/share/af8b09855e3a
### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
설치나 무거운 프로그램 실행 없이, 웹 브라우저 접속만으로 즐길 수 있는 게임이 필요했습니다. 
복잡한 룰을 외울 필요 없이 '장애물을 피하며 가장 빠르게 달린다'는 원초적인 재미와 속도감, 다양한 아이템들을 제공하여 일상 속의 답답함을 해소하고자 했습니다.

- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
공부나 코딩, 업무 중간에 짧은 휴식이 필요할 때 플레이할 것입니다. 
1~2분 내외의 짧은 플레이 타임 동안 최고 기록을 경신하기 위해 집중력을 발휘하며 기분 전환을 하는 용도로 사용할 계획입니다.

### 주요 기능

- 기능 1
* 다이내믹 1인칭 드라이빙 & 물리 엔진
 단순한 이동을 넘어 속도에 비례한 카메라 흔들림(Shake), 코너링 시 차체 기울어짐, 속도감에 따른 시야각(FOV) 변화 등을 구현하여 실제 운전석에 앉은 듯한 극대화된 몰입감을 제공합니다.
    
* 긴급 회피 액션 (Dash) 순간적으로 위기를 탈출할 수 있도록 Shift + 방향키를 이용해 차선 하나를 눈 깜짝할 새 이동하는 액션 요소를 더했습니다.
- 기능 2
* 하이 리스크 하이 리턴 점수 시스템 
 안전하게 느린 속도로 달리면 점수가 거의 오르지 않지만, 충돌의 위험을 안고 최고 속도를 유지하면 점수 획득량이 기하급수적으로 폭발하는 시스템을 통해 플레이어의 도전을 유도합니다.

- 기능 3
* 아이템 
    * 🟡 노란 보석 (부스터): 3초간 시야각이 찢어지듯 넓어지며 다른 차들을 튕겨내는 무적 초고속 돌진.
    * 🔵 파란 보석 (보호막): 치명적인 충돌을 1회 완벽하게 방어해 주는 쉴드 전개.
    * 🟣 보라 보석 (소형화): 차체가 낮아지고 좁아져, 촘촘한 장애물 사이를 요리조리 피하는 데 특화.

- 기능 4 
* 장애물
    * 절차적 무한 맵 & 동적 장애물 다가오는 일반 차량, 역주행 차량, 그리고 차선 중앙을 막는 공사 바리케이드가 끊임없이 랜덤하게 생성되며, 진행 거리에 따라 난이도가 자연스럽게 증가합니다.

- 처음 결과물의 문제점은 무엇이었나요?

- 어떤 식으로 프롬프트를 수정했나요?
선택한 옵션에 따른 API 호출 시 전달하는 시스템 지시어를 수정했습니다. 
보낼 대상이 '상사'나 '어색한 지인'일 경우 절대 장난스럽거나 비현실적인 변명을 하지 말고 극도로 현실적일 것, 가상의 병명 금지, 노로바이러스나 장염 등 되물을 수 없는 구체적인 이유로라는 부정 제약 조건을 추가했습니다.
- 몇 번의 반복을 거쳤나요?
3번의 반복을 거쳤습니다.
dalgak 에서 추출한 프롬포트가 워낙 자세하고 세밀해서 처음부터 만족스러운 결과가 나왔습니다.
