## 카테고리: 학습 앱

### 배포 링크

https://gemini.google.com/share/7f8c1af22dc5

<br/>

### 이 앱을 만든 이유

**해결하고자 한 문제**
> 쿠버네티스는 현대 IT 인프라의 핵심이지만, 입문자가 처음 접하기에는 인그레스(Ingress), 서비스(Service), 포드(Pod) 등 추상적인 개념이 너무 많고 흐름을 시각적으로 이해하기 어렵습니다.

**활용 방안**
> 신입 개발자 온보딩 교육, 학생들의 클라우드 기초 학습, 혹은 기술 세미나에서 쿠버네티스의 핵심 철학(선언적 관리, 자기 치유, 확장성)을 직관적으로 설명할 때 사용합니다.

<br/>

### 주요 기능

**단계별 인터랙티브 시나리오**
> `웹사이트 접속`, `자기 치유(복구)`, `오토스케일링`의 3가지 핵심 상황을 사용자가 직접 화살표 키나 버튼으로 넘겨보며 학습할 수 있습니다.

**현실 세계 비유 시스템**
> 쿠버네티스에 대해 모르는 사용자를 위해 비유를 활용하여 이해를 돕습니다.
- **Ingress**: 마을의 '정문 보안 요원과 안내 표지판'
- **Service**: 목록을 확인해 연결해주는 '안내데스크/관리사무소'
- **Pod**: 여러 전문가(컨테이너)가 모여 일하는 '작업 팀'
- **Control Plane**: 계획표를 지키는 '관리자 로봇'


**수동 제어 및 애니메이션**
> 사용자의 학습 속도에 맞춰 이전/다음 단계를 조절할 수 있으며, 패킷의 이동과 노드의 상태 변화가 실시간 애니메이션으로 구현됩니다.

**복습 퀴즈 및 보상**
> 시나리오 종료 후 핵심 용어를 묻는 퀴즈를 제공하며, 정답 시 폭죽 애니메이션과 함께 학습 완료 체크 표시를 부여하여 동기를 부여합니다.

**공간 분리 레이아웃**
> 시각 자료(좌측)와 텍스트 설명(우측) 공간을 엄격히 분리하여 화면이 겹치지 않고 가독성이 높습니다.
