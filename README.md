# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 💻 1. 유틸리티 앱 : ✨ 보송 청소 매니저

**자취생과 1인 가구를 위해, 다정하고 똑똑하게 집안일 주기를 관리해 주는 웹 애플리케이션입니다.**

이 앱은 '언제 청소했더라?' 하는 기억의 부담을 덜어주고, 딱딱한 알림 대신 다정한 룸메이트처럼 청소 시기를 챙겨주어 사용자가 스트레스 없이 쾌적한 생활 공간을 유지할 수 있도록 설계되었습니다.

## 🌟 주요 특징

### 1. 직관적인 상태 알림과 다정한 동기부여

- 각 집안일의 남은 주기에 따라 카드의 색상이 부드러운 파스텔톤(임박 시 노란색, 지났을 시 분홍색 은은한 글로우 효과)으로 변합니다.
- 기계적인 명령이 아닌 "슬슬 화장실 바닥이 미끄러워지려 해요. 가볍게 닦아볼까요?"와 같은 친근한 권유 문구로 청소를 기분 좋게 시작할 수 있게 돕습니다.

### 2. 원클릭 기록 및 스마트 주기 계산

- 청소를 마친 후 카드 하단의 **'✓ 완료'** 버튼을 누르면 즉시 완료 기록이 저장됩니다.
- 기록된 날짜를 바탕으로 사용자가 설정한 주기에 맞춰 '다음 예정일'과 '경과일'이 자동으로 계산되어 표시됩니다.

### 3. 나만의 맞춤형 청소 주기 설정

- 사용자의 라이프스타일과 집 크기에 맞춰 화장실 청소, 분리수거, 이불 빨래 등 8가지 기본 집안일의 목표 주기를(일 단위) 자유롭게 수정할 수 있습니다.

### 4. 꼼꼼한 활동 기록(청소 발자국) 및 수정

- **활동 기록 탭:** 전체 로그를 보거나 드롭다운 필터를 이용해 특정 집안일(예: 빨래)의 기록만 모아볼 수 있습니다.
- **기록 수정:** 청소 후 기록하는 것을 깜빡했더라도, 연필 아이콘을 눌러 실제 청소했던 과거의 시간으로 정확하게 수정할 수 있습니다.

### 5. 클라우드 기반 실시간 동기화

- 이메일 계정을 통한 회원가입/로그인 시스템을 제공합니다.
- Firebase를 연동하여 기기나 브라우저가 바뀌어도 나의 청소 설정과 과거 발자국들을 안전하게 불러오고 관리할 수 있습니다.

## 🛠 사용된 기술

- **Language:** 순수 JavaScript (Vanilla JS, ES6 Modules)
- **Markup:** HTML5
- **Styling:** CSS3 (Custom Variables, CSS Grid/Flexbox, Keyframe Animations 적용)
- **Backend/BaaS:** Firebase (Authentication, Cloud Firestore)
- **Font:** Gowun Dodum, Noto Sans KR (Google Fonts)

## 🚀 실행 방법

1. `index.html` 파일을 다운로드합니다.
2. 인터넷이 연결된 상태에서 최신 브라우저(Chrome, Safari 등)로 파일을 엽니다. (Firebase 통신을 위해 인터넷 연결 필수)
3. **가입하기**를 통해 이메일 계정을 생성하고 나만의 청소 주기를 관리해 보세요!

## 🧹 기본 관리 집안일 구성

- **위생 관리:** 화장실 청소
- **쓰레기 관리:** 음식물 쓰레기 비우기, 재활용 쓰레기 분리수거, 일반 쓰레기 비우기
- **공간 관리:** 바닥 청소(청소기/물걸레), 먼지 털기
- **세탁 관리:** 옷 빨래, 이불 빨래

**"보송 청소 매니저와 함께 매일매일 상쾌하고 보송보송한 일상을 만들어보세요!"**

## 🎮 2. 게임 : 🐢 바다거북 프로파일러

**수사물 매니아를 위해, AI가 게임 마스터가 되어주는 바다거북스프 형식의 추리 게임 웹 애플리케이션입니다.**

이 앱은 사건의 전말을 아는 '출제자'가 없으면 플레이하기 힘들었던 기존 바다거북스프 게임의 한계를 극복하고, 언제 어디서든 혼자서도 실감 나는 수사 시뮬레이션과 몰입감 넘치는 추리를 즐길 수 있도록 설계되었습니다.

## 🌟 주요 특징

### 1. 멀티 캐릭터 메신저 인터페이스

* 익숙한 모바일 메신저 UI를 채택하여 범인, 용의자, 피해자 등 각기 다른 입장을 가진 캐릭터들과 개별 채팅방에서 대화할 수 있습니다.
* 캐릭터들은 각자의 성격, 직군(프론트엔드/백엔드 크루 등), 알리바이에 맞춰 고유한 말투로 생동감 있게 반응합니다.

### 2. 고도화된 바다거북스프식 질답 시스템

* 모든 인물은 사용자의 질문에 자신이 아는 사실을 기반으로 오직 '예/아니오'로만 대답합니다.
* 질문이 사건의 핵심 전말에 근접할 경우 결정적인 힌트를 조금씩 흘려주며, 무관한 질문에는 캐릭터 특성이 담긴 재치 있는 코멘트로 대답해 지루할 틈 없는 추리를 돕습니다.

### 3. 지능형 정답 판별 (AI 강력반 형사)

* 사용자가 사건의 전말(범인, 동기, 상황)을 파악한 후, 형사 캐릭터에게 자유로운 문장 형식으로 정답을 보고할 수 있습니다.
* 단순 키워드 매칭이 아닌, AI가 문맥을 분석하여 범인 지목과 범행 동기가 논리적으로 완벽히 일치하는지 판단하고 '검거 성공' 여부를 결정합니다.

### 4. 시각적 물적 증거 인벤토리

* 단순히 텍스트로만 단서를 제공하는 것을 넘어, 포스트잇이나 과자 부스러기 같은 물적 증거를 직관적인 아이콘(SVG) 요소로 제공합니다.
* 실제 현장에서 단서를 수집하고 조사하는 듯한 시각적 몰입감을 더해줍니다.

### 5. Gemini AI 기반 동적 페르소나

* 하드코딩된 대본이 아닌 Google Gemini API를 활용하여, 사용자의 창의적이고 예상치 못한 질문에도 각 캐릭터의 지식 범위와 비밀(진실) 안에서 자연스럽게 대응합니다.
* 대화 기록을 기억하여 같은 질문을 반복하면 짜증을 내는 등 현실감 넘치는 상호작용을 제공합니다.

## 🛠 사용된 기술

* **Language:** 순수 JavaScript (Vanilla JS, ES6 async/await)
* **Markup:** HTML5
* **Styling:** CSS3 (Custom Variables, Flexbox, K사 메신저 테마 UI 구현)
* **AI/API:** Google Gemini API (gemini-2.5-flash)
* **Font:** Pretendard

## 🚀 실행 방법

1. `index.html` 파일을 다운로드합니다.
2. 인터넷이 연결된 상태에서 최신 브라우저(Chrome, Safari 등)로 파일을 엽니다. (AI 통신을 위해 인터넷 연결 필수)
3. 수사 본부(대화 탭)에 접속하여 용의자들과 대화하며 숨겨진 진실을 파헤쳐 보세요!

## 📂 사건 파일: 사라진 두쫀쿠의 행방

* **피해자 (테리):** 한정판 두쫀쿠를 도난당해 슬퍼하는 원주인
* **용의자 A (어피치):** 48시간째 메모리 누수를 잡느라 좀비가 된 백엔드 크루
* **용의자 B (춘식이):** 탕비실 간식 위치를 꿰고 있는 억울한 프론트엔드 크루
* **판별관 (강력반 형사):** 최종 수사 브리핑을 듣고 사건을 종결하는 베테랑 형사
* 
**"바다거북 프로파일러와 함께 날카로운 직관으로 숨겨진 진실을 밝혀내는 명탐정이 되어보세요!"**

## 📚 3. 학습 앱 : ☕ Java Master Quiz

**Java 기초부터 최신 Java 21 버전의 신기능까지 완벽하게 학습할 수 있는 인터랙티브 퀴즈 애플리케이션입니다.**

이 앱은 초보자부터 고수까지 모든 단계의 개발자가 Java의 핵심 개념과 최신 트렌드를 재미있고 체계적으로 익힐 수 있도록 설계되었습니다.

## 🌟 주요 특징

### 1. 중복 없는 스마트 문제 시스템
* 사용자가 한 번이라도 확인한 문제(정답, 오답, 건너뛰기 포함)는 학습 이력에 실시간으로 기록됩니다.
* 학습 세션을 새로 시작할 때 이미 본 문제는 출제 범위에서 영구적으로 제외되어 항상 새로운 문제를 접할 수 있습니다.

### 2. Java 21 최신 문법 반영
* 전통적인 Java 문법은 물론, **Sequenced Collections, Virtual Threads, Sealed Classes, Record** 등 최신 Java 21 버전의 핵심 기능들을 퀴즈를 통해 학습할 수 있습니다.

### 3. 맞춤형 난이도 필터
* **초보 / 중수 / 고수 / 전체** 4가지 모드를 제공하여 자신의 현재 실력에 맞는 문제를 선택해 풀 수 있습니다.
* 각 난이도별 정복 상태를 대시보드에서 실시간으로 확인할 수 있으며, 마지막으로 선택한 난이도가 자동으로 저장됩니다.

### 4. 고도화된 오답노트 및 학습 관리
* **대시보드:** 정답 개수와 오답 개수를 한눈에 파악합니다.
* **내역 확인:** 상세 리스트를 통해 정답과 해설을 토글 형식으로 다시 복습할 수 있습니다.
* **오답 팝업:** 틀린 문제만 모아 팝업창에서 다시 풀 수 있으며, 한 번에 맞춘 문제는 자동으로 오답 내역에서 삭제됩니다.

### 5. 사용자 친화적 UI/UX
* Java 테마(Blue & Orange)를 반영한 모던하고 깔끔한 디자인.
* 모든 문제를 정복했을 때 나타나는 특별한 축하 모달과 "Coming Soon" 안내 시스템.
* 브라우저 기본 알림 대신 일관성 있는 커스텀 모달 팝업 적용.

## 🛠 사용된 기술

* **Language:** 순수 JavaScript (Vanilla JS)

* **Styling:** CSS3 (Custom Variables, Flexbox, Grid 활용)

1. `index.html` 파일을 다운로드합니다.

* **고수:** JVM 구조, 가비지 컬렉션(GC) 전략, 동시성 프로그래밍, Java 21 신규 API 및 가상 스레드.

## 🤝 4. 페어 프롬프트 릴레이 앱 : 우테코 회고 자동 작성기 (Review Writer)

구글 로그인 후 사용 부탁드립니다!

### 배포 링크
https://gemini.google.com/share/58cd2dd5c9f7

### 이 앱을 만든 이유

**해결하고자 한 문제**
> 우테코의 고된 하루를 마치고 침대에 누운 크루들에게 매일 기록해야 하는 '회고'는 귀찮은 일입니다.  
> 피곤한 상태에서도 최소한의 입력만으로 깊이 있는 성찰이 담긴 회고록을 완성할 수 있도록 돕고자 했습니다.

**사용 시점 및 방법**
> 우테코 미션이나 강의가 끝나고 자기 직전, 모바일이나 노트북으로 오늘 한 일을 키워드 위주로 입력하여 사용합니다.
> 오늘 한 일들에 대한 질문을 던지면 답하는 과정에서 자연스럽게 '도전'에 대해서 회고해보고,
> 완성된 글을 복사해 블로그나 학습로그에 활용합니다.

### 주요 기능

**도전에 대한 성찰 유도**
> 오늘 한 일에 대해서 도전에 대해 다시 성찰해볼 수 있도록 2단계의 심층 질문을 제공합니다.

**자동 회고 작성**
> 오늘 한 일과 질문에 대한 답변을 토대로 오늘의 회고를 자동으로 작성하여 제공합니다.

**4단계 스탭 UI**
> `오늘 한 일` -> `1차 질문` -> `꼬리 질문` -> `최종 완성` 의 명확한 진행 단계를 제공합니다.

**다크 모드 최적화**
> 심야 시간대 사용자를 고려하여 눈의 피로를 최소화하는 어두운 테마와 넓은 터치 타겟을 적용했습니다.

**회고 편집 및 복사**
> AI가 작성한 초안을 '편집' 탭에서 직접 수정할 수 있으며, 버튼 클릭 한 번으로 클립보드에 복사할 수 있습니다.

### AI 기능

**문맥 인식 질문 생성**
> 사용자가 입력한 작업의 성격(설계, 구현, 협업 등)을 분석하여 성찰을 유도하는 1차 질문과 사용자 답변 기반으로 예리한 꼬리 질문을 생성합니다.

**1인칭 회고 대필**
> 사용자의 단편적인 답변들을 조합하여 "~했습니다" 체의 담백하고 전문적인 회고문을 대신 작성합니다.

**톤앤매너 컨트롤**
> 소위 오글거리는 수식어를 배제하고 사실과 깨달음 위주의 객관적인 복기가 가능하도록 프롬프트 엔지니어링이 적용되었습니다.
