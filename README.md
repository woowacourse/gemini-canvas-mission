# 🚀 Gemini Canvas Web App Mission

**Gemini Canvas**를 활용하여 프롬프트만으로 제작한 4종의 웹앱 컬렉션입니다.
"나에게 진짜 필요한 게 뭐지?"라는 질문에서 시작하여, 실생활에 유용한 유틸리티부터 학습 도구, 게임까지 동작하는 무언가를 세상에 내놓는 경험을 담았습니다.

## 🛠️ 기술 스택 및 요구사항 (Mission Requirements)

이 프로젝트는 아래의 엄격한 가이드라인을 준수하여 제작되었습니다.

* **No Framework:** React나 Vue 등 외부 프레임워크 없이 순수 **HTML, CSS, JavaScript**만 사용했습니다.
* **Gemini Canvas Only:** 구현은 오직 Gemini Canvas만을 사용하며, 프롬프트 제약 조건 안에서 유용한 앱을 만드는 것을 목표로 했습니다.
* **AI Integration:** 4개의 앱 중 최소 1개 이상에 **Gemini AI 기능**을 포함하여 사용자 입력을 분석하거나 피드백을 제공합니다.
* **Deployment:** 모든 앱은 정상 동작하는 배포 링크를 포함하고 있습니다.

## 🌟 앱별 핵심 요약

### 1. [유틸리티] ☯️ 사주 AI 도사 (Saju Master AI)
* **목표:** 복잡한 만세력 데이터를 시각화하여 사용자의 기운을 분석해 주는 라이프 사이클 매니저입니다.
* **핵심:** AI의 수치 계산 오류(환각)를 방지하기 위해 앱 내부 알고리즘으로 명식을 계산하고, **SVG 인생 총운 그래프**를 제공합니다.

### 2. [게임] 🧠 두뇌 트레이닝 (Brain Training)
* **목표:** 지뢰찾기, 스도쿠 등 4종의 퍼즐을 매일 랜덤으로 제공하여 두뇌 활성화를 돕는 게임입니다.
* **핵심:** 날짜별 시드(Seed)를 활용해 매일 다른 퍼즐을 배정하며, **Firebase 연동**을 통해 학습 진도를 달력에 기록합니다.

### 3. [학습 앱] 🧩 매일 코틀린 (Daily Kotlin)
* **목표:** 하루 하나씩 코틀린 개념과 알고리즘 문제를 정복하는 데일리 학습 카드 앱입니다.
* **핵심:** 초급부터 숙련자까지 **80개 이상의 학습 세트**를 구축하고, 실제 코딩 테스트 플랫폼(백준, 프로그래머스)과 연동됩니다.

### 4. [페어 릴레이] 🏹 고전 양궁 대결 (Classic Archery Duel)
* **목표:** 페어와 함께 프롬프트를 번갈아 입력하며 만든 물리 기반 2인용 대전 게임입니다.
* **핵심:** **Canvas API**를 활용한 정교한 화살 궤적과 바람 저항 시스템, 헤드샷 보너스 로직을 구현했습니다.
