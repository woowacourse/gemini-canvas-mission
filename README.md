# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 💻 1. 유틸리티 앱

### 앱 이름
배메추
### 배포 링크
https://gemini.google.com/share/9cf1f865fa68
### 이 앱을 만든 이유

- 판교캠퍼스는 새로 조성된 제2판교테크노밸리에 위치하여 주변 음식점에 대한 정보가 부족하고, 앞으로 많은 신규 음식점들이 입주될 것으로 예상됩니다.
- 본인 및 팀원들은 평소에 음식 메뉴 선정이나 주변 상권 정보 부재로 인해 불편함을 경험하였습니다.
- 따라서 메뉴 선정에 대한 고민을 줄여주고 맛집 리스트 공유 및 기록 하고자 해당 앱을 기획하게 되었습니다.

### 주요 기능

- 돌림판 기능
  - 기본적으로 제공되는 품목 외에도 사용자가 원하는 메뉴 추가 가능
- 맛집 리스트 저장 기능
  - 방문한 음식점의 가게명, 태그(음식명), 별점, 코멘트를 기록할 수 있음.
  - 돌림판과 연동하여, 돌림판에서 나온 결과물과 동일한 태그를 가진 음식점을 리스트 형태로 노출
- 최근 먹은 메뉴 기록
  - 돌림판을 돌려서 나온 결과물이 마음에 들어서 확정하게 된다면, 해당 음식을 최근에 먹은 음식에 기록함
  - 최근 먹은 메뉴 기록은 돌림판과 연동되어 3일내에 먹은 음식은 돌림판 후보에서 제외시킬 수 있음

## 🎮 2. 게임

### 앱 이름
우아한 웹 TRPG
### 배포 링크
https://gemini.google.com/share/e0c2ca49739b
### 이 앱을 만든 이유

- TRPG는 대화를 통해 함께 이야기를 만들어가는 스토리텔링 게임을 말합니다. 플레이어는 정해진 선택지를 누르는 대신, 이야기의 주인공이 되어 자신의 의지대로 자유롭게 행동하고 대화하며 서사를 이끌어갑니다.
- 게임의 흐름은 마스터와 플레이어의 상호작용으로 완성됩니다. 게임마스터가 눈앞의 상황을 생생하게 묘사하면, 플레이어는 자신의 캐릭터라면 이 위기를 어떻게 헤쳐 나갈지 결정하고 제안하는 방식으로 진행됩니다.
- 하지만 TRPG를 실제로 즐기기까지의 과정은 생각보다 훨씬 험난합니다. 가장 먼저 맞닥뜨리는 문제는 시간 맞추기 입니다. 마스터를 포함해 여러 명의 인원이 몇 시간 동안 동시에 접속해야 한다는 물리적 제약은 그 자체로 큰 벽이 됩니다.
- 심리적인 진입장벽 또한 무시할 수 없습니다. 처음 보는 사람들 앞에서 캐릭터를 연기해야 한다는 쑥스러움과, 게임을 시작하기도 전에 공부해야 하는 방대한 규칙들은 입문자들을 금방 지치게 만듭니다.
- 저는 AI를 통해 이러한 불편함을 해결하고 오직 이야기에만 몰입하는 환경을 만들고자 했습니다. 24시간 대기 중인 AI 마스터 덕분에 혼자서도 언제든 모험을 시작할 수 있으며, 복잡한 규칙 계산은 시스템이 대신 처리하여 누구나 가벼운 마음으로 주인공이 될 수 있습니다.

### 주요 기능

- 직업 선택 기능
  - 전사, 도적, 마법사 중 택1
  - 각 직업마다 고유한 스킬과 HP, MP, 골드 소지량을 가짐
- 아이템 사용
  - 게임 중 아이템을 습득할 수 있으며, 해당 아이템을 사용하여 스토리 진행에 도움을 받을 수 있음
- 업적 기능
  - 게임 진행 중 특정 비밀 조건을 달성하면 업적 달성 문구 표시.
- 엔딩
  - 해피 엔딩, 배드 엔딩 등 사용자의 선택에 따라 여러 엔딩을 구현

### AI 기능 (해당되는 경우)

- AI를 활용하여, TRPG에서 진행자 역할을 하는 게임 마스터 역할을 부여했습니다.
- 모든 전반적인 게임의 줄거리를 이끌며, 특정 상황에 조우했을 때 어떤 행동을 할지 플레이어에게 선택지를 제공합니다.
- 필요에 따라 아이템 사용 선택지를 제공해주기도 합니다.
- 플레이어가 제출한 응답에 따라 HP, MP, 아이템 등에도 상호작용하고 이를 시각적으로 확인할 수 있도록 UI에 반영합니다.

### 1. 초기 프롬프트

`챗봇 형식으로 진행되는 TRPG 게임을 만들어보려고 해.

배경은 중세 판타지이고, 너는 TRPG의 진행자이자 npc 역할을 수행해줘야해.

해당 앱은 HTML/CSS/JavaScript만으로 구현되어야 하는 조건이 있어.

UI에는 어떤 방식으로든 직업, 라이프, 소지 골드 등을 표시하는 기능이 있어야하고, 게임 진행에 따라 너가 바꿀 수 있어야 해. 기본적으로 2-3가지 정도의 엔딩이 있었으면 좋겠고, 게임 길이는 너무 길지 않게 스토리를 구성해줘.`

### 2. 프롬프트 개선 과정

- 처음 결과물에서는 게임의 디테일한 요소를 지정하지 못하여 게임을 재시작할 수 없거나, 직업 표시 칸은 있지만 선택할 수 없는 등의 문제가 발생하였습니다.
- 따라서 직접 테스트를 거친 후 해당 요소들을 리스트화하여 프롬프트를 입력하였습니다.
- 추가적으로 TRPG에 필요한 재미 요소도 부족하다고 생각하여 구체적으로 무엇을 더 추가하였으면 좋겠는지, 어떤 편의성을 제공하였으면 좋겠는지 등 AI에게 피드백하는 과정을 거쳤습니다.

### 3. 효과적이었던 프롬프팅 전략

- 작은 부분부터 시작하여 수정 항목들을 리스트화 하고 어느 위치에 어떤 기능이 어떤 문제가 있었는지 세세하게 지정해주는게 효과가 제일 좋았던 것 같습니다.
- 반대로 AI에게 알아서 맞긴 부분에서는 다소 아쉬운 모습을 보였습니다.

### 4. 배운 점

- 처음부터 큰 요소들을 전부 채울 생각으로 접근하는 것보단, 큰 틀에서 초안을 완성하고 디테일을 구성하는 것이 제일 만족스러운 결과물을 얻은 것 같습니다.
