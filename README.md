### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
단어장만 반복해서 보는 단순한 암기 방식은 지루하고 효율도 낮다. 특히 일상 속에서 마주치는 사물이나 상황을 외국어로 바로 알고 싶을 때, 매번 사전을 검색하는 과정이 번거롭게 느껴졌다. 이 불편함을 해결하기 위해, 사진 한 장만 올리면 AI가 즉시 분석해 학습에 최적화된 핵심 단어들을 추출해주는 앱을 제작하게 되었다.

- 이 앱을 언제, 어떻게 사용할 건가요?
길을 걷다 흥미로운 간판을 발견했을 때, 혹은 주변 사물을 외국어로 학습하고 싶을 때 즉시 활용할 수 있다. 사진 업로드만으로 나만의 맞춤 단어장이 자동 생성되며, 퀴즈 기능을 활용해 지인들과 학습 경쟁을 즐기는 용도로도 사용할 수 있다.

### 주요 기능
- 실시간 이미지 분석 및 단어 추출: 이미지를 업로드하거나 Ctrl+V로 붙여넣기하면 AI가 즉시 상황을 분석한다. 단어뿐만 아니라 실감 나는 예문과 해석까지 한 번에 제공한다.
- 지능형 퀴즈 시스템: 단어장의 전체 단어를 기반으로 4지선다형 퀴즈가 실시간 생성된다. 모든 단어가 정답으로 한 번씩 출제되어 빠짐없는 학습이 가능하다.
- 오답 정복 모드: 퀴즈에서 틀린 문제는 별도로 저장되며, '오답 정복하기' 기능을 통해 집중 반복 학습을 할 수 있다.
- AI 선생님과의 실시간 문답: 학습 중 궁금한 점이 생기면 하단 채팅창을 통해 Gemini AI에게 즉시 질문할 수 있다. 이미지 맥락이나 단어 뉘앙스에 대한 상세한 설명을 제공한다.
- 단어장 이미지 저장: 생성된 단어장을 이미지 파일로 저장할 수 있다. 이동 중 복습하거나 학습 인증샷으로 공유하기에 적합하다.

### AI 기능 (해당되는 경우)
- 어떤 AI 기능을 추가했나요?
이미지 기반 단어 추출, 동적 퀴즈 생성, 대화형 1:1 튜터링 기능을 탑재했다.

- AI 기능이 앱에서 어떤 역할을 하나요?
이미지를 분석해 상황을 한국어로 설명하고 학습에 유용한 단어를 지능적으로 선별한다. 또한 사용자가 업로드한 이미지에 따라 매번 새로운 퀴즈를 생성해 학습 긴장감을 유지하며, 대화형 인터페이스를 통해 학습자의 질문에 실시간으로 답변하는 개인 맞춤형 교사 역할을 수행한다.

### 2. 프롬프트 개선 과정
- 처음 결과물의 문제점은 무엇이었나요?
프롬프트로 요구한 기본 기능은 잘 구현되었지만, 실제 사용 환경에서 예상치 못한 오류가 있었습니다. 특히 퀴즈 생성 로직에서 AI가 데이터를 처리하는 동안 로딩이 길어지면 페이지가 튕기거나 초기화되는 현상이 발생했고, 이미지 붙여넣기(Ctrl+V) 기능이 특정 브라우저 환경에서 반응하지 않는 등 '사용자 경험(UX)' 측면의 디테일이 부족했습니다.
- 어떤 식으로 프롬프트를 수정했나요?
연하게 "고쳐줘"라고 하기보다는 발생한 오류 현상을 정확히 묘사하고, 코드의 어떤 부분에서 문제가 생겼는지 추측하여(예: 퀴즈 로딩 로직, 이벤트 바인딩 방식 등) 중요한 부분부터 하나씩 수정해 달라고 구체적으로 요청했습니다.
- 몇 번의 반복을 거쳤나요?
총 4~5번의 주요 반복(Iteration)을 거쳤습니다. 초기 레이아웃 설정, 핵심 기능 구현, 퀴즈 로직 수정, 붙여넣기 이벤트 최적화, 그리고 최종 UI/UX 다듬기 순으로 진행했습니다.

### 3. 효과적이었던 프롬프팅 전략
- 어떤 방식으로 요청했을 때 원하는 결과가 나왔나요?
초기 상세 설계: 첫 번째 프롬프트에서 앱의 목적, 타겟 사용자, 필수 기능을 상세히 설명하고 '페이지 번호'별로 기능을 나누어 요구했을 때 구조가 잘 잡혔습니다.

단계적 수정: 수정 요청 시 "페이지 2의 단어장 저장 버튼"처럼 위치를 명확히 지정하고, 한 번에 하나씩 기능을 개선하도록 유도했을 때 코드 꼬임 없이 정확한 결과가 나왔습니다.
- 반대로 효과가 없었던 방식은 무엇이었나요?
여러 개의 복잡한 오류를 한 번에 해결해 달라고 뭉뚱그려 요청하면, AI가 일부 기능을 누락하거나 기존에 잘 작동하던 코드를 삭제하는 경우가 있었습니다. 또한 추상적인 표현(예: "더 멋지게 만들어줘")은 의도와 다른 디자인이 나와 효과적이지 않았습니다.

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
SQL은 데이터 분석의 필수 언어지만, 딱딱한 이론 책이나 코딩 화면만 보면 금방 지루해진다. 기존 SQL 학습 사이트들은 공부하는 느낌이 강해 재미가 없었다. 이를 해결하기 위해 전 세계에서 가장 유명한 언어 학습 앱인 듀오링고의 요소를 SQL 학습에 접목했다. 블록 조립이나 타이핑을 통해 공부가 아닌 게임처럼 SQL을 익힐 수 있도록 제작했다.

- 이 앱을 언제, 어떻게 사용할 건가요?
지하철이나 버스 이동 중, 혹은 자기 전 10분 동안 가볍게 퀴즈를 풀며 SQL 감각을 유지할 것이다.

### 주요 기능
- 단계별 스테이지 학습: SQL 문법을 여러 스테이지로 나눠 원하는 문법을 선택해 학습할 수 있다. 각 스테이지는 반복 도전이 가능하며, 도전할 때마다 데이터베이스와 문제가 새롭게 바뀐다.
- 드래그 앤 드롭 SQL 빌더: SQL 키워드 블록을 순서대로 끌어다 놓으며 쿼리 문장을 완성할 수 있다. 복잡한 타이핑 없이 문법 구조를 시각적으로 익히는 데 효과적이다.
- 텍스트 입력 모드: SQL 쿼리를 직접 타이핑하여 처음부터 끝까지 스스로 문제를 해결한다. 직접 작성하는 과정을 통해 문법을 더 오래 기억할 수 있다.
- 실시간 데이터베이스 시뮬레이터: 정답 쿼리를 입력하면 가상의 데이터베이스 테이블에 즉시 반영되어 결과가 표시된다. 내가 작성한 코드에 따라 데이터가 어떻게 필터링되고 정렬되는지 테이블 형태로 직관적으로 확인할 수 있다.
- 듀오링고 스타일 하트 시스템: 스테이지 시작 시 하트 5개가 주어지며, 오답 제출 시마다 하트가 차감된다. 하트를 모두 소진하면 스테이지가 종료되어 게임처럼 긴장감을 유지하며 집중할 수 있다.
- 단계별 커리큘럼 및 이론 가이드: 조건 필터링(WHERE), 정렬(ORDER BY), 집계(SUM, AVG) 등 핵심 문법을 단계별로 구성했다. 각 스테이지 시작 전 이론 설명을 제공해 기초 없이도 학습이 가능하다.

- 이 앱을 언제, 어떻게 사용할 건가요?
1. 알고리즘 문제 풀이 직후
 내가 작성한 코드에 피드백을 받고 피드백 받은 내용을 바탕으로 학습 계획을 세운다.
 문제에 맞는 최적의 코드를 읽고 더 효율적인 코드 설계 방식에 대해 고민해 본다.
 
2. 학습 기록
 노션에 푼 문제를 정리할 때 문제의 카테고리와 주요 알고리즘, 내 코드 분석을
 노션에 정리하기 위해서 사용할 것이다.
 
3. 복습 설계
AI가 망각곡선을 이용해 에계산해주는 복습 일정으로 추후 복습 일정을 잡는다.


### 주요 기능
- 기능 1: 원클릭 코드 리뷰
사용자가 문제와 코드를 붙여넣기만 하면 AI가 성능과 가독성을 분석하여 피드백을 준다.

- 기능 2: 노션용 기록 제공
코드 피드백을 노션에 바로 붙여넣을 수 있도록 마크다운 문법으로 작성된 텍스트 제공한다. 

- 기능 3: 망각곡선을 이용한 복습 주기 설계 
오늘 날짜를 기준으로 AI가 망각곡선을 이용해 최적의 복습 날짜를 정해준다.

- 기능 4: 최적의 코드 제공
입력된 문제와 코드를 기반으로 최적의 코드를 제공한다.




### AI 기능
- AI 기능이 앱에서 어떤 역할을 하나요?
1. 문제와 코드 분석 및 피드백을 제공한다.
2. 문제 카테고리 분류를 분류한다.
3. 노션으로 붙여넣을 수 있는 마크다운 리포트를 작성한다.
4. 최적화된 코드를 제공한다.
