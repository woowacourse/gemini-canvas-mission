# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

---

# 1️⃣ 유틸리티 앱

## 🗓️ J들의 메모장 (J's Daily Planner)
J들의 메모장 (J's Daily Planner)
MBTI의 'J(판단형)' 성향을 가진 사람들을 위해 최적화된, 완벽한 하루 설계를 돕는 데일리 플래너입니다.

### 📃 앱 소개
"계획이 없으면 불안한 당신을 위한 가장 완벽한 도구"
단순한 메모장을 넘어,
하루를 시간 단위로 시각화하고 루틴을 체계적으로 관리할 수 있는 웹 기반 플래너입니다.
복잡한 기능은 덜어내고 '기록'과 '실천'에 집중하여, 사용자가 오늘 하루의 성취감을 시각적으로 즉시 느낄 수 있도록 설계되었습니다.

---

# 2️⃣ 게임
## 🐻 둠바족: 마사이족의 습격 (Doomba Village Crush)

### 📃 앱 소개
이 앱은 평화로운 자연을 지키려는 둠바족의 전사가 되어, 현대 문명과 기술의 상징인 IT 마을들을 습격하고 파괴하는 캐주얼 액션 아케이드 게임입니다.

사용자는 11층부터 13층까지 각각 안드로이드, 프론트엔드, 백엔드라는 고유한 IT 테마로 꾸며진 마을을 방문하게 됩니다.
각 마을의 성격에 맞는 기술 스택 아이콘(Kotlin, React, Spring 등)과 장비들을 타격하여 파괴하는 과정에서 시원한 타격감과 시각적 피드백을 느낄 수 있습니다.
Web Audio API를 통한 실감 나는 효과음과 부드러운 애니메이션이 더해져 짧은 시간 동안 스트레스를 해소하며 즐길 수 있도록 설계되었습니다.

# 3️⃣ 학습 앱

## ⌨️ IntelliJ Shortcut Master (인텔리제이 단축키 마스터)

### 📃 앱 소개
1. **맞춤형 학습**: MacOS와 Windows 환경을 선택하여 나에게 딱 맞는 인텔리제이 단축키를 체계적으로 탐색하고 저장할 수 있습니다.
2. **지능형 지원**: 궁금한 기능은 Gemini AI에게 바로 물어보고, 10초 타임어택 퀴즈를 통해 실전 단축키 감각을 익힙니다.
3. **생산성 극대화**: 필수 단축키 TOP 10과 즐겨찾기 기능을 활용해 백엔드 개발 크루의 업무 속도를 획기적으로 높여줍니다.
