# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.


## 💻 1. 유틸리티 앱

### 앱 이름
이미지 편집기

### 배포 링크
https://gemini.google.com/share/a93d5edeb01b

### 이 앱을 만든 이유

프론트로 디자이너(figma) 없이 웹을 만들 때 요소의 색상을 가져올 때 간단한 이미지 편집이나, 색상코드를 가져와야 할 때, 무거운 프로그램 설치 없이 매번 여러 프로그램으로 각각 실행해야한 점이 불편했다. 이를 위해 간단한 웹으로 편집과 색상을 가져오고, 또한 이미지를 다른 서버에 저장하지 않아 보안적으로 더 안전하면 좋겠어서 만들게 되었다.


### 주요 기능

- 사진 자르기
- 사진 선택 영역 색상 변경
- 사진 확장자 변경
- 사진 해당 부분 색상 코드 추출
- 전반적인 색상 코드 가져오기


## 🎮 2. 게임

### 앱 이름
3D 슈팅 게임

### 배포 링크
https://gemini.google.com/share/d486cb1205f1

### 이 앱을 만든 이유

- 3D 작업을 만드는 데 쉽지 않기 때문에 ai로 3d로 게임을 제작할 수 있는 지 궁금해서 제작하였다.
- 예전에 유니티로 제작했던 게임 영상을 보고 참고하였다.

### 주요 기능

- w,a,s,d로 이동을 하고, 마우스 클릭으로 공격을 합니다.
- 라운드는 상단의 시간동안 진행되며, 매 라운드마다 적이 추가됩니다.
- 라운드 시간 안에 적을 모두 처지하면, 라운드 보상이 주어집니다.
- 라운드 보상은 플레이어의 능력치를 증가시켜주는 선택지를 줍니다. 각 선택지는 확률에 따라 다른 수치로 등장합니다.
- 적의 공격을 맞으면 체력이 달고, 모든 체력이 다 닳으면 게임이 종료됩니다.


## 📚 3. 학습 앱

### 앱 이름
DevInterview

### 배포 링크
https://gemini.google.com/share/1ee9bb506007

### 이 앱을 만든 이유
면접 대비로 여러 문제들과 답변 예시는 있지만, 막상 내가 말한 답변이 제대로 된 답변인지 잘 모르겠어서 한번 검증, 피드백을 받으면 좋겠다 생각하여 제작하였다.

### 주요 기능

- 각 분야에 따른 세부 주제들로 ai기반 문제 생성
- 답변에 대한 체점 및 해설, 모범 답안 제공
- 이전 질문에 대한 연계 질문 생성

### AI 기능 (해당되는 경우)

- 어떤 AI 기능을 추가했나요?
  - LLM기반 맞춤형 질문 생성 및 답변 채점
- AI 기능이 앱에서 어떤 역할을 하나요?
  - 사용자가 선택한 분야에 맞게 질문을 생성하고, 답변에 대한 틀린 부분과 보완해야 하는 부분, 질문에 대한 분석이 담은 해설을 담고 있으며, 예시 답안을 제공한다.
