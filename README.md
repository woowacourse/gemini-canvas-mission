# gemini-canvas-mission

## markdownTemplateBuilder.html

"문서의 시작을 스마트하게" 복잡한 문서 구조 잡기에 시간을 쏟지 마세요. 상황만 입력하면 AI가 당신을 위한 최적의 마크다운 틀(Template)을 즉시 설계합니다.

### ✨ 핵심 기능 (Key Features)
- ⚡️ 즉각적인 템플릿 설계: 상황(예: 회고록, 강의 노트, 프로젝트 리드미)을 입력하면 AI가 논리적인 구조를 제안합니다.

- ✍️ 사용자 가이드 포함: [이곳에 내용을 입력하세요]와 같은 플레이스홀더를 제공하여 바로 작성이 가능하도록 돕습니다.

- 🎨 모던 & 미니멀 UI: Tailwind CSS 기반의 유리질(Glassmorphism) 디자인과 직관적인 사용자 경험을 선사합니다.

- 📋 원클릭 복사: 생성된 마크다운을 클립보드에 바로 복사하여 원하는 에디터에서 즉시 사용할 수 있습니다.

- 📱 반응형 디자인: 데스크톱부터 모바일 환경까지 최적화된 화면을 제공합니다.

### 🛠 기술 스택 (Tech Stack)
- Frontend: HTML5, Tailwind CSS

- AI Engine: Google Gemini 2.0 Flash (Preview)

- Icons: Lucide Icons (SVG)

- Typography: Noto Sans KR, Fira Code

## paperWrestling.html

"추억의 교실 책상 위 대결이 웹으로 돌아왔습니다!" > 친구와 마주 앉아 키보드가 부서져라 연타하던 그 시절의 손맛을 브라우저에서 그대로 느껴보세요.

### ✨ 핵심 기능 (Key Features)
1. 🎮 손맛 넘치는 2인용 로컬 대전
   리얼한 연타 메커니즘: A키와 L키를 누가 더 빠르게 누르느냐에 따라 승패가 결정되는 직관적인 시스템입니다.

    역동적인 피드백: 연타 시 발생하는 흔들림(Shake) 효과와 패배 시 화면 밖으로 날아가는 추락 애니메이션이 타격감을 극대화합니다.

2. 🏆 다양한 경기 모드 지원
   단순한 한 판 승부를 넘어, 긴장감을 유지할 수 있는 세 가지 모드를 제공합니다.

    단판 승부: 깔끔하고 빠른 한 판!
    
    3판 2선승제: 실력과 운을 모두 시험하는 표준 모드.
    
    5판 3선승제: 진정한 연타 왕을 가리는 끝장 승부.

3. 🎨 아날로그 감성의 모던한 디자인
   추억 소환 테마: 나무 책상 배경과 줄이 그어진 공책 종이를 모티브로 하여 학교 교실의 분위기를 재현했습니다.

    반응형 UI: 다양한 화면 크기에 최적화되어 어떤 PC 환경에서도 쾌적하게 즐길 수 있습니다.

### 🛠️ 기술 스택 (Tech Stack)
- Language: HTML5, JavaScript (ES6+)

- Styling: CSS3 (Flexbox, Keyframe Animations)

- Font: Pretendard / System Sans-serif

## thumbnailMaker.html

"글만 입력하세요, 디자인은 AI가 합니다." > 블로그 본문 내용을 분석하여 배경 이미지를 생성하고, 감각적인 폰트로 전문적인 썸네일을 완성하는 원스톱 제작 도구입니다.

### ✨ 핵심 기능 (Key Features)
1. 🤖 AI 기반 배경 자동 생성 (AI Magic)
   내용 분석: 블로그 요약글을 입력하면 Google Gemini가 시각적 프롬프트를 생성합니다.

    이미지 생성: Imagen 4.0 엔진을 통해 텍스트에 딱 맞는 고해상도 추상화 또는 사진 배경을 즉석에서 그려냅니다.

2. 폰트 감성 큐레이션 (Typography)
   다양한 스타일: 본고딕(깔끔), 나눔명조(감성), 검은고딕(강렬), 도현체(캐주얼), 송명체(우아) 등 5가지 테마별 폰트를 즉시 적용할 수 있습니다.

    실시간 렌더링: Canvas 엔진을 통해 폰트 크기, 줄 간격, 그림자 효과를 실시간으로 확인합니다.

3. 🛠 정교한 디자인 컨트롤
   투명도 및 레이어: 배경 이미지의 투명도(Opacity) 조절을 통해 글자 가독성을 최적화합니다.

    커스텀 업로드: AI 생성 이미지 외에도 사용자가 보유한 개인 사진을 업로드하여 편집할 수 있습니다.

    표준 규격: 티스토리, Velog, 네이버 블로그 등에서 가장 선호하는 1200 x 630 (1.91:1) 표준 비율을 지원합니다.

### 🛠 기술 스택 (Tech Stack)

- Core: HTML5 Canvas API, JavaScript (ES6+)

- Styling: Tailwind CSS, Font Awesome 6

- AI Integration: Google Gemini 2.5 Flash: 프롬프트 엔지니어링 및 텍스트 분석

- Imagen 4.0: 고품질 이미지 생성

- Fonts: Google Fonts API (Noto Sans KR, etc.)

## jetpackComposeLifecycle.html

"컴포즈의 탄생부터 소멸까지, 코드가 아닌 감각으로 익히세요." > 안드로이드의 최신 UI 프레임워크인 Jetpack Compose의 핵심, **Lifecycle(생명주기)**을 인터랙티브한 시뮬레이션과 퀴즈를 통해 완벽하게 마스터할 수 있는 학습 도구입니다.

### ✨ 핵심 기능 (Key Features)
1. 🔍 인터랙티브 생명주기 다이어그램
   3단계 시각화: Enter Composition → Recomposition → Leave Composition으로 이어지는 흐름을 직관적인 노드 구조로 표현했습니다.

    상세 가이드: 각 단계를 클릭하면 해당 시점에 발생하는 remember, LaunchedEffect, onDispose 등의 내부 동작 원리를 학습할 수 있습니다.

2. 📱 실시간 시뮬레이터 & 이벤트 로그
   가상 컴포저블 실행: 버튼 클릭 한 번으로 컴포저블을 트리에서 생성하거나 제거하며 실제 앱의 동작을 시뮬레이션합니다.

    상태 변경 추적: 'State 변경' 버튼을 통해 **리컴포지션(Recomposition)**이 일어나는 순간을 시각적 링 애니메이션으로 확인할 수 있습니다.

    디버그 로그 콘솔: 생명주기 변화에 따라 시스템 내부에서 어떤 로직이 실행되는지 타임스탬프와 함께 실시간 로그를 출력합니다.

3. 📝 지식 확인 퀴즈 (Self-Assessment)
   학습 검증: 학습한 내용을 바탕으로 구성된 4가지 핵심 퀴즈를 풀며 이해도를 측정합니다.

    친절한 해설: 정답 여부와 상관없이 각 문항에 대한 상세한 해설을 제공하여 개념을 다시 한번 복기하도록 돕습니다.

### 🛠 기술 스택 (Tech Stack)

- Language: HTML5, JavaScript (ES6+)

- Styling: Tailwind CSS

- Typography: Noto Sans KR

- Concept: Jetpack Compose (Android Modern UI)
