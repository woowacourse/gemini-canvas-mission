### 배포 링크

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?

```
자바 코드, 기술 등 이해하기 어려웠던 문제를 쉽게 이해하고자 했습니다.

실제 경험 중 운영체제를 공부하면서 논블락킹/블락킹 개념이 이해하기 힘들었습니다.
"직접 코드로 작성하면 조금 더 이해하기 쉽지 않을까?"라는 생각으로 자바 코드로 작성해봤지만,
여전히 저에겐 어려웠어요... ㅋㅋㅋ  

그래서 개념만으로 이해하기 힘든 내용을 시각화하면, 조금 더 이해하기 쉬울 것 같았습니다.
```
- 이 앱을 언제, 어떻게 사용할 건가요?

```text
학습 중 개념 이해가 어려운 내용들을 마주할 때마다 사용하려고 합니다!

앞으로 우테코 활동을 하면서 점점 더 어려운 개념들을 마주할 수 있을 것 같아요.
저는 그럴 때마다 canvas를 활용해서 매번 시각화 자료들을 추가할 예정이에요.

저와 같이 어려움을 느끼는 크루가 있다면 공유해서 함께 극복하고 싶습니다!
```

### 주요 기능
* 논블락킹/블락킹 시각화
* Stream API 시각화
* JVM + GC 시각화

### AI 기능 (해당되는 경우)
