# 🌍 여기에서 뭐 입지: 3D 지구본 기반 날씨 & 옷차림 추천

3D 지구본을 직접 돌려보며 전 세계 도시의 실시간 날씨를 확인하고, AI 기반 옷차림 추천을 받을 수 있는 인터랙티브 웹 애플리케이션입니다.

지구본 위의 핀을 클릭하거나 도시 이름을 검색하면, 해당 지역의 날씨 정보와 함께 온도에 최적화된 옷차림을 추천받을 수 있습니다.


## ✨ 주요 기능

**3D 인터랙티브 지구본**
- Three.js 기반 실제 지구 텍스처 적용
- 마우스 드래그로 자유롭게 회전 및 줌
- 주요 도시 18곳에 핀(빨간 점) 표시

**실시간 날씨 정보**
- 현재 기온, 날씨 상태, 풍속 확인
- 당일 최고/최저 기온 및 현지 시간 표시
- Open-Meteo API 기반 실시간 데이터

**도시 검색 기능**
- 우측 상단 검색창에서 전 세계 도시 검색 가능
- 검색한 위치로 카메라 자동 이동
- 검색 결과는 초록색 마커로 표시

**AI 옷차림 추천**
- 온도와 날씨 코드 기반 맞춤 옷차림 제안
- 기온대별 상의/하의/액세서리 조합
- 비/눈 등 강수 상황 시 우산/방한용품 추가 추천


## 🎮 사용 방법

**지구본 조작**
- **드래그**: 지구본 회전
- **마우스 휠**: 확대/축소
- **핀 클릭**: 해당 도시의 날씨 정보 표시

**도시 검색**
- 우측 상단 검색창에 도시 이름 입력 (한글/영문 가능)
- Enter 키 또는 검색 버튼 클릭
- 자동으로 해당 위치로 카메라 이동 및 날씨 정보 표시

**옷차림 추천**
- 날씨 정보가 로드되면 "✨ AI 옷차림 추천받기" 버튼 활성화
- 버튼 클릭 시 현재 날씨에 맞는 옷차림 조합 표시
- 옷걸이 아이콘과 함께 추천 아이템 시각화
