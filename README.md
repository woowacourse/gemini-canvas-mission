**인터랙티브 AI PDF 학습 웹 앱**

**배포 링크**  
https://gemini.google.com/share/a2a00e50e3e0

### 핵심 기능

- PDF 업로드 및 전자책형 뷰어

- AI 기반 핵심 문장 추출 기능
- 자동 밑줄 가이드 시각화

**한 줄 설명**

## 3. AlgoEasy (알고이지)

**알고리즘 시각화 학습 웹앱**

**배포 링크**  
https://gemini.google.com/share/1fca0db69930

### 핵심 기능

- Step-by-step 실행 제어 (Play / Pause / Next / Prev)
- 정렬 알고리즘 시각화 (버블, 삽입, 퀵, 병합, 힙)
- 그래프 탐색 (BFS, DFS, 다익스트라)
- 이분 탐색, 1D/2D Prefix Sum
- 시간 및 공간 복잡도 비교표 제공
- 4개 언어 코드 제공 (JavaScript, Python, Java, C++)

**한 줄 설명**  
정적 설명을 애니메이션으로 확장한 알고리즘 학습 도구

## 4. 스네이크 아레나

**2인용 배틀로얄 스네이크 게임**

**배포 링크**  
https://gemini.google.com/share/0b5291ed424d

### 핵심 기능

- 2인 로컬 대전 (WASD vs 방향키)
- 10초마다 맵이 축소되는 배틀로얄 시스템
- 축소 5초 전 점멸 경고 효과
- 상대 속도 증폭 아이템 (중첩 가능)
- 전략 및 심리전 기반 승부 구조

**한 줄 설명**  
클래식 지렁이 게임에 배틀로얄 요소를 결합한 대전 게임
