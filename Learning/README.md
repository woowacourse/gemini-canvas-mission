## 카테고리: 학습 앱

### 배포 링크
https://gemini.google.com/share/8200cfc356c8

### 이 앱을 만든 이유
**어떤 문제/불편함을 해결하려고 했나요?**
- 테스트 코드를 작성하려면 어떤 형태로 작성해야할지, TDD를 잘하고 싶은 주니어 개발자는
많은 연습 문제가 필요하다고 느꼈습니다.
- 테스트 코드 연습에는 많은 시간이 필요합니다. 간단한 방식으로 매일 부담없이 문제를 풀며
연습하여 테스트 코드 작성 능력을 향상시킵니다.

**이 앱을 언제, 어떻게 사용할 건가요?**
- 하루에 한 문제씩, 내 수준에 맞는 단계를 선정하여 문제를 풀어봅니다.

### 주요 기능
- 레벨 선택 기능
- 설계 도식 작성 기능
- 작성 도식 평가 및 답안 추천 기능
- AI와 문제에 대한 추가 대화 기능

### AI 기능 (해당되는 경우)

**어떤 AI 기능을 추가했나요?**
- 사용자가 입력한 도식 해석 및 리뷰 기능
- 문제에 대한 답안 추천 기능
- 문제 및 답변과 연계된 추가 대화 기능

**AI 기능이 앱에서 어떤 역할을 하나요?**
- 각 레벨에 맞게 테스트 코드 작성을 위한 문제를 생성해줍니다.
- 사용자가 입력한 도식을 해석, 리뷰해주며, 추천 답안도 제안해줍니다.
- 문제에 대해 추가로 질문이 있을 경우, AI대화를 통해 사용자의 질문에 답변해줍니다.
