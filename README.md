### 앱 이름: 어디서나 할인

### 배포 링크
[https://gemini.google.com/share/3eef5e9c6089](https://gemini.google.com/share/3eef5e9c6089)
> 특정 매장 방문 시, 내가 보유한 통신사·네이버 멤버십·신용카드 혜택 중 해당 브랜드에서 쓸 수 있는 혜택이 있는지 확인하기 위해 앱마다 일일이 제휴사 목록을 뒤지는 불편함을 해결하는 **통합 혜택 조회** 서비스입니다.

### 이 앱을 만든 이유

**해결하고자 한 문제:**
매장 방문 시 보유 중인 여러 멤버십의 할인 혜택을 확인하려면 각 앱을 하나씩 열어 제휴사 목록을 직접 검색해야 하는 번거로움이 있었습니다.

**사용 목적:**
브랜드명 하나만 입력하면 해당 매장에서 사용 가능한 모든 멤버십 혜택을 한 화면에서 한눈에 비교할 수 있습니다.

### 주요 기능

- 통합 혜택 조회:
    - 브랜드명(매장명) 입력 시 해당 브랜드에 혜택을 제공하는 멤버십 목록을 한 번에 조회합니다.
    - 검색 자동 완성: 입력한 키워드에 맞춰 DB 내 매장명 및 별칭(Alias)을 실시간으로 매칭하여 후보 리스트를 보여줍니다.
    - 스마트 추천 혜택: 조회된 혜택 중 할인율이 높거나 가장 대중적인 혜택을 '추천 혜택' 배지와 함께 최상단에 노출합니다.

- 멤버십 통합 관리:
    - 5대 주요 멤버십 지원: 통신 3사(SKT T멤버십, KT 멤버십, LG U+ 멤버십)와 생활형 멤버십(네이버 플러스 멤버십, CJ ONE)을 지원합니다.
    - 디렉토리 뷰(전체보기): 각 멤버십별로 제휴된 모든 매장 정보를 카테고리별로 모아볼 수 있는 탭 시스템을 제공합니다.
    - 브랜드 특화 UI: 각 멤버십의 브랜드 가이드라인에 맞춘 전용 컬러와 배지를 적용하여 시각적 구분이 용이합니다.
    - (추가 예정) 신용카드·체크카드·기타 멤버십 연동 및 보유 중인 항목만 필터링하는 기능을 추가할 예정입니다.

### AI 기능

- **사용 모델:** Google Gemini 2.5 Flash
- **역할:** DB에 등록되지 않은 매장 검색 시, 실시간으로 인터넷을 탐색하여 최신 혜택 정보를 자동 생성합니다.
    - Google Search Grounding: 단순 학습 데이터가 아닌 구글 검색 결과를 바탕으로 실제 제휴 혜택 정보를 제공합니다.
    - 지능형 데이터 파싱: AI 응답에서 불필요한 마크다운을 제거하고 순수 JSON 데이터만 추출하여 UI에 즉시 반영합니다.

## 🎮 2. 게임

### 앱 이름: 컬러 매치

### 배포 링크
[https://gemini.google.com/share/d70951b6d6cb](https://gemini.google.com/share/d70951b6d6cb)
> 무작위로 제시되는 **목표 색상**을 보고, 제한 시간 내에 **RGB 슬라이더**를 조작하여 가장 유사한 색상을 조합해 내는 캐주얼 웹 게임입니다. 색상의 정확도와 완성 속도에 따라 점수와 최종 등급이 결정됩니다.

### 이 앱을 만든 이유

**해결하고자 한 문제:**
프로젝트에서 디자이너와 협업할 때 "좀 더 밝은 파스텔 톤으로"처럼 추상적인 표현에 의존하게 되었습니다. 색감에 대한 이해가 부족하다 보니 원하는 색상을 정확하게 전달하기 어려웠습니다.

**사용 목적:**
RGB 슬라이더를 직접 조작하며 목표 색상을 맞추는 과정을 통해 색채 감각을 재미있게 키울 수 있습니다. 친구와 점수를 겨루며 자연스럽게 학습할 수도 있습니다.

### 주요 기능

- 메인 메뉴 및 게임 설정:
    - 라운드 설정: 1라운드부터 최대 10라운드까지 슬라이더로 플레이 볼륨을 조절할 수 있습니다.
    - 난이도 선택: 쉬움(Easy), 보통(Medium), 어려움(Hard), 불가능(Impossible) 4단계를 제공하며, 난이도에 따라 라운드별 초기 시간과 시간 감소 속도가 달라집니다.

- 게임 플레이 UI 및 컨트롤:
    - 긴급 상황 시각 효과: 남은 시간이 3초 미만이 되면 타이머 텍스트와 막대가 붉은색으로 변하고 깜빡이는 애니메이션이 적용되어 직관적인 경고를 줍니다.
    - RGB 슬라이더 실시간 피드백: 슬라이더를 움직일 때마다 '내가 만든 색상' 박스에 즉시 색상이 렌더링되어 목표 색상과 직관적으로 비교할 수 있습니다.
    - 자동 제출 방어선: 제한 시간 초과 시 기본색이 아닌, 시간이 끝나는 순간까지 플레이어가 조작한 최종 슬라이더 상태를 자동으로 감지하여 제출합니다.

- 결과 피드백 시스템:
    - 라운드별 결과 화면: 매 라운드 종료 시 목표 색상과 제출한 색상을 나란히 보여주며, 정확도(%), 시간 보너스, 라운드 최종 점수(최대 100점)를 표시합니다.
    - 최종 성적표 및 랭크 시스템: 모든 라운드 종료 후 누적 총점과 함께 평균 정확도에 기반한 **알파벳 등급(S, A, B, C, F)**을 부여하여 성취감과 재도전 욕구를 자극합니다.
    - 상세 라운드 기록 로그: 최종 결과 화면 하단에 각 라운드별 목표 색상, 제출 색상, 정확도, 점수를 리스트 형태로 정리하여 제공합니다.

## 📚 3. 학습 앱

### 앱 이름: JAVA GC 시뮬레이터

### 배포 링크
[https://gemini.google.com/share/4dac015b2c37](https://gemini.google.com/share/4dac015b2c37)
> Java 메모리 관리의 핵심인 GC(Garbage Collector)의 동작 원리를 시각적으로 체험할 수 있는 학습용 인터랙티브 시뮬레이터입니다. 주니어 개발자들이 눈으로 보며 직접 GC 동작을 체험하고 이해할 수 있도록 설계되었습니다.

### 이 앱을 만든 이유

**해결하고자 한 문제:**
Java GC는 개념 설명만으로는 동작 원리를 직관적으로 이해하기 어렵고, 실제 메모리 상태 변화를 눈으로 보며 학습할 수 있는 도구가 부족했습니다.

**사용 목적:**
Young/Old 영역 간 객체 이동, Minor GC·Full GC 발생 과정 등을 시각적으로 확인하며 GC의 동작 원리를 체험적으로 학습할 수 있습니다.

### 주요 기능

- 3가지 시나리오 체험:
    - Lv.1 단명 객체: 대부분의 객체가 Unreachable 상태로 변해 즉시 수거되는 모습을 관찰합니다.
    - Lv.2 세대 이동: 일부 객체가 살아남아 S0 ↔ S1 영역을 오가며 나이(Age)를 쌓고, 임계치를 초과하면 Old 영역으로 승격되는 과정을 시각화합니다.
    - Lv.3 메모리 누수: 객체가 수거되지 않고 Old 영역을 가득 채워 최종적으로 OutOfMemoryError를 발생시키는 과정을 재현합니다.

- 실시간 시각화:
    - 상단 진행률 바: Eden, Survivor, Old 영역이 차오르는 것을 실시간으로 확인할 수 있습니다.
    - 객체 블록 뷰: 생성된 객체는 사각형 블록으로 표현되며, 마우스를 올리면 해당 객체의 상태(나이, 종류)를 툴팁으로 확인할 수 있습니다. (블록 내 숫자는 객체의 나이를 의미합니다.)
    - 콘솔 로그(GC Event Logs): Minor GC와 Full GC 발생 시 하단 터미널에 수집·승격된 객체 수치 로그가 출력되어 내부 동작의 세부 정보를 확인할 수 있습니다.

> **"오늘 점심은 새로운 크루와 함께!"**
밥친구는 우아한테크코스 환경에서 크루들이 서먹함을 깨고 항상 먹는 사람들이 아닌 새로운 크루들, 다른 코스의 크루들과도 밥을 먹으며 자연스럽게 친해질 수 있도록 돕는 랜덤 점심 매칭 서비스입니다.

### 이 앱을 만든 이유

**해결하고자 한 문제:**
우아한테크코스 8기 크루들이 100명이 넘는 인원이다 보니, 매일 점심시간마다 익숙한 사람들과만 식사하게 되어 새로운 사람들과 친해질 기회가 없는 문제를 해결하고 싶었습니다.

**사용 목적:**
 매일 점심시간, 랜덤으로 짜여진 4~5인의 조원들과 함께 식사하며 서먹했던 크루들과의 친밀감을 높이고 새로운 네트워크를 형성하기 위해 사용합니다.

### 주요 기능

- 닉네임 기반 간편 로그인:
    - 별도의 회원가입 없이 사전 등록된 크루 닉네임만으로 즉시 이용 가능합니다.

- 실시간 참여 및 메뉴 설정:
    - 매일 점심시간 전 매칭 참여 여부와 선호하는 식사 장소(구내식당/외부 식당)를 선택할 수 있습니다.

- 랜덤 매칭 알고리즘:
    - 한 팀당 4~5명으로 구성되도록 자동 분배합니다.
    - 특정 식당 선호 인원이 부족한 경우 예외적으로 다른 식당 인원과 함께 매칭시켜줍니다.

- 관리자 전용 대시보드:
    - 전체 크루의 참여 상태를 실시간으로 모니터링하고 조작할 수 있습니다.
    - [매칭 시작] 버튼을 통해 원하는 시점에 즉시 랜덤 배정을 실행합니다.

- 사용자 경험:
    - 매칭 결과 화면에서 어색함을 깨줄 '오늘의 스몰토크 주제'를 제공합니다.
