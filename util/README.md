## 앱 이름: 테크코스 생활 가이드 챗봇

## 카테고리: 유틸리티 앱

### 배포 링크

https://gemini.google.com/share/7db89be34f71

### 이 앱을 만든 이유

- 레벨1에서 방대한 정보속에 크루들은 생활 가이드를 빠르게 확인하기 어렵습니다.
- 자연어 질문만으로 가이드북의 정확한 정보를 즉시 확인할 수 있도록 만들었습니다.
- 이 앱은 가이드북 내용이 궁금할 때마다 PDF를 직접 열어 검색하는 번거로움을 줄이기 위해 사용합니다.

### 주요 기능

- 자연어 질문 기반 가이드북 검색 — "회의실 예약 신청은 어떻게 해?" 같은 질문에 가이드북 내용을 근거로 정확하게 답변합니다.
- 목차 기반 사이드바 — [테크코스 가이드](https://docs.google.com/document/d/1IltsTYaLYkQbXOW1W2GuC85_vrwoPNh_2jbdS0f9wdU/edit?tab=t.0)의 목차를 그대로 사이드바에 표시하며, 섹션을 선택하면 해당 내용을 즉시 확인할 수 있습니다.
- 다크/라이트 모드 — 사용 환경에 맞게 테마를 전환할 수 있습니다.
- 답변 복사 및 프롬프트 수정 — 답변을 한 번에 복사하거나, 가장 최근 질문을 수정하여 재전송할 수 있습니다.

### AI 기능

- Gemini API를 연동하여 응답을 생성합니다.
- 하나의 대화에서 이전 대화에 대해 기억합니다.
- 가이드북 텍스트 데이터를 컨텍스트로 제공하여, AI가 가이드북 범위 내에서만 답변하도록 제한합니다. 가이드북에 없는 질문에는 답변을 거부하여 잘못된 정보 전달을 방지합니다.
