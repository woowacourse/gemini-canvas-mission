## 🎮 2. 게임

### 앱 이름
- 개인 랜덤 디펜스

### 배포 링크
- https://gemini.google.com/share/7bbb4656db9d

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
    - 스타크래프트 유즈맵 개인 랜덤 디펜스의 재미 요소(랜덤 유닛, 업그레이드, 상성, 웨이브 진행)를 웹에서 가볍게 즐기고 싶었습니다.
    - 설치 없이 바로 플레이 가능한 형태로 만들어 빠르게 한 판 즐길 수 있도록 했습니다.

- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
    - 쉬는 시간이나 이동 중에 짧게 1~2판 즐길 때 사용할 예정입니다.
    - “유닛 뽑기 → 배치/드래그 이동 → 업그레이드 → 20웨이브 클리어” 흐름으로 플레이합니다.

### 주요 기능

- 기능 1: 랜덤 유닛 뽑기 & 배치/이동
    - 초이스를 소모해 랜덤 유닛을 뽑고, 맵에 자동 배치됩니다.
    - 유닛은 드래그 앤 드롭으로 원하는 위치로 옮길 수 있습니다(길 위/중복 배치 불가).

- 기능 2: 웨이브/라이프 기반 디펜스 진행
    - 총 20웨이브, 웨이브마다 적이 생성되고 도착 시 라이프가 감소합니다.
    - 10킬마다 초이스 +1 보상을 받아 유닛 뽑기/도박에 활용할 수 있습니다.

- 기능 3: 자원 운영(초이스/미네랄)
    - 초이스로 미네랄 도박(0~10) 을 할 수 있고, 미네랄은 업그레이드에 사용됩니다.

- 기능 4: 종족별 공격력 업그레이드
    - 바이오닉/메카닉/저그/프로토스 종족별 공격력 업그레이드가 가능하며, 레벨이 오를수록 비용이 증가합니다.

- 기능 5: 공격 타입 & 장갑 상성 시스템
    - 일반/폭발/진동/마법 타입을 적용했고, 적 크기(소/중/대) 에 따라 피해량이 달라집니다(마법은 방어 무시).
