## 🔮 1. 엘리멘탈 샌드박스: 마법 연성소
**다섯 가지 기초 원소를 조합하여 화려한 시각적 마법 효과를 생성하는 입자 기반 샌드박스 시뮬레이터입니다.**

### ✨ 주요 기능
* **5대 핵심 원소 시스템:** 불(Fire), 물(Water), 바람(Wind), 땅(Earth), 번개(Lightning) 원소 드래그 연성.
* **마법 조합 메커니즘:**
    * **이색 조합(Cross-Elements):** 서로 다른 원소 혼합 시 고유 기술 생성 (예: 불+바람 = 다크 파이어 토네이도).
    * **동일 조합(Ultimate Mastery):** 같은 원소 중첩 시 극의 기술 발동 (예: 번개+번개 = 신의 심판).
* **고품질 시각 효과(VFX):**
    * 수백 개의 입자가 실시간으로 물리 연산되는 **고성능 파티클 시스템**.
    * `lighter` 블렌딩 모드를 통한 눈부신 발광 효과 및 화면 흔들림(Screen Shake) 연출.

## ☕ 2. Java 코딩테스트 문법 & 알고리즘 퀴즈 앱
**코딩테스트 직전, Java의 필수 문법과 알고리즘 지식을 점검할 수 있는 인터랙티브 퀴즈 웹 애플리케이션입니다.**

### 📌 프로젝트 특징
* **실전 맞춤형 문항:** 배열/문자열 변환, Stream API, 정렬, BFS/DFS 등 단골 주제 12문제 수록.
* **직관적인 학습 경험:** 어두운 테마의 코드 뷰어, 즉각적인 피드백(초록/빨강), 상세한 오답 해설 제공.
* **상태 관리:** React Hooks를 사용하여 이전/다음 문제 이동 시에도 선택한 답과 해설 유지.

### 🛠 기술 스택 및 설치
* **Frontend:** React.js, Tailwind CSS, Lucide React
* **실행 방법:**
    ```bash
    git clone [https://github.com/your-username/java-coding-test-quiz.git](https://github.com/your-username/java-coding-test-quiz.git)
    npm install && npm install lucide-react
    npm start
    ```

## 🎲 3. 3D 대환장 경마 게임 (Chaos Racing)
**순수 자바스크립트와 Three.js로 구현된, 예측 불허의 돌발 상황이 가득한 3D 레이싱 시뮬레이션입니다.**

### 🌟 주요 기능
* **Three.js 기반 3D 그래픽:** 프레임워크 없이 구현된 가벼운 환경, 3D 복셀 캐릭터 및 동적 조명 적용.
* **스마트 카메라 시스템:** 선두 그룹 추적 및 돌발 상황 발생 시 우측 상단 **PIP(Picture-in-Picture) 클로즈업** 중계.
* **실시간 중계 UI:** 아나운서의 텍스트 중계와 실시간 순위판을 통한 직관적인 경기 파악.

### 🚨 돌발 상황 시스템
* **💥 꽈당!:** 무작위 기절 효과.
* **🤸 물구나무!:** 거꾸로 뒤집혀 느리게 이동.
* **🍌 쭈우욱!:** 바나나 껍질 미끄러짐 회전.
* **🐅 호랑이 난입:** 5% 확률로 말이 호랑이에게 잡혀먹히고 기수가 직접 뛰는 연출.

### 🚀 실행 방법
별도의 빌드 과정 없이 `index.html` 파일을 크롬 등 모던 브라우저에 드래그 앤 드롭하여 바로 실행할 수 있습니다.
