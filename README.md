# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 앱 목록

### 1. AI 스타킹 (`ai_stocking.html`)
Gemini API를 활용한 실시간 AI 주식 분석 대시보드. 종목명을 검색하면 매수/매도 확률을 VS 형태로 시각화하고, AI 분석 리포트와 글로벌 증시 뉴스 요약을 제공합니다.

### 2. 추억놀이 동네 모임 (`childhood_game.html`)
Firebase 기반의 어린 시절 놀이(숨바꼭질, 경찰과 도둑, 무궁화 꽃이 피었습니다) 모임 매칭 앱. 출생연도 기반 참가 자격 제한, 방 생성/참여/관리 기능을 지원합니다.

### 3. 도큐퀴즈 (`docu_quiz.html`)
공식 문서 URL을 입력하면 Gemini API가 Google 검색으로 해당 문서를 분석하여 5개의 객관식 퀴즈를 자동 생성하는 학습 도구. 정답/오답 피드백과 최종 점수 리포트를 제공합니다.

### 4. 링구아 (`lingua.html`)
txt 파일을 업로드하면 문장 단위로 분리하여 AI 기계 번역과 사용자 번역을 나란히 비교할 수 있는 번역 워크벤치. 원문 단어 클릭 시 Gemini API로 사전 의미를 조회하고, 완성된 번역본을 파일로 내보낼 수 있습니다.

### 5. 네온 오버드라이브(`neon_overdrive.html`)
뱀서라이크(로그라이트 서바이벌) 게임. WASD/방향키로 무한 맵을 이동하며 자동 공격으로 적을 처치하고, 레벨업 시 3가지 업그레이드 중 선택하여 캐릭터를 강화합니다.
