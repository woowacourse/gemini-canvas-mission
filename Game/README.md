## 앱 이름: WAR SURVIVE
## 카테고리: 게임

### 배포 링크
https://gemini.google.com/share/30bfd157140f

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?  
  : 개발을 하면서 중간중간에 가볍게 스트레스 해소할 겸 편하게 할 수 있는 게임을 위해 만들었습니다.
- 이 앱을 언제, 어떻게 사용할 건가요?  
  : 위 이유와 같이 개발을 하던 중 쉬는 시간에 자주 사용하면서 즐길 것 같습니다.

### 주요 기능
- 직관적인 조작: 마우스 이동만으로 캐릭터를 조종하는 오토 슈팅 방식
- 성장 및 파밍: 좌측의 강화 벽을 파괴하여 공격력, 연사력, 인원수 실시간 업그레이드
- 디펜스 및 생존: 우측에서 몰려오는 적을 놓치거나 부딪히면 생명력(인원수) 감소
- 5단계 스테이지: 라운드마다 점진적으로 상승하는 난이도와 각 라운드별 보스전 진행
