# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 💻 1. 유레카 (Eureka)

> **"지능형 학습 자동화: 모르는 것과 아는 것을 연결하다"**
> 

[배포 링크 바로가기](https://gemini.google.com/share/1edcab5290e2)

공식 문서를 학습할 때 지식이 파편화되는 문제를 해결하기 위해 **'아하!**'와 **'응?**'이라는 개념을 도입한 스마트 학습 도구입니다.

- **학습 모먼트의 정의**
    - **아하!(Aha!):** 기존 지식이 확장되거나, 새로운 정보들이 서로 연결되며 깨달음을 얻는 순간.
    - **응?(Huh?):** 처음 접하는 개념이거나, 논리적으로 이해가 되지 않아 흐름이 끊기는 순간.
- **학습 효과:** 이 두 순간을 의식적으로 기록하면, 내가 무엇을 모르는지 명확히 파악(메타인지)할 수 있고, 지식을 체계적으로 매핑하여 장기 기억으로 전환하는 데 큰 도움을 줍니다.
- **Key Features**
    - **AI 자동 모먼트 분류:** 사용자가 학습 내용을 자유롭게 기록하면, AI가 문맥을 분석하여 **아하!**와 **응?** 카드로 **자동 분류하여 저장**합니다.
    - **지식의 시각화:** 해결되지 않은 **'응?'** 질문이 해결될수록 해당 카드의 색상이 짙은 초록색으로 변하며, 자신의 이해도를 직관적으로 추적할 수 있습니다.
    - **개인화 분석 리포트:** 축적된 데이터를 바탕으로 AI가 현재의 이해 상태를 진단하고, 부족한 부분을 채우기 위한 단계별 학습 방향을 제시합니다.

## 🎮 2. F1 스타트 체험하기 (F1 Reaction Timer)

> **"0.1초의 승부, 당신의 반응 속도는 어느 정도인가요?"**
> 

[배포 링크 바로가기](https://gemini.google.com/share/e6af1940ee18)

F1 레이싱의 하이라이트인 '스타트' 순간을 재현했습니다. 찰나의 반응 속도를 측정하고 실제 드라이버들과 비교해 보세요.

- **Key Features**
    - **실제 F1 스타트 UI:** 5개의 레드 라이트가 순차적으로 점등된 후, 꺼지는 순간의 반응 속도를 측정합니다.
    - **반응 속도 기반 드라이버 매칭:** 측정된 기록을 바탕으로 S~C 등급을 부여하며, "당신의 반응 속도는 니코 휠켄베르크급!"과 같이 실제 선수와 비교해 줍니다.

## 📚 3. JVM 메모리 동작 이해하기 (Visual JVM)

> **"보이지 않는 자바의 내부 동작을 시각화하다"**
> 

[배포 링크 바로가기](https://gemini.google.com/share/8dd1e8bd6819)

텍스트만으로는 이해하기 힘든 JVM(Java Virtual Machine)의 메모리 구조와 가비지 컬렉션(GC) 과정을 동적으로 시각화합니다.

- **Key Features**
    - **메모리 할당 시뮬레이션:** 객체 생성 시 Heap 영역의 변화와 메서드 호출 시 Stack 영역의 동작을 실시간으로 확인합니다.
    - **실시간 동작 해설:** MinorGC, 메모리 이동 및 해제 과정마다 AI 안내 문구가 출력되어 동작 원리를 쉽게 설명해 줍니다.

## 🤝 4. 우아한 정거장 (Woowahan Station)

> **"우테코 크루들을 위한 올인원 커뮤니티 허브"**
> 

[배포 링크 바로가기](https://gemini.google.com/share/c0524824c081)

분산된 학습 정보와 크루들의 활동 소식을 한곳에서 관리하고 공유하는 우테코 전용 플랫폼입니다.

- **Key Features**
    - **크루 위치 레이더:** 현재 동료들이 몇 층에서 열공 중인지 실시간으로 공유하고 조회합니다.
    - **공유 주파수 & 탐사 기록물:** 유용한 기술 아티클과 미션 결과물을 공유하고 추천(좋아요)할 수 있습니다.
    - **AI 전파 교정기:** 크루 간의 원활한 협업(소프트 스킬)을 돕기 위해, 입력한 문장을 더 부드럽고 정중한 말투로 AI가 변환해 줍니다.
