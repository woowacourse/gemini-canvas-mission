# ☕ Java 알고리즘 마스터
### 배포 링크: https://gemini.google.com/share/049ef718f9c7

### 프로젝트 개요

‘Java 알고리즘 마스터’는 Java 언어를 통해 알고리즘 핵심 이론을 단계적으로 학습할 수 있는 인터랙티브 웹 애플리케이션입니다. 단순히 개념을 나열하는 방식이 아니라, 각 알고리즘 주제별로 시각적인 인포그래픽과 퀴즈를 결합하여 학습자가 개념을 직접 확인하고 체화할 수 있도록 설계되었습니다. 시간복잡도부터 그래프 이론까지 총 9개의 핵심 주제를 순차적으로 학습할 수 있습니다.

###  목표 사용자

- Java를 활용하여 알고리즘을 처음 공부하는 학습자
- 코딩 테스트를 준비하며 핵심 개념을 체계적으로 정리하고 싶은 사람
- 이론을 배운 후 즉각적인 퀴즈로 이해도를 점검하고 싶은 사람

### 학습 커리큘럼

총 9개의 주제를 아래 순서로 학습합니다.

1. 시간복잡도 (Time Complexity)
2. 그리디 (Greedy)
3. 구현 (Implementation)
4. DFS / BFS
5. 정렬 (Sorting)
6. 이진탐색 (Binary Search)
7. 동적 프로그래밍 (Dynamic Programming)
8. 최단 경로 (Shortest Path)
9. 그래프 이론 (Graph Theory)

### 핵심 기능 요구사항

#### 1. 인포그래픽 기반 개념 설명

각 알고리즘 주제를 시각적으로 이해할 수 있도록 인포그래픽 형태로 제공합니다.

- 개념 설명과 함께 Java 코드 예제를 나란히 배치하여 이론과 실습을 동시에 확인
- 알고리즘의 동작 흐름을 단계별 시각화로 표현
- 시간복잡도 표, 그래프, 트리 등 주제에 맞는 다양한 시각 요소 포함

#### 2. 퀴즈를 통한 이해도 확인

각 주제를 학습한 후 퀴즈를 통해 개념을 점검할 수 있습니다.

- 주제별 퀴즈 제공
- 정답 및 오답에 대한 즉각적인 피드백과 해설 제공
- 퀴즈 점수 및 진행 현황을 화면에 표시

#### 3. 순차 학습 구조

학습 주제가 단계적으로 구성되어 있습니다.

- 사이드바 또는 네비게이션을 통해 9개 주제 간 자유로운 이동 지원
- 현재 학습 중인 주제와 완료된 주제를 시각적으로 구분하여 진도 파악 가능


### 구현 및 프로그래밍 제약 조건

- **AI 도구 제한**: 오직 Gemini Canvas만을 사용하여 코드를 생성합니다. 다른 AI 코딩 어시스턴트는 사용하지 않습니다.
- **프롬프트 엔지니어링 훈련**: 직접 코드를 작성하기보다, 명확한 성공 기준과 제약 조건을 포함한 프롬프트 지시어만으로 유용한 앱을 완성하는 것을 목표로 합니다.
- **기술 스택**: HTML5, CSS3, JavaScript만 사용합니다. React 등 어떠한 프론트엔드 프레임워크나 빌드 도구도 사용하지 않습니다.
