# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

---

이 레포지토리는 우아한테크코스 교육 과정 중 겪는 기술적 어려움을 해소하고, 크루 간의 유대감을 높이며, 성장을 가속화하기 위해 제작된 유틸리티 앱들을 포함하고 있습니다.

## 🛠 Project Lineup

### 1. 🍖 나 벨트 풀었다. (음식 쌓기 게임)

- **카테고리**: 게임
- **주요 특징**: 배달의민족 브랜드 아이덴티티를 활용한 메인 음식 쌓기 게임입니다.
- **핵심 기능**:
- 다양한 음식(떡볶이~족발) 단계별 병합 및 스코어링
- 배민 특유의 위트 있는 문구와 UI 애니메이션 구현
- 우테코 8기 크루들의 긴장 해소를 위한 엔터테인먼트 요소

### 2. 🔐 여러분 저 됐어요. 로그인 됐어요

- **카테고리**: 학습 앱
- **주요 특징**: Spring Security의 복잡한 인증 내부 구조를 시나리오별로 시각화합니다.
- **핵심 기능**:
- Form 로그인, JWT, OAuth2, OIDC 등 5가지 핵심 인증 시나리오 매핑
- 단계별 필터 체인(Filter Chain) 및 객체 간 상호작용 추적
- Spring Security의 높은 진입장벽을 낮추기 위한 인터랙티브 가이드

### 3. 👤 우테코 코치님, 이름이 뭐예요?

- **카테고리**: 페어 프롬프트 릴레이
- **주요 특징**: 토스(Toss) 스타일의 깔끔한 UI를 활용한 코치진 이름 맞히기 퀴즈입니다.
- **핵심 기능**:
- 사용자가 직접 코치 사진과 이름을 등록하고 커스텀 데이터 생성
- 시간 제한 및 입력 방식(객관식/주관식) 설정 기능
- 초성 및 소개 문구를 활용한 단계별 힌트 시스템 제공

### 4. 🎯 풀래?플레! (알고리즘 문제 추천)

- **카테고리**: 유틸리티
- **주요 특징**: `solved.ac` API와 Gemini AI를 결합한 개인화 알고리즘 문제 추천 서비스입니다.
- **핵심 기능**:
- 사용자의 백준 ID 기반 실력 분석 및 약점 파악
- 주요 빅테크 기업의 출제 경향에 맞춘 집중 문제 추천
- AI를 통한 객관적인 난이도 조절로 효율적인 학습 지원

## 🏗 Tech Stack (Common)

- **Frontend**: HTML5, CSS3 (Tailwind CSS), JavaScript (Vanilla JS/ES6+)
- **Library**: Lucide Icons, Pretendard Font
- **AI Implementation**: Google Gemini API
- **External API**: solved.ac API
