            가이드
          

          

            당황하지 마세요. 현재 겪고 있는 상황을 선택하면 해결책을
            찾아드립니다.
          


          
          

            
            
            
            
            
          


          
          

            

            

              
            

          

        

      


      
      

        
        

          

            

              🔄 가장 최근 커밋 메시지 수정하기
            

            

              git commit --amend -m "새로운 메시지"
              
            

          

          
          

            

              위험
            

            

              ⏪ 방금 한 커밋 강제 취소 (작업 내역까지 모두 삭제)
            

            

              git reset --hard HEAD~1
              
            

          

          

            

              ⏪ 방금 한 커밋 안전하게 취소 (작업 내역 유지)
            

            

              git reset --soft HEAD~1
              
            

          

          

            

              🗑️ 원격 저장소의 특정 브랜치 삭제하기
            

            

              git push origin --delete 브랜치명
              
            

          

          

            

              위험
            

            

              🧹 로컬에서 추적되지 않는 파일 모두 강제 삭제
            

            

              git clean -fd
              
            

          

          

            

              🌱 새 브랜치 생성하고 이동하기
            

            

              git switch -c 새로운_브랜치명
              
            

          

          

            

              📦 작업 중인 변경사항 임시 저장 (스태시)
            

            

              git stash
              
            

          

          

            

              📥 임시 저장한 변경사항 다시 가져오기 (스태시 적용)
            

            

              git stash pop
              
            

          

          

            

              ⚙️ 전역 사용자 이름 및 이메일 설정
            

            

              git config --global user.name "내 이름" git config --global
                user.email "내 이메일"
              
            

          

          

            

              🔗 기존 로컬 저장소를 원격 저장소에 연결
            

            

              git remote add origin 원격저장소_주소
