# 우테코 데일리 로그

> AI 가이드 질문으로 매일의 배움을 부담 없이 기록하는 회고 앱입니다.

---

## 이 앱을 만든 이유

- 우아한 테크코스에서 배운 점들을 매일 기록하고 싶지만, **백지 상태에서 시작하는 기록은 쉽지 않다**는 문제를 해결하고 싶었습니다.
- AI가 가이드 질문을 던져주고, 그 질문에 답하는 과정을 통해 **훨씬 수월하게 하루를 정리**할 수 있도록 만들었습니다.
- 우테코 출석 후 **매일 저녁 하루를 마무리할 때** 사용하며, 나중에 하루 단위로 쌓인 기록들을 한눈에 모아볼 수 있습니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| AI 회고 작성 | 날짜를 클릭하면 AI가 우테코 하루를 되돌아볼 수 있는 연계 질문 3개를 제시하고, 답변을 취합해 회고록을 완성해줍니다. |
| 모의 면접 질문 | 작성한 회고를 바탕으로 AI가 날카로운 면접 질문을 생성해, 하루를 다시 한번 되돌아볼 수 있게 합니다. |
| 회고 낭독 (TTS) | 작성한 회고를 AI 음성으로 낭독해줍니다. |
| 월간 성장 분석 | 해당 달에 기록한 회고들을 AI가 분석해 성장 포인트, 보완할 점, 응원 메시지를 리포트로 생성해줍니다. |
| 출석 현황 확인 | 회고를 남긴 날짜는 출석으로 처리되며, 이번 달 출석일을 모아볼 수 있습니다. |

---

## AI 기능

이 앱의 AI는 **매일의 회고 기록 전 과정**에 걸쳐 사용자의 부담을 줄이고 재미를 더하는 역할을 합니다.

1. **질문 생성** — 오늘 하루를 기록할 때 도움이 될 질문 3개를 AI가 생성합니다.
2. **회고록 완성** — 질문에 대한 답변들을 취합해 하나의 유기적인 회고록으로 정리해줍니다.
3. **모의 면접** — 완성된 회고록을 바탕으로 면접 질문을 생성해 매일 새로운 자기 점검 경험을 제공합니다.
4. **월간 분석** — 선택한 달의 회고록 전체를 살펴보고 성장 포인트, 보완할 점, 따뜻한 응원 메시지를 제공합니다.

> AI 기능 덕분에 사용자는 스트레스 없이, 질문에 답하는 방식으로 자연스럽게 회고를 작성하고 성장을 확인할 수 있습니다.
