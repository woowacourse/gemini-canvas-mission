# 프로젝트 소개

# 🧠 1. Smart Note

## 📌 프로젝트 소개

아이디어를 흩어두고 다시 찾지 못하는 문제를 해결하기 위해 만든 AI 기반
메모 관리 앱입니다.\
AI가 **메모를 분석·구조화·요약·탐색**해주는 지능형 메모 시스템입니다.

🔗 배포 링크\
https://gemini.google.com/share/e11aa18a8999

## 🛠 주요 기능

-   메모 목록 조회
-   메모 수정
-   AI 자동 카테고리 생성
-   제목 자동 생성 (기존 제목 유지)
-   `/summarize {번호/주제}` 메모 요약 기능
-   `/find {프롬프트}` 맥락 기반 메모 탐색 기능
