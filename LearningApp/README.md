## 📚 3. 학습 앱

### 앱 이름
- REST Status Master

### 배포 링크
- https://gemini.google.com/share/b368047223ac

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
    - HTTP 상태코드는 백엔드 개발에서 매우 중요하지만, 단순 암기 위주로 학습하는 경우가 많았습니다.
    - 특히 401과 403의 차이, 400과 422의 구분, 409의 사용 시점 등 실무 상황에서 헷갈리는 경우가 많았습니다.
    - 그래서 실제 REST API 시나리오 기반으로 상태코드를 학습할 수 있는 인터랙티브 퀴즈 앱을 만들었습니다.

- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
    - 면접 준비나 CS 복습을 할 때 빠르게 개념을 점검하는 용도로 사용합니다.
    - 5~10문제를 설정해 짧게 풀면서 상태코드 감각을 유지하는 데 활용합니다.
    - 오답 리뷰 기능을 통해 틀린 개념을 다시 확인합니다.

### 주요 기능

- 기능 1
    - “만료된 JWT 토큰 접근”, “이메일 중복 가입 시도” 등 실제 상황을 제시합니다.
    - 8개의 상태코드 보기 중 올바른 코드를 선택합니다.
    - 정답 여부에 따라 해설과 REST 예시 응답(JSON)을 제공합니다.
- 기능 2
    - 문제 풀이 후 점수를 100점 기준으로 환산하여 표시합니다.
    - 사용자가 선택한 답과 실제 정답을 비교하여 보여줍니다.
    - 모든 문제에 대한 해설과 JSON 응답 예시를 다시 확인할 수 있습니다.

### AI 기능 (해당되는 경우)

- 어떤 AI 기능을 추가했나요?
    - Gemini API를 활용하여 HTTP 상태코드 실무 시나리오를 동적으로 생성하는 기능을 추가했습니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
    - 사용자가 설정한 문제 개수에 맞춰 새로운 상황을 자동으로 생성합니다.
    - 단순 고정 문제풀이가 아닌, 매번 다른 시나리오를 제공하여 반복 학습 효과를 높입니다.
