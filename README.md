# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## ✅ 제출 체크리스트

- [X] 4개 웹앱 제출 (유틸리티 앱 1개 + 게임 1개 + 학습 앱 1개 + 페어 프롬프트 릴레이 1개)
- [X] 최소 1개 앱에 Gemini AI 기능 포함
- [X] 모든 앱이 배포 링크로 정상 동작함
- [X] AI 사용 일지 작성 완료

## 💻 1. 유틸리티 앱

### 앱 이름
**구름 뉴스**
### 배포 링크
[링크](https://gemini.google.com/share/296eef23df9b)
### 이 앱을 만든 이유
>다양한 정보를 신속하게 확보하고, 내게 필요한 데이터로 가공 및 활용하는 것이 경쟁력이라고 생각합니다.
OECD 38개국의 기간언론사 기사를 지도 상에서 직관적으로 탐색하고, 국가별로 자주 나오는 이슈를 한눈에 파악하고 싶어서 만들었습니다.
해외 뉴스는 언어 장벽 때문에 제목만 보고 넘어가는 경우가 많아, AI 번역/요약을 탑재했습니다.
- 어떤 문제/불편함을 해결하려고 했나요? 
  - 국가별 뉴스 탐색의 번거로움 해결
    - 여러 사이트/앱을 오가야하는 불편함을 해결했습니다.
    - 내가 원하는 주제만 카테고리에서 선택해 골라볼 수 있도록 했습니다.
  - 정보 과부하
    - 찾아봐야할 국내/해외 뉴스가 너무 많아 지금 중요한 것을 빠르게 추려보기 힘듭니다.
    - 최신순으로 정렬하여 주요 소식을 놓치지 않도록 도와줍니다.
  - 언어 장벽 해결
    - 해외 속보는 국내 언론사가 번역허여 속보로 올리지 않는 이상 보기 힘듭니다.
    - 이러한 불편함을 AI 번역/요약으로 해결했습니다.
  - 신뢰도 문제
    - 국가별로 어느 매체가 상대적으로 공신력 있는지 사용자가 매번 판단하기 어렵습니다. 
- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
  - 자투리 시간에 빠르게 전 세계의 이슈를 확인하고 학습, 개발, 투자 등에 활용하고자 합니다.
  - 지도에서 관심 국가를 클릭해서 최신 이슈를 빠르게 훑습니다. 
  - 회의/스터디 전에 특정 키워드로 검색해 관련 뉴스를 모아봅니다. 
  - 관심 기사들은 북마크해두고, 나중에 원문 링크로 더 자세히 확인합니다. 
  - 해외 기사는 필요할 때 일괄 번역을 눌러 한국어로 맥락을 빠르게 잡고, 중요한 건 AI 요약으로 핵심만 확인합니다.

### 주요 기능
- 지도 기반 국가별 뉴스 탐색 (Leaflet)
  - 세계 지도를 띄우고, 국가별 뉴스 개수를 마커나 숫자 배지로 표시합니다. 
  - 국가나 마커를 클릭하면 해당 국가로 줌인하고, 오른쪽 패널에서 해당 국가 뉴스 목록을 보여줍니다. 
- 실시간 뉴스 수집 및 필터링, 검색, 북마크 
  - 뉴스 수집 
    - Google News RSS + Bing News RSS를 병렬로 가져와 중복 제거 후 최신순 정렬합니다. 
    - CORS 문제를 피하기 위해 allorigins, corsproxy를 이용한 fetch fallback 구조를 사용합니다. 
  - 뉴스 분류 
    - 제목/카테고리/요약을 합쳐 키워드 매칭으로 정치/경제/사회/IT/과학/문화/스포츠 자동 분류합니다. 
  - 탐색 기능
    - 카테고리 필터, 키워드 검색 패널, 최신순 피드 제공 
    - 읽음 처리(리스트에서 흐리게 표시), 북마크(스크랩) 저장 및 북마크만 보기 토글 
  - 추가 로딩 
    - 국가 패널에서 스크롤 하단 도달 시 과거 기사를 단계적으로 더 불러오는 무한 스크롤 구조를 구현했습니다. 
  - 갱신 UX 
    - 전체 LIVE 갱신, 국가별 갱신 버튼이 있고, 마지막 갱신 후 경과시간을 표시합니다.
    - 사용자의 컴퓨팅 리소스를 고려해 일정시간 후 강제갱신은 지원하지 않습니다.
    
### AI 기능 (해당되는 경우)
- 어떤 AI 기능을 추가했나요?
  - 번역 기능
    - 대한민국 외 국가 뉴스에 대해, 제목/요약을 한국어로 번역합니다. 
    - 최대 15개씩 순차 처리하며, 번역 결과를 translations 상태에 저장합니다. 
  - 요약 기능 
    - 사용자가 'AI 요약하기' 버튼을 누르면, 해당 뉴스를 1~2문장 한국어 핵심 요약으로 생성합니다. 
    - 결과는 summaries 상태에 저장되고, 카드 상단에 AI Summary 박스로 노출됩니다. 
    - Google Gemini API 엔드포인트(generateContent)를 호출하도록 구성되어 있기에 추후에 실제 활용하려면 API KEY가 필요합니다!
- AI 기능이 앱에서 어떤 역할을 하나요?
  - 해외 뉴스의 진입 장벽을 낮추는 역할
    - 사용자가 원문을 열기 전에도 번역/요약으로 “무슨 내용인지”를 즉시 파악할 수 있게 합니다.
  - 바쁜 사용자를 위한 빠른 의사결정 지원
    - 뉴스 전체를 읽지 않고도, 요약 1~2문장으로 중요도를 판단하고 북마크할 수 있습니다. 
  - 탐색 효율 향상 
    - 사용자가 국가 단위의 많은 언론사와 포털사이트를 방문하지 않아도 정보를 얻을 수 있습니다.
    - AI 요약 기능을 통해 핵심에 더 빨리 도달하도록 돕습니다.

## 🎮 2. 게임

### 앱 이름
**대체당하기 싫으면 튀어라**
### 배포 링크
[링크](https://gemini.google.com/share/cd14ee7029e1)
### 이 앱을 만든 이유
>AI가 빠르게 발전하면서 개발자로서 계속 성장해야 한다는 압박감과 불안을 게임처럼 재밌게 체감하고, 동시에 Kotlin과 Android 아키텍처 지식을 퀴즈로 반복 학습할 수 있게 만들기 위해 제작했습니다.
단순 퀴즈가 아니라, 추격전으로 긴장감을 넣어서 게임 속에서 공부하는 흐름을 자연스럽게 만들어보고자 했습니다.
- 어떤 문제/불편함을 해결하려고 했나요?
  - 공부가 지루해서 꾸준히 하기 어렵다
    - 단순 CS 문제를 푸는 행위를 AI가 쫒아오는 긴박한 게임으로 연결해서 몰입도를 높이고자 했습니다.
  - 은근히 기술 지식을 쉽게 외울 수 있다.
    - 레벨별(학부생 -> CTO) 난도로 구성해 단계적 학습을 할 수 있게 구성했습니다.
    - 단순히 미래를 대비하기 위해 하는 막연한 학습이 아닌, 당장 게임에서 패배하지 않기 위해 답을 맞춰야 하는 상황을 이용해 학습 효율을 높이고자 했습니다.
  - 자기 점검이 어렵다.
    - 정답/오답이 즉시 피드백으로 반영되므로 내 실력을 체감할 수 있습니다. 
  - 설치 없이 가볍게 즐길 수 있는 학습형 콘텐츠가 부족하다
    - 설치 없이 브라우저에서 바로 실행되는 Three.js 기반 미니게임으로 접근성을 높였습니다.
- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
    - 출퇴근 시간에 5~10분씩 짧게 플레이하면서 개념을 리마인드하고자 합니다.
    - 스터디/면접 대비 중 레벨별 문제를 반복해서 약점을 확인합니다. 
    - 학습 루틴이 늘어질 때, 게임 한 판으로 강제 집중해서 공부 텐션을 올려볼 생각입니다.
### 주요 기능

- 기능 1 : Three.js 3D 게임 
  - Three.js로 3D 씬, 카메라, 조명, 그리드를 구성하고, 플레이어는 박스로 표현된 캐릭터로 전진, 좌우 이동합니다. 
  - 뒤에서 거대한 붉은 AI 벽이 일정 속도로 추격하며, 플레이어가 느리면 잡혀서 게임오버가 됩니다. 
  - 좌우 벽으로 코스를 제한해 달리기 트랙 느낌을 만들고, 카메라는 플레이어 뒤를 따라가며 추적 시점을 제공합니다. 
  - 오답 또는 벽과 충돌 시 화면이 붉게 깜빡이는 damage-overlay로 타격감을 줍니다.
- 기능 2 : 퀴즈 기반 3지선다 선택 및 레벨 업 시스템 
  - 전방에 퀴즈 벽이 등장하고, 벽에는 3개의 문이 있으며 정답이 적힌 문을 통과해야 합니다. 
  - 정답 
    - XP(+50) 획득 
    - 해당 벽 통과 처리 
    - AI를 뒤로 밀어내 약간의 거리 확보 
  - 오답 
    - 목숨 감소(총 3개)
    - 플레이어가 튕겨나며 속도가 리셋되며 AI가 앞으로 당겨져 잡힐 위험이 증가하도록 설계했습니다.
    -  AI와 거리가 있더라도, 목숨 0이면 즉시 게임오버됩니다.
  - 레벨 시스템 
    - Lv.1(학부생) -> Lv.10(CTO)까지 구성했습니다. 
    - 누적 XP가 임계값을 넘으면 레벨업하며, AI 속도 배수가 증가해 난이도가 올라갑니다. 
  - UI 
    - 현재 레벨, XP 점수, 남은 목숨, 문제 패널, 벽
    - 화면 하단 AI와의 거리 미터 표시 
      - 하단 트랙 UI로 플레이어와 추격하는 AI 간 위치를 퍼센트로 시각화합니다. 
  - 입력 지원 
    - PC: W(전진), A/D(좌우), S(감속)
    - 모바일: 터치 버튼 제공(좌/우/전진)

## 📚 3. 학습 앱

### 앱 이름
**디지털 디톡스 웹앱 버전 (Digital Detox Web App Ver.)**
### 배포 링크
[링크](https://gemini.google.com/share/dc1dbc7dd8e3)
### 이 앱을 만든 이유
> 프리코스 당시 스마트폰 앱으로 개발한 [Digital Detox](https://github.com/GiyunKim00/DigitalDetox)를 웹앱 버전으로 개발했습니다.
> 웹의 경우, 넷플릭스나 유튜브의 유혹으로 공부 집중이 자주 끊기는 문제를 체감하고, 얼마나 집중했는지를 감으로만 판단하지 않고 수치로 기록하고 싶어서 만들었습니다.
또한 집중이 흐트러질 때 딴짓 대신 가볍게 할 수 있는 자투리 Android 학습 콘텐츠를 한 앱 안에 묶어, 집중 → 기록 → 회고 → 학습 루틴을 만들려는 목적이 있습니다.
- 어떤 문제/불편함을 해결하려고 했나요?
  - 집중 시간과 딴짓 시간을 구분하기 어렵다
    - 단순 타이머가 아니라, 탭 전환/화면 비활성 상태를 감지해 자리비움/딴짓 시간을 별도로 누적합니다. 
  - 공부 세션이 끝나면 무엇이 문제였는지 잊는다.
    - 세션 종료 시 회고를 남기고, 최근 기록을 다시 볼 수 있게 해 회복 루틴을 제공합니다.
  - 할 일을 앱, 메모, 노션 등 여러 곳에 적는다.
    - 간단한 To-do 기능을 내장해 오늘의 집중 목표를 한곳에서 관리합니다.
  - 딴짓이 시작되면 다시 공부로 복귀하기 어렵다. 
    - 딴짓 대신 할 수 있는 짧은 학습 모듈(퀴즈/카드)을 제공해 복귀 비용을 낮춥니다.
- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
  - 공부/코딩 시작 전
    - 할 일 탭에서 오늘 목표를 2~3개 등록합니다.
  - 집중 세션 시작
    - 타이머 시작 이후 실제로 집중했는지, 탭을 벗어났는지 자동 추적합니다. 
  - 집중 중 방해 최소화
    - 전체화면 Zen 모드로 들어가 화면을 단순화합니다. 
  - 세션 종료
    - 정지 -> 회고 모달에서 왜 흐트러졌는지/어떤 점이 좋았는지 짧게 기록합니다.
    - 리포트에서 누적된 회고록을 확인할 수 있습니다.
  - 쉬는 시간, 딴짓 감지 후
    - 학습 탭에서 퀴즈나 코틀린 카드로 3~5분 복습하고 다시 집중으로 복귀할 수 있습니다.

### 주요 기능

- 기능 1
    - 집중 타이머 + 딴짓(자리비움) 타이머 자동 분리 
      - 메인 타이머: 공부/집중 시간을 초 단위로 누적
      - 서브 타이머: 딴짓 시간을 별도로 누적
    - 구현 방식 
      - window blur/focus, document.visibilitychange, document.hasFocus()를 이용해 사용자가 화면을 벗어났는지 추적 
      - useRef(isAwayRef, lastTickRef, accumFocusRef, accumDistractionRef)로 백그라운드에서도 누적 오차를 줄이도록 설계
      - 실행 중에는 document.title을 [mm:ss] 집중 중! 또는 [자리비움] 형태로 바꿔 상태를 바로 알 수 있게 함 
    - 세션 중단 시 
      - 집중/딴짓 시간이 조금이라도 있으면 회고 모달을 띄워 기록을 유도 
      - 기록이 없으면 바로 초기화
- 기능 2
  - 목표 관리 + 리포트,회고 + 자투리 학습 
  - 목표
    - 목표 추가/완료 체크/삭제 기능 
    - 오늘의 집중 목표를 간단히 관리 
  - 리포트
    - 오늘 집중한 시간 표시 
    - 요일별 주간 막대 그래프 UI 제공(현재는 목업입니다.)
    - 저장된 세션 회고 기록을 카드 형태로 보여줌 
  - 회고 기록 
    - 세션 종료 시 날짜/시간/집중/딴짓/메모를 저장
    - 내가 집중을 망치는 패턴을 나중에 되돌아볼 수 있음 
  - 학습 
    - 생명주기 퀴즈: Activity/Fragment/Compose 관련 객관식, 즉시 채점/정답 표시/점수 집계

  - 번아웃이 올 때: 번아웃 선택 후 ,오늘은 쉬어도 된다는 허락을 받는 용도 
  - 하루가 끝난 뒤: 상담을 마치고 기록을 남긴 다음, 다음 날 비슷한 상황이 왔을 때 이전 상담 기록을 보며 패턴을 확인
