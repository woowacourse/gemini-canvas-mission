## 📚 3. 학습 앱

> ### [우테코 테코톡 퀴즈 생성기](https://gemini.google.com/share/0aafe23c477e)

### 주요 기능
- **우아한테크코스 10분 테코톡 기반 퀴즈**
    - 테코톡 영상에서 다룬 내용을 활용해 다양한 퀴즈를 생성
- **퀴즈 분류**
    - 퀴즈에서 다룬 내용을 다양하게 추출해 분야/레벨/키워드 별로 분류
- **퀴즈 선택**
    - 사용자가 원하는 분류, 원하는 만큼의 퀴즈를 선택
- **퀴즈 풀이**
    - 사용자가 선택한 퀴즈를 풀이
- **결과 확인**
    - 풀이 결과와 해당 퀴즈의 출처 영상을 제공
- **추가 학습**
    - 희망하는 퀴즈의 출처 영상을 통해 자율적 학습 기회 제공

## 🤝 4. 페어 프롬프트 릴레이 앱

### [`프로젝트 회고 보드`](https://gemini.google.com/share/1bb0dff2dec4)

### 페어
- [캐리](https://github.com/tjdakf)

### 주요 기능
- **활동 기록, 회고** 
  - 프리코스의 미션 소감/피드백을 기반으로
    - 이번 미션에서 만족스러운/배운 부분
    - 이번 미션에서 아쉬운/실패한 부분
    - 다음 미션에서 시도할 부분
  - 를 Keep/Problem/Try 로 정리
  - 한 줄 길이로, 작지만 여러개의 내용을 작성
- **회고 공유**
    - 같은 서비스를 공유하는 다른 크루원들의 회고 탐색, 댓글과 공감으로 상호 교류 
- **회고 비교**
    - 특정 회고들을 선택해 일괄 비교
- **주제 태깅**
  - 활동에 다른 크루들의/나만의 태그를 붙여 분류
- **태그별 정리**
  - 태그 기준 회고 조회 
- **AI 기반 회고 비교분석**
  - 특정 회고들을 선택해 각 회고의 키워드와 내용 분석
  - K/P/T 분류별로 공통적으로 드러나는 부분을 요약정리
