## 앱 이름: Daily Planner
## 카테고리: 유틸리티 앱

### 배포 링크
https://gemini.google.com/share/e5bca1ead097

### 이 앱을 만든 이유
**어떤 문제/불편함을 해결하려고 했나요?**
- 할 일이 정리되지 않아 머리가 아플 때가 있습니다. 매일 아침 시간을 투자하여
  오늘 해야할 일을 정리하고, 시간을 미리 할당한다면 계획적인 하루를 보낼 수 있을 거예요.

**이 앱을 언제, 어떻게 사용할 건가요?**
- 매일 아침, 가볍게 생각나는 일들을 작성해보고, 하루의 시간에 맞춰 배치해보며 
하루 일정 계획을 만들 수 있습니다. 만들어진 계획표는 이미지 파일로 내보내어 
필요할 때 언제든 확인할 수 있고, 모든 일정이 마무리되면 이미지는 삭제해버리면 됩니다.


### 주요 기능
- 할 일 추가 기능
- 중요도 선택 기능
- 할 일 배치 기능
- 시간표 이미지로 내보내기
