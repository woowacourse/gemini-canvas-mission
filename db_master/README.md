### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
    - 데이터베이스를 체계적으로 공부하고 싶어도 어느 수준까지 알아야 하는지 기준이 없어 방향을 잡기 어려운 문제를 해결하고 싶었습니다.
- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
    - 우테코 과정 중 DB 관련 미션이 시작되기 전이나, 기술 면접 준비 시 단계별 자가 점검 용도로 활용할 예정입니다.

### 주요 기능
- 기능 1
    - 입문 -> 기본 -> 설계 -> 고급 4단계로 구성된 섬을 순서대로 클리어(10문제 중 8개 이상 정답)해야 다음 단계로 진행할 수 있습니다.
- 기능 2
    - 문제를 맞추면 해당 개념의 동작 과정을 Gemini AI가 인포그래픽으로 시각화해 이해를 돕습니다.

### AI 기능 (해당되는 경우)
- 어떤 AI 기능을 추가했나요?
    - Gemini AI를 활용한 퀴즈 문제 생성 및 정답 해설 인포그래픽 자동 생성 기능을 추가했습니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
    - 각 단계에 맞는 4지선다 문제를 동적으로 생성하고, 정답 선택 시 해당 개념(ex - 트랜잭션 ACID, B-Tree 인덱스 구조 등)의 동작 원리를 시각화하여 단순 암기가 아닌 원리 이해를 돕습니다.
