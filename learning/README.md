# 백엔드 성장 시뮬레이션

> 미션을 클리어하며 레벨업하는 백엔드 개발 학습 플랫폼입니다.
> AI가 핵심 개념을 설명하고 퀴즈를 생성해 실전 감각을 키울 수 있습니다.

---

## 이 앱을 만든 이유

- 백엔드 개발의 다양한 개념을 단순히 읽는 것이 아니라 **상황 기반 미션**으로 직접 선택하고 판단하며 학습하고 싶었습니다.
- XP와 레벨업 시스템을 통해 **성장이 눈에 보이는 학습 경험**을 만들고자 했습니다.
- AI의 심층 설명과 퀴즈 생성을 통해 **매번 다른 문제**로 지루하지 않게 복습할 수 있도록 했습니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 45개 순차 미션 | API 설계, DB, 보안, 인프라, 아키텍처 등 다양한 주제의 미션을 난이도 순서대로 해금하며 진행합니다. |
| XP & 레벨 시스템 | 미션 정답 여부에 따라 XP를 획득하고, 주니어 → 테크 리드까지 5단계 레벨로 성장합니다. |
| 마스터 키 | 레벨업 시 획득하는 마스터 키로 잠긴 미션을 먼저 해금할 수 있습니다. |
| AI 심층 설명 | 미션 풀이 후 AI가 핵심 개념 설명, 인포그래픽(SVG), 실무 관점 해설을 제공합니다. |
| AI 퀴즈 생성 | 미션 키워드를 바탕으로 AI가 매번 새로운 퀴즈 2문제를 생성해 개념을 즉시 점검합니다. |

---

## AI 기능

- 미션 풀이 후 AI가 해당 개념의 **핵심 원리**를 3~5문장으로 설명해줍니다.
- **SVG 인포그래픽**을 자동 생성해 개념을 시각적으로 이해할 수 있게 합니다.
- 미션 키워드 기반으로 **맥락에 맞는 퀴즈**를 동적으로 생성해 단순 암기가 아닌 사고력을 키웁니다.
- 각 퀴즈 선택지에 대한 **상세한 피드백**을 제공해 틀린 이유까지 파악할 수 있습니다.
