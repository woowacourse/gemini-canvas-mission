## 앱 이름: 일본어 기초 학습 앱

## 카테고리: 페어 프롬프트 릴레이

### 배포 링크

https://gemini.google.com/share/141ae2936df1

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
    - 기존에 스픽, 말해보카, 케이크 등 영어 학습 앱은 많지만 일본어 학습 앱은 상대적으로 서비스가 적다는 문제를 해결하고자 했습니다.
    - 또한, 학습 앱의 경우 비용이 발생하기 때문에 선뜻 결제하기 어렵다는 점을 보완하고자 했습니다.
- 이 앱을 언제, 어떻게 사용할 건가요?
    - 가볍게 일본어 기초 학습을 진행하기 위해 사용할 계획입니다.

### 주요 기능

- 히라가나 및 가타카나 학습
- 일본어 문장 스피치 학습
    - 자동 문장 생성
    - TTS를 활용한 음성 생성 기능
- 일본어 문장 받아쓰기 학습
    - 자동 문장 생성
    - 마이크를 활용한 사용자의 일본어 발음 인식 및 일치 여부 확인 기능

### AI 기능

- 어떤 AI 기능을 추가했나요?
    - 퓨샷 프롬프팅을 통해 일본어 문장을 자동으로 생성하는 기능을 추가했습니다.
    - TTS를 활용해 생성한 문제의 발음을 오디오로 생성하는 기능을 추가했습니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
    - 일본어 학습 문제 자료 생성
    - TTS 음성 처리
