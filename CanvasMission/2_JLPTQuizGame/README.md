### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
  - JLPT 공부를 하기 위해 두꺼운 책을 펼쳐야 하는 상황을 줄이고, 재밌게 퀴즈 형식으로 AI와 실시간으로 대화하면서 인터랙티브한 학습을 진행할 수 있게 제작
- 이 앱을 언제, 어떻게 사용할 건가요?
  - JLPT 필수단어를 익히고 싶을 때, 원하는 난이도를 선택하여 각 급수에 해당하는 단어를 퀴즈로 학습

### 주요 기능
- 기능 1 : N5부터 N1까지의 난이도 선택
- 기능 2 : 난이도별 총 50개의 필수단어 중 10개 랜덤선택으로 퀴즈 진행
- 기능 3 : 정답/오답 시 초록색/빨간색으로 표시, 정답의 발음, 뜻, 예문이 담긴 카드 하단에 제공
- 기능 4 : 추가 선택 시 AI가 단어의 연상 암기 비법을 생성하여 학습을 도움
- 기능 5 : 퀴즈 종료 후 결과창 출력 - 맞춘 갯수, 정답률, 틀린 문제 포함 다시풀기, 처음으로 돌아가기 기능
- 기능 6 : 퀴즈 종료 후 나온 단어 10가지로 AI가 짧은 일본어 이야기를 생성해 복습을 도와줌
- 기능 7 : 시작화면부터 종료화면까지 우측에 제미나이 챗봇이 있어 정답을 직접적으로 알려주는 것을 제외하고 학습에 도움을 줌

### AI 기능 (해당되는 경우)
- 어떤 AI 기능을 추가했나요?
  - 단어별 연상 암기 비법 기능
  - 퀴즈에 사용된 10개의 단어를 자연스럽게 녹인 일본어 이야기 생성 기능
  - 실시간으로 대화 가능한 챗봇기능
- AI 기능이 앱에서 어떤 역할을 하나요?
  - 추가 용례 질문, 암기 비법 생성, 이야기를 통한 언어의 접근성 증대 등으로 인터랙티브하고, 효율적인 학습을 기대할 수 있음
