## 앱 이름: 오늘의 음식은?
## 카테고리: 유틸리티 앱

### 배포 링크
https://gemini.google.com/share/0464b8bc5fb4

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
: 매 끼니마다 '뭐 먹을까?' 고민하며 쉽게 결정을 내리지 못하는 사람들(이른바 결정장애)의 피로도를 줄여주고자 했습니다. 방대한 메뉴의 바다 속에서 시간대와 큰 카테고리만 선택하면, 앱이 간편하게 한 가지 음식을 콕 집어주어 선택의 스트레스를 덜어주는 해결책을 만들고 싶었습니다.

- 이 앱을 언제, 어떻게 사용할 건가요?
: 친구, 연인, 직장 동료들과 모였을 때 누구 하나 선뜻 메뉴를 정하지 못하는 난감한 상황에서 유용하게 사용할 수 있습니다. 다 함께 화면을 보며 룰렛을 돌리고 멈추는 과정을 통해, 지루할 수 있는 메뉴 고르는 시간마저 하나의 재미있는 게임처럼 즐길 수 있습니다.

### 주요 기능

- 직관적인 2단계 맞춤 필터링  
: 언제 먹을 것인지(아침, 점심, 저녁, 간식), 어떤 종류가 끌리는지(한식, 중식, 일식, 양식, 디저트)를 시각적인 아이콘과 함께 직관적으로 선택할 수 있습니다.

- 풍부한 음식  
: 각 카테고리별로 대중적으로 인기 있는 20가지의 음식 메뉴를 꼼꼼하게 등록해 두어, 총 100가지의 폭넓은 메뉴 중 하나를 추천받을 수 있습니다.

- 사용자 친화적인 깔끔한 UI/UX  
: 상단에 진행률 바(Progress Bar)를 배치하여 현재 어느 단계에 있는지 쉽게 알 수 있으며, 따뜻한 식욕을 돋우는 오렌지 톤과 부드러운 애니메이션 효과를 적용하여 모바일/PC 어디서나 쾌적하게 사용할 수 있습니다.

- 간편한 재시도 및 초기화 기능  
: 추천 결과가 마음에 들지 않거나, 다른 종류를 알아보고 싶을 때 원클릭으로 '다시 뽑기(같은 카테고리 내에서 재실행)' 또는 '처음부터(완전 초기화)'를 실행할 수 있습니다.
